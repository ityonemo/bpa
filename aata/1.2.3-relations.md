# Equivalence Relations

A literate `bpa` transliteration of the tractable part of **Chapter 1
("Preliminaries"), §1.2.3 "Equivalence Relations and Partitions"** of Thomas W.
Judson's *Abstract Algebra: Theory and Applications* (source:
`vendor/aata/src/sets.xml`; © 1997–2026 Judson, GFDL 1.3). The book's prose is
reproduced in order; each result within reach of bpa's first-order kernel is
followed by a machine-checked `bpa` proof. Run `bpa check aata/1.2.3-relations.md`.

The theory lives in `std/relation.bpa`: a relation is a binary predicate
`related(x, y)` over a sort `Element`, and *reflexive* / *symmetric* /
*transitive* / *equivalence* are transparent `define`s (macros) — each *is* its
body, so a proof gets the body for free (no defining axiom to cite and unfold).
We import it and alias to the book's names (`related` as `∼`).

```bpa
import relation <<< "std/relation.bpa"

sort Element = relation.Element
pred related = relation.related
define reflexive = relation.reflexive
define symmetric = relation.symmetric
define transitive = relation.transitive
define equivalence = relation.equivalence
```

> *Modeling note. An equivalence relation on $X$ is, in the book, a subset
> $R \subset X \times X$; `bpa` takes the relation `related(x, y)` (i.e.
> $(x,y) \in R$, or $x \sim y$) as a primitive binary predicate over a single
> element sort, which is all the structural results below need. What this file
> does NOT reach is the second half of §1.2.3 — **equivalence classes** $[a]$
> and **partitions** ($X = \bigcup [x]$) and their correspondence with
> equivalence relations — because those quantify over classes (themselves sets)
> and partitions (sets of sets), needing a quotient / sets-of-sets structure
> `std/set.bpa`'s flat membership does not model. That is deferred; see
> `aata/README`.*

## Equivalence Relations and Partitions

A fundamental notion in mathematics is that of equality. We can generalize
equality with equivalence relations and equivalence classes. An **equivalence
relation** on a set $X$ is a relation $R \subset X \times X$ such that

- $(x, x) \in R$ for all $x \in X$ (**reflexive** property);
- $(x, y) \in R$ implies $(y, x) \in R$ (**symmetric** property);
- $(x, y)$ and $(y, z) \in R$ imply $(x, z) \in R$ (**transitive** property).

Given an equivalence relation $R$ on a set $X$, we usually write $x \sim y$
instead of $(x, y) \in R$.

Directly from the definition, an equivalence relation *is* each of its three
constituent properties. Because `equivalence` is now a transparent `define` — it
*is* the term `reflexive and symmetric and transitive` — the hypothesis already
is that conjunction, and each projection is just the appropriate `and`-elimination
(no defining axiom to cite and unfold first).

```bpa
theorem equivalenceIsReflexive: equivalence -> reflexive
proof
  @given-equivalence |
    assume equivalence {
      @all-three |
        equivalence
        [by hypothesis given-equivalence]
      @reflexive-and-symmetric |
        reflexive and symmetric
        [by and_elim_left all-three]
      @conclusion-reflexive |
        reflexive
        [by and_elim_left reflexive-and-symmetric]
    }
  @conclusion |
    equivalence -> reflexive
    [by implies_intro given-equivalence]
qed

theorem equivalenceIsSymmetric: equivalence -> symmetric
proof
  @given-equivalence |
    assume equivalence {
      @all-three |
        equivalence
        [by hypothesis given-equivalence]
      @reflexive-and-symmetric |
        reflexive and symmetric
        [by and_elim_left all-three]
      @conclusion-symmetric |
        symmetric
        [by and_elim_right reflexive-and-symmetric]
    }
  @conclusion |
    equivalence -> symmetric
    [by implies_intro given-equivalence]
qed

theorem equivalenceIsTransitive: equivalence -> transitive
proof
  @given-equivalence |
    assume equivalence {
      @all-three |
        equivalence
        [by hypothesis given-equivalence]
      @conclusion-transitive |
        transitive
        [by and_elim_right all-three]
    }
  @conclusion |
    equivalence -> transitive
    [by implies_intro given-equivalence]
qed
```

## Exercises

**Exercise 24.** *The reflexive property is redundant in the axioms for an
equivalence relation* — provided every element is related to something. The
book's hint: if $x \sim y$, then $y \sim x$ by symmetry, and using transitivity
$x \sim x$.

The unqualified statement is actually false (the empty relation on a nonempty
set is vacuously symmetric and transitive but not reflexive), so we make the
missing hypothesis explicit: $\sim$ is **serial** — every $x$ relates to some $y$
($\forall x\, \exists y;\ x \sim y$). Under symmetry, transitivity, and
seriality, reflexivity follows.

```bpa
theorem reflexiveIsRedundant:
  symmetric -> transitive -> (forall x: Element; exists y: Element; related(x, y)) -> reflexive
proof
  @given-symmetric |
    assume symmetric {
      @given-transitive |
        assume transitive {
          @given-serial |
            assume forall x: Element; exists y: Element; related(x, y) {
              @symmetric-holds |
                symmetric
                [by hypothesis given-symmetric]
              @transitive-holds |
                transitive
                [by hypothesis given-transitive]
              @serial |
                forall x: Element; exists y: Element; related(x, y)
                [by hypothesis given-serial]
              @every-element-reflexive |
                fix x: Element {
                  @x-relates-to-something |
                    exists y: Element; related(x, y)
                    [by forall_elim(x) serial]
                  @with-witness-y |
                    unpack y: Element from x-relates-to-something {
                      @x-related-y |
                        related(x, y)
                        [by hypothesis with-witness-y]
                      @symmetry-at |
                        related(x, y) -> related(y, x)
                        [by forall_elim(x, y) symmetric-holds]
                      @y-related-x |
                        related(y, x)
                        [by modus_ponens symmetry-at x-related-y]
                      @transitivity-at |
                        related(x, y) -> related(y, x) -> related(x, x)
                        [by forall_elim(x, y, x) transitive-holds]
                      @transitivity-1 |
                        related(y, x) -> related(x, x)
                        [by modus_ponens transitivity-at x-related-y]
                      @x-related-x |
                        related(x, x)
                        [by modus_ponens transitivity-1 y-related-x]
                    }
                  @conclusion-x-reflexive |
                    related(x, x)
                    [by exists_elim with-witness-y]
                }
              @conclusion-reflexive |
                reflexive
                [by forall_intro every-element-reflexive]
            }
          @discharge-serial |
            (forall x: Element; exists y: Element; related(x, y)) -> reflexive
            [by implies_intro given-serial]
        }
      @discharge-transitive |
        transitive -> (forall x: Element; exists y: Element; related(x, y)) -> reflexive
        [by implies_intro given-transitive]
    }
  @conclusion |
    symmetric -> transitive -> (forall x: Element; exists y: Element; related(x, y)) -> reflexive
    [by implies_intro given-symmetric]
qed
```

## Deferred to a later file

The rest of §1.2.3 — **equivalence classes** $[a] = \{ x : x \sim a \}$,
**partitions**, and the fundamental correspondence (*an equivalence relation on
$X$ partitions $X$, and conversely a partition induces an equivalence relation*)
— needs a **sets-of-sets / quotient structure**: the classes $[a]$ are sets, and
a partition is a *set of sets* with a membership one level up (`member : Set ->
Powerset`) that `std/set.bpa`'s flat model does not provide. The concrete
equivalence-relation exercises (is $x \sim y$ iff $x \ge y$ an equivalence
relation on $\mathbb R$, etc.) additionally need concrete number domains. Both
are deferred; see `aata/README`.
