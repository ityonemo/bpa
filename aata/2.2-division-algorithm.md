## The Division Algorithm

> **Theorem (Division Algorithm).** Let $a$ and $b$ be integers, with $b > 0$.
> Then there exist unique integers $q$ and $r$ such that $a = bq + r$ where
> $0 \le r < b$.

Judson's proof of existence runs the Principle of Well-Ordering on the set
$S = \{\, a - bk : k \in \mathbb Z \text{ and } a - bk \ge 0 \,\}$; its least
member is the remainder $r = a - bq$. Uniqueness runs the other way: from two
decompositions $a = bq + r = bq' + r'$ it derives $b \mid (r' - r)$ with
$0 \le r' - r < b$, forcing $r' - r = 0$. Both directions need one arithmetic
fact the book takes for granted — a product of nonnegatives is nonnegative —
proved in the library by induction on the second factor (base $b\cdot 0 = 0$;
step $b\cdot(k+1) = b\cdot k + b$, a sum of nonnegatives).

```bpa
theorem productOfNonnegativesIsNonneg = division.productOfNonnegativesIsNonneg
```

The second fact is the one Judson invokes when he writes "$b \mid (r' - r)$ and
$0 \le r' - r < b$ is possible only if $r' - r = 0$." A nonnegative multiple of
$b$ that lies strictly below $b$ must be zero. Writing the multiple as $m = bk$,
the library splits on the sign of $k$. If $k = 0$ then $m = 0$ directly. If $k >
0$ then $k = d + 1$ for a nonnegative $d$, so $m = bk = bd + b$; but $m < b$ then
forces $bd < 0$, impossible since $bd$ is a product of nonnegatives. If $k < 0$
then $-m = b(-k)$ is a product of nonnegatives, so $m \le 0$; with $m \ge 0$ that
pins $m = 0$.

```bpa
theorem boundedNonnegMultipleIsZero = division.boundedNonnegMultipleIsZero
```

Judson also uses, at the very end of uniqueness, that $b > 0$ cancels: from
$bq = bq'$ one reads off $q = q'$. The library isolates the fact behind that
cancellation: a positive times a positive is positive, and therefore a positive
times a factor that is *not* zero cannot be zero — so $bz = 0$ with $b > 0$
forces $z = 0$.

```bpa
theorem positiveFactorZeroForcesZero = division.positiveFactorZeroForcesZero
```

### Uniqueness

Judson's uniqueness argument compares two decompositions $a = bq + r = bq' + r'$.
Subtracting, $b(q - q') = r' - r$, so $b \mid (r' - r)$; and since $0 \le r, r' <
b$ the difference $r' - r$ lies strictly between $-b$ and $b$. A divisor's
multiple that small must be $0$, so $r = r'$ and then $bq = bq'$ gives $q = q'$.
The library records the small order facts the argument leans on, the difference
identity $b(q - q') = r' - r$ (the ring rearrangement the book performs in one
line), and finally the uniqueness theorem.

The remainders must agree: trichotomy on $r_1$ versus $r_2$ makes each strict
case a bounded multiple of $b$, which the packaging lemma forbids; equal
remainders then cancel to $bq_1 = bq_2$, and a positive $b$ cannot annihilate,
so $q_1 = q_2$.

```bpa
theorem remaindersEqual = division.remaindersEqual
theorem divisionAlgorithmUnique = division.divisionAlgorithmUnique
```

### Existence

For existence Judson invokes Well-Ordering on the set $S = \{\, a - bk : k \in
\mathbb Z,\ a - bk \ge 0 \,\}$. Its least member $r = a - bq$ satisfies $a = bq +
r$ with $r \ge 0$; and $r < b$, for otherwise $a - b(q+1) = r - b$ would be a
smaller nonnegative member. Nonemptiness is where the sign of $a$ enters, and
Judson splits on it: if $a \ge 0$ the witness $k = 0$ gives the member
$a - b\cdot 0 = a \ge 0$; if $a < 0$ the witness $k = 2a$ gives the member
$a - b(2a) = a(1 - 2b)$, a product of two nonpositive factors ($a < 0$, and
$1 - 2b < 0$ because $b > 0$ forces $2b \ge 2 > 1$), hence $\ge 0$. The library
reproduces that split explicitly; the factorisation $a - b(2a) = a(1 - 2b)$ is
the only elided ring algebra. The classical least-element instance for
$S_{a,b} = \{\, x : x = a - bk \text{ for some } k \,\}$ is proved there directly
from strong induction.

```bpa
theorem remainderSetHasLeast = division.remainderSetHasLeast
theorem divisionAlgorithmExists = division.divisionAlgorithmExists
```

Together `divisionAlgorithmExists` and `divisionAlgorithmUnique` are the
Division Algorithm: for every $a$ and every $b > 0$ there are integers $q$ and
$r$ with $a = bq + r$ and $0 \le r < b$, and they are unique.
