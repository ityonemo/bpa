## The Division Algorithm

> **Theorem (Division Algorithm).** Let $a$ and $b$ be integers, with $b > 0$.
> Then there exist unique integers $q$ and $r$ such that $a = bq + r$ where
> $0 \le r < b$.

Judson's proof of existence runs the Principle of Well-Ordering on the set
$S = \{\, a - bk : k \in \mathbb Z \text{ and } a - bk \ge 0 \,\}$; its least
member is the remainder $r = a - bq$. Uniqueness runs the other way: from two
decompositions $a = bq + r = bq' + r'$ it derives $b \mid (r' - r)$ with
$0 \le r' - r < b$, forcing $r' - r = 0$. Both directions need one arithmetic
fact the book takes for granted — a product of nonnegatives is nonnegative —
proved in the library by induction on the second factor (base $b\cdot 0 = 0$;
step $b\cdot(k+1) = b\cdot k + b$, a sum of nonnegatives).

```bpa
theorem productOfNonnegativesIsNonneg = division.productOfNonnegativesIsNonneg
```

The second fact is the one Judson invokes when he writes "$b \mid (r' - r)$ and
$0 \le r' - r < b$ is possible only if $r' - r = 0$." A nonnegative multiple of
$b$ that lies strictly less_than $b$ must be zero. Writing the multiple as $m = bk$,
the library splits on the sign of $k$. If $k = 0$ then $m = 0$ directly. If $k >
0$ then $k = d + 1$ for a nonnegative $d$, so $m = bk = bd + b$; but $m < b$ then
forces $bd < 0$, impossible since $bd$ is a product of nonnegatives. If $k < 0$
then $-m = b(-k)$ is a product of nonnegatives, so $m \le 0$; with $m \ge 0$ that
pins $m = 0$.

```bpa
theorem boundedNonnegMultipleIsZero = division.boundedNonnegMultipleIsZero
```

Judson also uses, at the very end of uniqueness, that $b > 0$ cancels: from
$bq = bq'$ one reads off $q = q'$. The library isolates the fact behind that
cancellation: a positive times a positive is positive, and therefore a positive
times a factor that is *not* zero cannot be zero — so $bz = 0$ with $b > 0$
forces $z = 0$.

```bpa
theorem positiveFactorZeroForcesZero = division.positiveFactorZeroForcesZero
```

### Uniqueness

Judson's uniqueness argument compares two decompositions $a = bq + r = bq' + r'$.
Subtracting, $b(q - q') = r' - r$, so $b \mid (r' - r)$; and since $0 \le r, r' <
b$ the difference $r' - r$ lies strictly between $-b$ and $b$. A divisor's
multiple that small must be $0$, so $r = r'$ and then $bq = bq'$ gives $q = q'$.

The remainders must agree first: trichotomy on $r_1$ versus $r_2$ makes each
strict case a bounded multiple of $b$, which the packaging lemma forbids. That is
`remaindersEqual`; the full uniqueness theorem then substitutes $r_2 = r_1$,
cancels the common remainder to get $bq_1 = bq_2$, rewrites it as
$b(q_1 - q_2) = 0$, and reads off $q_1 = q_2$ because a positive $b$ cannot
annihilate.

```bpa
theorem remaindersEqual: forall b, q1, r1, q2, r2: Int;
  less_than(ZERO, b) -> is_nonneg(r1) -> less_than(r1, b) -> is_nonneg(r2) -> less_than(r2, b) ->
  add(mul(b, q1), r1) = add(mul(b, q2), r2) -> r1 = r2
proof
  @generalize-b |
    fix b: Int {
      @generalize-q1 |
        fix q1: Int {
          @generalize-r1 |
            fix r1: Int {
              @generalize-q2 |
                fix q2: Int {
                  @generalize-r2 |
                    fix r2: Int {
                      @given-b-positive |
                        assume less_than(ZERO, b) {
                          @given-r1-nonneg |
                            assume is_nonneg(r1) {
                              @given-r1-less_than-b |
                                assume less_than(r1, b) {
                                  @given-r2-nonneg |
                                    assume is_nonneg(r2) {
                                      @given-r2-less_than-b |
                                        assume less_than(r2, b) {
                                          @given-decompositions-equal |
                                            assume add(mul(b, q1), r1) = add(mul(b, q2), r2) {
                                              @b-positive |
                                                less_than(ZERO, b)
                                                [by hypothesis given-b-positive]
                                              @r1-nonneg |
                                                is_nonneg(r1)
                                                [by hypothesis given-r1-nonneg]
                                              @r1-less_than-b |
                                                less_than(r1, b)
                                                [by hypothesis given-r1-less_than-b]
                                              @r2-nonneg |
                                                is_nonneg(r2)
                                                [by hypothesis given-r2-nonneg]
                                              @r2-less_than-b |
                                                less_than(r2, b)
                                                [by hypothesis given-r2-less_than-b]
                                              @decompositions-equal |
                                                add(mul(b, q1), r1) = add(mul(b, q2), r2)
                                                [by hypothesis given-decompositions-equal]
                                              @difference-is-zero-forces-equal |
                                                forall x, y: Int; add(sub(x, y), y) = x
                                                [by theorem subAddCancel]
                                              @zero-prefix-is-identity |
                                                forall n: Int; add(ZERO, n) = n
                                                [by axiom addZeroLeft]
                                              @remainders-trichotomous |
                                                forall x, y: Int; less_than(x, y) or x = y or less_than(y, x)
                                                [by theorem trichotomy]
                                              @r1-r2-trichotomy |
                                                less_than(r1, r2) or r1 = r2 or less_than(r2, r1)
                                                [by forall_elim(r1, r2) remainders-trichotomous]
                                              @difference-is-multiple |
                                                forall bb, x1, s1, x2, s2: Int; add(mul(bb, x1), s1) = add(mul(bb, x2), s2) -> sub(s2, s1) = mul(bb, sub(x1, x2))
                                                [by theorem remainderDifferenceIsMultiple]
                                              @bounded-difference-zero |
                                                forall bb, s, t: Int; less_than(ZERO, bb) -> is_nonneg(s) -> less_than(t, bb) -> less_than(s, t) -> does_divide(bb, sub(t, s)) -> sub(t, s) = ZERO
                                                [by theorem boundedRemainderDifferenceIsZero]
                                              @conclusion-remainders-equal |
                                                r1 = r2
                                                case r1-r2-trichotomy {
                                                  @when-r1-less_than-r2 |
                                                    assume less_than(r1, r2) {
                                                      @r1-less_than-r2 |
                                                        less_than(r1, r2)
                                                        [by hypothesis when-r1-less_than-r2]
                                                      // sub(r2,r1) = b*(q1-q2), so b | sub(r2,r1).
                                                      @r2-minus-r1-is-multiple |
                                                        add(mul(b, q1), r1) = add(mul(b, q2), r2) -> sub(r2, r1) = mul(b, sub(q1, q2))
                                                        [by forall_elim(b, q1, r1, q2, r2) difference-is-multiple]
                                                      @r2-minus-r1-multiple |
                                                        sub(r2, r1) = mul(b, sub(q1, q2))
                                                        [by modus_ponens r2-minus-r1-is-multiple decompositions-equal]
                                                      @b-divides-r2-minus-r1 |
                                                        does_divide(b, sub(r2, r1))
                                                        [by exists_intro(sub(q1, q2)) r2-minus-r1-multiple]
                                                      @r2-minus-r1-zero-if |
                                                        less_than(ZERO, b) -> is_nonneg(r1) -> less_than(r2, b) -> less_than(r1, r2) -> does_divide(b, sub(r2, r1)) -> sub(r2, r1) = ZERO
                                                        [by forall_elim(b, r1, r2) bounded-difference-zero]
                                                      @r2-minus-r1-zero |
                                                        sub(r2, r1) = ZERO
                                                        [by tautology r2-minus-r1-zero-if b-positive r1-nonneg r2-less_than-b r1-less_than-r2 b-divides-r2-minus-r1]
                                                      // sub(r2,r1)=0 gives r2 = r1.
                                                      @difference-plus-r1-is-r2 |
                                                        add(sub(r2, r1), r1) = r2
                                                        [by forall_elim(r2, r1) difference-is-zero-forces-equal]
                                                      @zero-plus-r1-is-r2 |
                                                        add(ZERO, r1) = r2
                                                        [by rewrite r2-minus-r1-zero difference-plus-r1-is-r2]
                                                      @zero-plus-r1-is-r1 |
                                                        add(ZERO, r1) = r1
                                                        [by forall_elim(r1) zero-prefix-is-identity]
                                                      @conclusion-remainders-equal |
                                                        r1 = r2
                                                        [by rewrite zero-plus-r1-is-r1 zero-plus-r1-is-r2]
                                                    }
                                                  @when-remainders-equal |
                                                    assume r1 = r2 {
                                                      @conclusion-remainders-equal |
                                                        r1 = r2
                                                        [by hypothesis when-remainders-equal]
                                                    }
                                                  @when-r2-less_than-r1 |
                                                    assume less_than(r2, r1) {
                                                      @r2-less_than-r1 |
                                                        less_than(r2, r1)
                                                        [by hypothesis when-r2-less_than-r1]
                                                      // flip the equation; sub(r1,r2) = b*(q2-q1).
                                                      @decompositions-equal-flipped |
                                                        add(mul(b, q2), r2) = add(mul(b, q1), r1)
                                                        [by symmetry decompositions-equal]
                                                      @r1-minus-r2-is-multiple |
                                                        add(mul(b, q2), r2) = add(mul(b, q1), r1) -> sub(r1, r2) = mul(b, sub(q2, q1))
                                                        [by forall_elim(b, q2, r2, q1, r1) difference-is-multiple]
                                                      @r1-minus-r2-multiple |
                                                        sub(r1, r2) = mul(b, sub(q2, q1))
                                                        [by modus_ponens r1-minus-r2-is-multiple decompositions-equal-flipped]
                                                      @b-divides-r1-minus-r2 |
                                                        does_divide(b, sub(r1, r2))
                                                        [by exists_intro(sub(q2, q1)) r1-minus-r2-multiple]
                                                      @r1-minus-r2-zero-if |
                                                        less_than(ZERO, b) -> is_nonneg(r2) -> less_than(r1, b) -> less_than(r2, r1) -> does_divide(b, sub(r1, r2)) -> sub(r1, r2) = ZERO
                                                        [by forall_elim(b, r2, r1) bounded-difference-zero]
                                                      @r1-minus-r2-zero |
                                                        sub(r1, r2) = ZERO
                                                        [by tautology r1-minus-r2-zero-if b-positive r2-nonneg r1-less_than-b r2-less_than-r1 b-divides-r1-minus-r2]
                                                      @difference-plus-r2-is-r1 |
                                                        add(sub(r1, r2), r2) = r1
                                                        [by forall_elim(r1, r2) difference-is-zero-forces-equal]
                                                      @zero-plus-r2-is-r1 |
                                                        add(ZERO, r2) = r1
                                                        [by rewrite r1-minus-r2-zero difference-plus-r2-is-r1]
                                                      @zero-plus-r2-is-r2 |
                                                        add(ZERO, r2) = r2
                                                        [by forall_elim(r2) zero-prefix-is-identity]
                                                      @r2-is-r1 |
                                                        r2 = r1
                                                        [by rewrite zero-plus-r2-is-r2 zero-plus-r2-is-r1]
                                                      @conclusion-remainders-equal |
                                                        r1 = r2
                                                        [by symmetry r2-is-r1]
                                                    }
                                                }
                                            }
                                          @decompositions-equal-implies |
                                            add(mul(b, q1), r1) = add(mul(b, q2), r2) -> r1 = r2
                                            [by implies_intro given-decompositions-equal]
                                        }
                                      @r2-less_than-b-implies |
                                        less_than(r2, b) -> add(mul(b, q1), r1) = add(mul(b, q2), r2) -> r1 = r2
                                        [by implies_intro given-r2-less_than-b]
                                    }
                                  @r2-nonneg-implies |
                                    is_nonneg(r2) -> less_than(r2, b) -> add(mul(b, q1), r1) = add(mul(b, q2), r2) -> r1 = r2
                                    [by implies_intro given-r2-nonneg]
                                }
                              @r1-less_than-b-implies |
                                less_than(r1, b) -> is_nonneg(r2) -> less_than(r2, b) -> add(mul(b, q1), r1) = add(mul(b, q2), r2) -> r1 = r2
                                [by implies_intro given-r1-less_than-b]
                            }
                          @r1-nonneg-implies |
                            is_nonneg(r1) -> less_than(r1, b) -> is_nonneg(r2) -> less_than(r2, b) -> add(mul(b, q1), r1) = add(mul(b, q2), r2) -> r1 = r2
                            [by implies_intro given-r1-nonneg]
                        }
                      @b-positive-implies |
                        less_than(ZERO, b) -> is_nonneg(r1) -> less_than(r1, b) -> is_nonneg(r2) -> less_than(r2, b) -> add(mul(b, q1), r1) = add(mul(b, q2), r2) -> r1 = r2
                        [by implies_intro given-b-positive]
                    }
                  @discharge-r2 |
                    forall r2: Int; less_than(ZERO, b) -> is_nonneg(r1) -> less_than(r1, b) -> is_nonneg(r2) -> less_than(r2, b) -> add(mul(b, q1), r1) = add(mul(b, q2), r2) -> r1 = r2
                    [by forall_intro generalize-r2]
                }
              @discharge-q2 |
                forall q2, r2: Int; less_than(ZERO, b) -> is_nonneg(r1) -> less_than(r1, b) -> is_nonneg(r2) -> less_than(r2, b) -> add(mul(b, q1), r1) = add(mul(b, q2), r2) -> r1 = r2
                [by forall_intro generalize-q2]
            }
          @discharge-r1 |
            forall r1, q2, r2: Int; less_than(ZERO, b) -> is_nonneg(r1) -> less_than(r1, b) -> is_nonneg(r2) -> less_than(r2, b) -> add(mul(b, q1), r1) = add(mul(b, q2), r2) -> r1 = r2
            [by forall_intro generalize-r1]
        }
      @discharge-q1 |
        forall q1, r1, q2, r2: Int; less_than(ZERO, b) -> is_nonneg(r1) -> less_than(r1, b) -> is_nonneg(r2) -> less_than(r2, b) -> add(mul(b, q1), r1) = add(mul(b, q2), r2) -> r1 = r2
        [by forall_intro generalize-q1]
    }
  @conclusion |
    forall b, q1, r1, q2, r2: Int; less_than(ZERO, b) -> is_nonneg(r1) -> less_than(r1, b) -> is_nonneg(r2) -> less_than(r2, b) -> add(mul(b, q1), r1) = add(mul(b, q2), r2) -> r1 = r2
    [by forall_intro generalize-b]
qed

theorem divisionAlgorithmUnique: forall a, b, q1, r1, q2, r2: Int;
  less_than(ZERO, b) ->
  a = add(mul(b, q1), r1) -> is_nonneg(r1) -> less_than(r1, b) ->
  a = add(mul(b, q2), r2) -> is_nonneg(r2) -> less_than(r2, b) ->
  (q1 = q2 and r1 = r2)
proof
  @generalize-a |
    fix a: Int {
      @generalize-b |
        fix b: Int {
          @generalize-q1 |
            fix q1: Int {
              @generalize-r1 |
                fix r1: Int {
                  @generalize-q2 |
                    fix q2: Int {
                      @generalize-r2 |
                        fix r2: Int {
                          @given-b-positive |
                            assume less_than(ZERO, b) {
                              @given-first-decomposition |
                                assume a = add(mul(b, q1), r1) {
                                  @given-r1-nonneg |
                                    assume is_nonneg(r1) {
                                      @given-r1-less_than-b |
                                        assume less_than(r1, b) {
                                          @given-second-decomposition |
                                            assume a = add(mul(b, q2), r2) {
                                              @given-r2-nonneg |
                                                assume is_nonneg(r2) {
                                                  @given-r2-less_than-b |
                                                    assume less_than(r2, b) {
                                                      @b-positive |
                                                        less_than(ZERO, b)
                                                        [by hypothesis given-b-positive]
                                                      @first-decomposition |
                                                        a = add(mul(b, q1), r1)
                                                        [by hypothesis given-first-decomposition]
                                                      @r1-nonneg |
                                                        is_nonneg(r1)
                                                        [by hypothesis given-r1-nonneg]
                                                      @r1-less_than-b |
                                                        less_than(r1, b)
                                                        [by hypothesis given-r1-less_than-b]
                                                      @second-decomposition |
                                                        a = add(mul(b, q2), r2)
                                                        [by hypothesis given-second-decomposition]
                                                      @r2-nonneg |
                                                        is_nonneg(r2)
                                                        [by hypothesis given-r2-nonneg]
                                                      @r2-less_than-b |
                                                        less_than(r2, b)
                                                        [by hypothesis given-r2-less_than-b]
                                                      // the two decompositions of a coincide.
                                                      @first-decomposition-flipped |
                                                        add(mul(b, q1), r1) = a
                                                        [by symmetry first-decomposition]
                                                      @decompositions-equal |
                                                        add(mul(b, q1), r1) = add(mul(b, q2), r2)
                                                        [by rewrite second-decomposition first-decomposition-flipped]
                                                      // remainders agree.
                                                      @remainders-are-equal |
                                                        forall bb, x1, s1, x2, s2: Int; less_than(ZERO, bb) -> is_nonneg(s1) -> less_than(s1, bb) -> is_nonneg(s2) -> less_than(s2, bb) -> add(mul(bb, x1), s1) = add(mul(bb, x2), s2) -> s1 = s2
                                                        [by theorem remaindersEqual]
                                                      @remainders-equal-if |
                                                        less_than(ZERO, b) -> is_nonneg(r1) -> less_than(r1, b) -> is_nonneg(r2) -> less_than(r2, b) -> add(mul(b, q1), r1) = add(mul(b, q2), r2) -> r1 = r2
                                                        [by forall_elim(b, q1, r1, q2, r2) remainders-are-equal]
                                                      @remainders-equal |
                                                        r1 = r2
                                                        [by tautology remainders-equal-if b-positive r1-nonneg r1-less_than-b r2-nonneg r2-less_than-b decompositions-equal]
                                                      // substitute r2 = r1 and cancel the common remainder.
                                                      @r2-is-r1 |
                                                        r2 = r1
                                                        [by symmetry remainders-equal]
                                                      @decompositions-equal-same-remainder |
                                                        add(mul(b, q1), r1) = add(mul(b, q2), r1)
                                                        [by rewrite r2-is-r1 decompositions-equal]
                                                      @addition-commutes |
                                                        forall u, v: Int; add(u, v) = add(v, u)
                                                        [by theorem addIsCommutative]
                                                      @left-commuted |
                                                        add(mul(b, q1), r1) = add(r1, mul(b, q1))
                                                        [by forall_elim(mul(b, q1), r1) addition-commutes]
                                                      @right-commuted |
                                                        add(mul(b, q2), r1) = add(r1, mul(b, q2))
                                                        [by forall_elim(mul(b, q2), r1) addition-commutes]
                                                      @remainder-prefixed-equal-partial |
                                                        add(r1, mul(b, q1)) = add(mul(b, q2), r1)
                                                        [by rewrite left-commuted decompositions-equal-same-remainder]
                                                      @remainder-prefixed-equal |
                                                        add(r1, mul(b, q1)) = add(r1, mul(b, q2))
                                                        [by rewrite right-commuted remainder-prefixed-equal-partial]
                                                      @cancel-remainder-on-left |
                                                        forall c, u, v: Int; add(c, u) = add(c, v) -> u = v
                                                        [by theorem addCancelLeft]
                                                      @products-equal-if-cancel |
                                                        add(r1, mul(b, q1)) = add(r1, mul(b, q2)) -> mul(b, q1) = mul(b, q2)
                                                        [by forall_elim(r1, mul(b, q1), mul(b, q2)) cancel-remainder-on-left]
                                                      @products-equal |
                                                        mul(b, q1) = mul(b, q2)
                                                        [by modus_ponens products-equal-if-cancel remainder-prefixed-equal]
                                                      // b*(q1-q2) = bq1 - bq2 = 0.
                                                      @distributes |
                                                        forall bb, x, y: Int; mul(bb, sub(x, y)) = sub(mul(bb, x), mul(bb, y))
                                                        [by theorem distributesOverDifference]
                                                      @product-of-quotient-difference |
                                                        mul(b, sub(q1, q2)) = sub(mul(b, q1), mul(b, q2))
                                                        [by forall_elim(b, q1, q2) distributes]
                                                      @products-difference-reflexive |
                                                        sub(mul(b, q1), mul(b, q2)) = sub(mul(b, q1), mul(b, q2))
                                                        [by reflexivity]
                                                      @products-equal-flipped |
                                                        mul(b, q2) = mul(b, q1)
                                                        [by symmetry products-equal]
                                                      @difference-of-equal-products |
                                                        sub(mul(b, q1), mul(b, q2)) = sub(mul(b, q1), mul(b, q1))
                                                        [by rewrite products-equal-flipped products-difference-reflexive]
                                                      @self-difference-is-zero |
                                                        forall n: Int; sub(n, n) = ZERO
                                                        [by theorem subSelf]
                                                      @product-self-difference-zero |
                                                        sub(mul(b, q1), mul(b, q1)) = ZERO
                                                        [by forall_elim(mul(b, q1)) self-difference-is-zero]
                                                      @products-difference-zero |
                                                        sub(mul(b, q1), mul(b, q2)) = ZERO
                                                        [by rewrite product-self-difference-zero difference-of-equal-products]
                                                      @quotient-difference-times-b-zero |
                                                        mul(b, sub(q1, q2)) = ZERO
                                                        [by rewrite products-difference-zero product-of-quotient-difference]
                                                      // b > 0 forces the factor sub(q1,q2) to be 0.
                                                      @positive-factor-zero |
                                                        forall bb, zz: Int; less_than(ZERO, bb) -> mul(bb, zz) = ZERO -> zz = ZERO
                                                        [by theorem positiveFactorZeroForcesZero]
                                                      @quotient-difference-zero-if |
                                                        less_than(ZERO, b) -> mul(b, sub(q1, q2)) = ZERO -> sub(q1, q2) = ZERO
                                                        [by forall_elim(b, sub(q1, q2)) positive-factor-zero]
                                                      @quotient-difference-zero |
                                                        sub(q1, q2) = ZERO
                                                        [by tautology quotient-difference-zero-if b-positive quotient-difference-times-b-zero]
                                                      // sub(q1,q2)=0 gives q1 = q2.
                                                      @difference-plus-q2-reaches-q1 |
                                                        forall x, y: Int; add(sub(x, y), y) = x
                                                        [by theorem subAddCancel]
                                                      @difference-plus-q2-is-q1 |
                                                        add(sub(q1, q2), q2) = q1
                                                        [by forall_elim(q1, q2) difference-plus-q2-reaches-q1]
                                                      @zero-plus-q2-is-q1 |
                                                        add(ZERO, q2) = q1
                                                        [by rewrite quotient-difference-zero difference-plus-q2-is-q1]
                                                      @zero-prefix-is-identity |
                                                        forall n: Int; add(ZERO, n) = n
                                                        [by axiom addZeroLeft]
                                                      @zero-plus-q2-is-q2 |
                                                        add(ZERO, q2) = q2
                                                        [by forall_elim(q2) zero-prefix-is-identity]
                                                      @q2-is-q1 |
                                                        q2 = q1
                                                        [by rewrite zero-plus-q2-is-q2 zero-plus-q2-is-q1]
                                                      @quotients-equal |
                                                        q1 = q2
                                                        [by symmetry q2-is-q1]
                                                      @conclusion-unique |
                                                        q1 = q2 and r1 = r2
                                                        [by and_intro quotients-equal remainders-equal]
                                                    }
                                                  @r2-less_than-b-implies |
                                                    less_than(r2, b) -> (q1 = q2 and r1 = r2)
                                                    [by implies_intro given-r2-less_than-b]
                                                }
                                              @r2-nonneg-implies |
                                                is_nonneg(r2) -> less_than(r2, b) -> (q1 = q2 and r1 = r2)
                                                [by implies_intro given-r2-nonneg]
                                            }
                                          @second-decomposition-implies |
                                            a = add(mul(b, q2), r2) -> is_nonneg(r2) -> less_than(r2, b) -> (q1 = q2 and r1 = r2)
                                            [by implies_intro given-second-decomposition]
                                        }
                                      @r1-less_than-b-implies |
                                        less_than(r1, b) -> a = add(mul(b, q2), r2) -> is_nonneg(r2) -> less_than(r2, b) -> (q1 = q2 and r1 = r2)
                                        [by implies_intro given-r1-less_than-b]
                                    }
                                  @r1-nonneg-implies |
                                    is_nonneg(r1) -> less_than(r1, b) -> a = add(mul(b, q2), r2) -> is_nonneg(r2) -> less_than(r2, b) -> (q1 = q2 and r1 = r2)
                                    [by implies_intro given-r1-nonneg]
                                }
                              @first-decomposition-implies |
                                a = add(mul(b, q1), r1) -> is_nonneg(r1) -> less_than(r1, b) -> a = add(mul(b, q2), r2) -> is_nonneg(r2) -> less_than(r2, b) -> (q1 = q2 and r1 = r2)
                                [by implies_intro given-first-decomposition]
                            }
                          @b-positive-implies |
                            less_than(ZERO, b) -> a = add(mul(b, q1), r1) -> is_nonneg(r1) -> less_than(r1, b) -> a = add(mul(b, q2), r2) -> is_nonneg(r2) -> less_than(r2, b) -> (q1 = q2 and r1 = r2)
                            [by implies_intro given-b-positive]
                        }
                      @discharge-r2 |
                        forall r2: Int; less_than(ZERO, b) -> a = add(mul(b, q1), r1) -> is_nonneg(r1) -> less_than(r1, b) -> a = add(mul(b, q2), r2) -> is_nonneg(r2) -> less_than(r2, b) -> (q1 = q2 and r1 = r2)
                        [by forall_intro generalize-r2]
                    }
                  @discharge-q2 |
                    forall q2, r2: Int; less_than(ZERO, b) -> a = add(mul(b, q1), r1) -> is_nonneg(r1) -> less_than(r1, b) -> a = add(mul(b, q2), r2) -> is_nonneg(r2) -> less_than(r2, b) -> (q1 = q2 and r1 = r2)
                    [by forall_intro generalize-q2]
                }
              @discharge-r1 |
                forall r1, q2, r2: Int; less_than(ZERO, b) -> a = add(mul(b, q1), r1) -> is_nonneg(r1) -> less_than(r1, b) -> a = add(mul(b, q2), r2) -> is_nonneg(r2) -> less_than(r2, b) -> (q1 = q2 and r1 = r2)
                [by forall_intro generalize-r1]
            }
          @discharge-q1 |
            forall q1, r1, q2, r2: Int; less_than(ZERO, b) -> a = add(mul(b, q1), r1) -> is_nonneg(r1) -> less_than(r1, b) -> a = add(mul(b, q2), r2) -> is_nonneg(r2) -> less_than(r2, b) -> (q1 = q2 and r1 = r2)
            [by forall_intro generalize-q1]
        }
      @discharge-b |
        forall b, q1, r1, q2, r2: Int; less_than(ZERO, b) -> a = add(mul(b, q1), r1) -> is_nonneg(r1) -> less_than(r1, b) -> a = add(mul(b, q2), r2) -> is_nonneg(r2) -> less_than(r2, b) -> (q1 = q2 and r1 = r2)
        [by forall_intro generalize-b]
    }
  @conclusion |
    forall a, b, q1, r1, q2, r2: Int; less_than(ZERO, b) -> a = add(mul(b, q1), r1) -> is_nonneg(r1) -> less_than(r1, b) -> a = add(mul(b, q2), r2) -> is_nonneg(r2) -> less_than(r2, b) -> (q1 = q2 and r1 = r2)
    [by forall_intro generalize-a]
qed
```

### Existence

For existence Judson invokes Well-Ordering on the set $S = \{\, a - bk : k \in
\mathbb Z,\ a - bk \ge 0 \,\}$. Its least member $r = a - bq$ satisfies $a = bq +
r$ with $r \ge 0$; and $r < b$, for otherwise $a - b(q+1) = r - b$ would be a
smaller nonnegative member. Nonemptiness is where the sign of $a$ enters, and
Judson splits on it: if $a \ge 0$ the witness $k = 0$ gives the member
$a - b\cdot 0 = a \ge 0$; if $a < 0$ the witness $k = 2a$ gives the member
$a - b(2a) = a(1 - 2b)$, a product of two nonpositive factors ($a < 0$, and
$1 - 2b < 0$ because $b > 0$ forces $2b \ge 2 > 1$), hence $\ge 0$. We reproduce
that split explicitly; the factorisation $a - b(2a) = a(1 - 2b)$ is the only
elided ring algebra (a `simplify`). The classical least-element instance for
$S_{a,b} = \{\, x : x = a - bk \text{ for some } k \,\}$ is `remainderSetHasLeast`,
proved directly from strong induction.

```bpa
theorem remainderSetHasLeast: forall a, b: Int;
  (exists n: Int; is_nonneg(n) and (exists k: Int; n = sub(a, mul(b, k))))
  -> exists least: Int; is_nonneg(least) and (exists k: Int; least = sub(a, mul(b, k))) and (forall m: Int; is_nonneg(m) -> (exists k: Int; m = sub(a, mul(b, k))) -> at_most(least, m))
proof
  @generalize-a |
    fix a: Int {
      @generalize-b |
        fix b: Int {
          @given-inhabited |
            assume exists n: Int; is_nonneg(n) and (exists k: Int; n = sub(a, mul(b, k))) {
              @some-nonneg-element-is-a-member |
                exists n: Int; is_nonneg(n) and (exists k: Int; n = sub(a, mul(b, k)))
                [by hypothesis given-inhabited]
              @given-no-least |
                assume not (exists least: Int; is_nonneg(least) and (exists k: Int; least = sub(a, mul(b, k))) and (forall m: Int; is_nonneg(m) -> (exists k: Int; m = sub(a, mul(b, k))) -> at_most(least, m))) {
                  @no-least |
                    not (exists least: Int; is_nonneg(least) and (exists k: Int; least = sub(a, mul(b, k))) and (forall m: Int; is_nonneg(m) -> (exists k: Int; m = sub(a, mul(b, k))) -> at_most(least, m)))
                    [by hypothesis given-no-least]
                  @strong-step |
                    fix n: Int {
                      @given-n-nonneg |
                        assume is_nonneg(n) {
                          @n-nonneg |
                            is_nonneg(n)
                            [by hypothesis given-n-nonneg]
                          @given-all-less_than-fail |
                            assume forall m: Int; is_nonneg(m) -> less_than(m, n) -> (not (exists k: Int; m = sub(a, mul(b, k)))) {
                              @all-less_than-fail |
                                forall m: Int; is_nonneg(m) -> less_than(m, n) -> (not (exists k: Int; m = sub(a, mul(b, k))))
                                [by hypothesis given-all-less_than-fail]
                              @given-n-is-member |
                                assume exists k: Int; n = sub(a, mul(b, k)) {
                                  @n-is-member |
                                    exists k: Int; n = sub(a, mul(b, k))
                                    [by hypothesis given-n-is-member]
                                  @n-is-lower-bound |
                                    fix m: Int {
                                      @given-m-nonneg |
                                        assume is_nonneg(m) {
                                          @m-nonneg |
                                            is_nonneg(m)
                                            [by hypothesis given-m-nonneg]
                                          @given-m-is-member |
                                            assume exists k: Int; m = sub(a, mul(b, k)) {
                                              @m-is-member |
                                                exists k: Int; m = sub(a, mul(b, k))
                                                [by hypothesis given-m-is-member]
                                              @trichotomy-n-m |
                                                forall x, y: Int; less_than(x, y) or x = y or less_than(y, x)
                                                [by theorem trichotomy]
                                              @order-n-m |
                                                less_than(n, m) or n = m or less_than(m, n)
                                                [by forall_elim(n, m) trichotomy-n-m]
                                              @n-at-most-m |
                                                at_most(n, m)
                                                case order-n-m {
                                                  @when-n-less_than-m |
                                                    assume less_than(n, m) {
                                                      @n-less_than-m |
                                                        less_than(n, m)
                                                        [by hypothesis when-n-less_than-m]
                                                      @less-than-to-at-most |
                                                        forall x, y: Int; less_than(x, y) -> at_most(x, y)
                                                        [by theorem lessThanToLessOrEqual]
                                                      @n-at-most-m-if-less_than |
                                                        less_than(n, m) -> at_most(n, m)
                                                        [by forall_elim(n, m) less-than-to-at-most]
                                                      @conclusion-n-at-most-m |
                                                        at_most(n, m)
                                                        [by modus_ponens n-at-most-m-if-less_than n-less_than-m]
                                                    }
                                                  @when-n-equals-m |
                                                    assume n = m {
                                                      @n-equals-m |
                                                        n = m
                                                        [by hypothesis when-n-equals-m]
                                                      @at-most-reflexive |
                                                        forall x: Int; at_most(x, x)
                                                        [by theorem lessOrEqualRefl]
                                                      @n-at-most-n |
                                                        at_most(n, n)
                                                        [by forall_elim(n) at-most-reflexive]
                                                      @conclusion-n-at-most-m |
                                                        at_most(n, m)
                                                        [by rewrite n-equals-m n-at-most-n]
                                                    }
                                                  @when-m-less_than-n |
                                                    assume less_than(m, n) {
                                                      @m-less_than-n |
                                                        less_than(m, n)
                                                        [by hypothesis when-m-less_than-n]
                                                      @m-fails-if-nonneg-less_than-n |
                                                        is_nonneg(m) -> less_than(m, n) -> (not (exists k: Int; m = sub(a, mul(b, k))))
                                                        [by forall_elim(m) all-less_than-fail]
                                                      @m-is-not-member |
                                                        not (exists k: Int; m = sub(a, mul(b, k)))
                                                        [by tautology m-fails-if-nonneg-less_than-n m-nonneg m-less_than-n]
                                                      @conclusion-n-at-most-m |
                                                        at_most(n, m)
                                                        [by absurd m-is-member m-is-not-member]
                                                    }
                                                }
                                            }
                                          @m-member-implies-bound |
                                            (exists k: Int; m = sub(a, mul(b, k))) -> at_most(n, m)
                                            [by implies_intro given-m-is-member]
                                        }
                                      @m-nonneg-implies-bound |
                                        is_nonneg(m) -> (exists k: Int; m = sub(a, mul(b, k))) -> at_most(n, m)
                                        [by implies_intro given-m-nonneg]
                                    }
                                  @n-is-lower-bound-forall |
                                    forall m: Int; is_nonneg(m) -> (exists k: Int; m = sub(a, mul(b, k))) -> at_most(n, m)
                                    [by forall_intro n-is-lower-bound]
                                  @n-nonneg-and-member |
                                    is_nonneg(n) and (exists k: Int; n = sub(a, mul(b, k)))
                                    [by and_intro n-nonneg n-is-member]
                                  @n-is-least |
                                    is_nonneg(n) and (exists k: Int; n = sub(a, mul(b, k))) and (forall m: Int; is_nonneg(m) -> (exists k: Int; m = sub(a, mul(b, k))) -> at_most(n, m))
                                    [by and_intro n-nonneg-and-member n-is-lower-bound-forall]
                                  @least-exists |
                                    exists least: Int; is_nonneg(least) and (exists k: Int; least = sub(a, mul(b, k))) and (forall m: Int; is_nonneg(m) -> (exists k: Int; m = sub(a, mul(b, k))) -> at_most(least, m))
                                    [by exists_intro(n) n-is-least]
                                  @contradiction-from-n |
                                    not (exists k: Int; n = sub(a, mul(b, k)))
                                    [by absurd least-exists no-least]
                                }
                              @n-member-implies-not-member |
                                (exists k: Int; n = sub(a, mul(b, k))) -> (not (exists k: Int; n = sub(a, mul(b, k))))
                                [by implies_intro given-n-is-member]
                              @n-is-not-member |
                                not (exists k: Int; n = sub(a, mul(b, k)))
                                [by tautology n-member-implies-not-member]
                            }
                          @all-less_than-fail-implies-n-fails |
                            (forall m: Int; is_nonneg(m) -> less_than(m, n) -> (not (exists k: Int; m = sub(a, mul(b, k))))) -> (not (exists k: Int; n = sub(a, mul(b, k))))
                            [by implies_intro given-all-less_than-fail]
                        }
                      @strong-step-at-n |
                        is_nonneg(n) -> (forall m: Int; is_nonneg(m) -> less_than(m, n) -> (not (exists k: Int; m = sub(a, mul(b, k))))) -> (not (exists k: Int; n = sub(a, mul(b, k))))
                        [by implies_intro given-n-nonneg]
                    }
                  @strong-step-forall |
                    forall n: Int; is_nonneg(n) -> (forall m: Int; is_nonneg(m) -> less_than(m, n) -> (not (exists k: Int; m = sub(a, mul(b, k))))) -> (not (exists k: Int; n = sub(a, mul(b, k))))
                    [by forall_intro strong-step]
                  @nothing-nonneg-is-member |
                    forall n: Int; is_nonneg(n) -> (not (exists k: Int; n = sub(a, mul(b, k))))
                    [by instantiate nonnegStrongInduction((fun j: Int => not (exists k: Int; j = sub(a, mul(b, k))))) strong-step-forall]
                  @with-witness |
                    unpack w: Int from some-nonneg-element-is-a-member {
                      @witness-nonneg-and-member |
                        is_nonneg(w) and (exists k: Int; w = sub(a, mul(b, k)))
                        [by hypothesis with-witness]
                      @witness-nonneg |
                        is_nonneg(w)
                        [by and_elim_left witness-nonneg-and-member]
                      @witness-is-member |
                        exists k: Int; w = sub(a, mul(b, k))
                        [by and_elim_right witness-nonneg-and-member]
                      @witness-not-member-if-nonneg |
                        is_nonneg(w) -> (not (exists k: Int; w = sub(a, mul(b, k))))
                        [by forall_elim(w) nothing-nonneg-is-member]
                      @witness-not-member |
                        not (exists k: Int; w = sub(a, mul(b, k)))
                        [by modus_ponens witness-not-member-if-nonneg witness-nonneg]
                      @contradiction |
                        exists least: Int; is_nonneg(least) and (exists k: Int; least = sub(a, mul(b, k))) and (forall m: Int; is_nonneg(m) -> (exists k: Int; m = sub(a, mul(b, k))) -> at_most(least, m))
                        [by absurd witness-is-member witness-not-member]
                    }
                  @least-exists-from-witness |
                    exists least: Int; is_nonneg(least) and (exists k: Int; least = sub(a, mul(b, k))) and (forall m: Int; is_nonneg(m) -> (exists k: Int; m = sub(a, mul(b, k))) -> at_most(least, m))
                    [by exists_elim with-witness]
                }
              @least-exists-not-absent |
                not not (exists least: Int; is_nonneg(least) and (exists k: Int; least = sub(a, mul(b, k))) and (forall m: Int; is_nonneg(m) -> (exists k: Int; m = sub(a, mul(b, k))) -> at_most(least, m)))
                [by not_intro given-no-least least-exists-from-witness no-least]
              @least-exists-by-contradiction |
                exists least: Int; is_nonneg(least) and (exists k: Int; least = sub(a, mul(b, k))) and (forall m: Int; is_nonneg(m) -> (exists k: Int; m = sub(a, mul(b, k))) -> at_most(least, m))
                [by double_negation least-exists-not-absent]
            }
          @inhabited-implies-least |
            (exists n: Int; is_nonneg(n) and (exists k: Int; n = sub(a, mul(b, k)))) -> exists least: Int; is_nonneg(least) and (exists k: Int; least = sub(a, mul(b, k))) and (forall m: Int; is_nonneg(m) -> (exists k: Int; m = sub(a, mul(b, k))) -> at_most(least, m))
            [by implies_intro given-inhabited]
        }
      @discharge-b |
        forall b: Int; (exists n: Int; is_nonneg(n) and (exists k: Int; n = sub(a, mul(b, k)))) -> exists least: Int; is_nonneg(least) and (exists k: Int; least = sub(a, mul(b, k))) and (forall m: Int; is_nonneg(m) -> (exists k: Int; m = sub(a, mul(b, k))) -> at_most(least, m))
        [by forall_intro generalize-b]
    }
  @conclusion |
    forall a, b: Int; (exists n: Int; is_nonneg(n) and (exists k: Int; n = sub(a, mul(b, k)))) -> exists least: Int; is_nonneg(least) and (exists k: Int; least = sub(a, mul(b, k))) and (forall m: Int; is_nonneg(m) -> (exists k: Int; m = sub(a, mul(b, k))) -> at_most(least, m))
    [by forall_intro generalize-a]
qed

theorem divisionAlgorithmExists: forall a, b: Int; less_than(ZERO, b) ->
  exists q: Int; exists r: Int; a = add(mul(b, q), r) and is_nonneg(r) and less_than(r, b)
proof
  @generalize-a |
    fix a: Int {
      @generalize-b |
        fix b: Int {
          @given-b-positive |
            assume less_than(ZERO, b) {
              @b-positive |
                less_than(ZERO, b)
                [by hypothesis given-b-positive]
              @difference-reaches |
                forall w, z: Int; add(w, sub(z, w)) = z
                [by theorem addDiffReaches]
              @product-with-zero |
                forall n: Int; mul(n, ZERO) = ZERO
                [by theorem mulZeroRight]
              @subtraction-unfolds |
                forall u, v: Int; sub(u, v) = add(u, neg(v))
                [by axiom subDef]
              @negation-of-zero |
                neg(ZERO) = ZERO
                [by axiom negZero]
              @adding-zero-is-identity |
                forall n: Int; add(n, ZERO) = n
                [by theorem addZeroRight]
              @zero-prefix-is-identity |
                forall n: Int; add(ZERO, n) = n
                [by axiom addZeroLeft]
              @positive-shifts-strictly-up |
                forall x, c: Int; less_than(ZERO, c) -> less_than(x, add(x, c))
                [by theorem lessThanSelfPlusPositive]
              // S is nonempty.  Judson splits on the sign of a.  Trichotomy
              // gives a >= 0 (0 < a or a = 0) or a < 0; we produce a member
              // of S in each branch.
              @sign-trichotomy |
                forall x, y: Int; less_than(x, y) or x = y or less_than(y, x)
                [by theorem trichotomy]
              @a-sign |
                less_than(ZERO, a) or ZERO = a or less_than(a, ZERO)
                [by forall_elim(ZERO, a) sign-trichotomy]
              @less-than-elim |
                forall x, y: Int; less_than(x, y) -> exists d: Int; is_nonneg(d) and add(x, succ(d)) = y
                [by axiom lessThanElim]
              @set-is-nonempty |
                exists n: Int; is_nonneg(n) and (exists k: Int; n = sub(a, mul(b, k)))
                case a-sign {
                  @when-a-nonnegative |
                    assume less_than(ZERO, a) or ZERO = a {
                      @a-nonnegative |
                        less_than(ZERO, a) or ZERO = a
                        [by hypothesis when-a-nonnegative]
                      // a >= 0, so a itself is a nonneg member: a = a - b*0.
                      @a-nonneg |
                        is_nonneg(a)
                        case a-nonnegative {
                          @when-zero-less_than-a |
                            assume less_than(ZERO, a) {
                              @zero-less_than-a |
                                less_than(ZERO, a)
                                [by hypothesis when-zero-less_than-a]
                              // 0 < a means a = succ(d) for nonneg d, hence nonneg.
                              @gap-exists-if-less_than |
                                less_than(ZERO, a) -> exists d: Int; is_nonneg(d) and add(ZERO, succ(d)) = a
                                [by forall_elim(ZERO, a) less-than-elim]
                              @gap-exists |

                      @quotient-and-remainder-exist |
                        exists q: Int; exists r: Int; a = add(mul(b, q), r) and is_nonneg(r) and less_than(r, b)
                        [by exists_intro(quot) remainder-exists]
                    }
                  @decomposition-exists-for-remainder |
                    exists q: Int; exists r: Int; a = add(mul(b, q), r) and is_nonneg(r) and less_than(r, b)
                    [by exists_elim with-quotient-q]
                }
              @decomposition-exists |
                exists q: Int; exists r: Int; a = add(mul(b, q), r) and is_nonneg(r) and less_than(r, b)
                [by exists_elim conclusion-decomposition-exists]
            }
          @b-positive-implies-decomposition |
            less_than(ZERO, b) -> exists q: Int; exists r: Int; a = add(mul(b, q), r) and is_nonneg(r) and less_than(r, b)
            [by implies_intro given-b-positive]
        }
      @discharge-b |
        forall b: Int; less_than(ZERO, b) -> exists q: Int; exists r: Int; a = add(mul(b, q), r) and is_nonneg(r) and less_than(r, b)
        [by forall_intro generalize-b]
    }
  @conclusion |
    forall a, b: Int; less_than(ZERO, b) -> exists q: Int; exists r: Int; a = add(mul(b, q), r) and is_nonneg(r) and less_than(r, b)
    [by forall_intro generalize-a]
qed
```

Together `divisionAlgorithmExists` and `divisionAlgorithmUnique` are the
Division Algorithm: for every $a$ and every $b > 0$ there are integers $q$ and
$r$ with $a = bq + r$ and $0 \le r < b$, and they are unique.
