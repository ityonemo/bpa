# The Integers — Primes

A literate `bpa` transliteration of **Chapter 2 ("The Integers"), §2.2 (Greatest
Common Divisors and Primes)** of Thomas W. Judson's *Abstract Algebra* (source:
`vendor/aata/src/integers.xml`; © 1997–2026 Judson, GFDL 1.3). Run
`bpa check aata/2.3-primes.md`.

This section proves the **GCD / Bézout theorem** and its **coprime corollary**,
following Judson's argument. They build on the Division Algorithm proved in
`std/integer-division.bpa` (§2.2). We bring in that library, the ℤ order,
divisibility, and the Well-Ordering schema, naming the arithmetic vocabulary
this section will use. Because there is no `gcd` function, we *characterize* the
greatest common divisor by its defining properties (positive, a common divisor,
divisible by every common divisor).

A positive integer is in particular nonnegative — the fact that lets the
Well-Ordering schema's guard (`is_nonneg`) be discharged from `below(ZERO, x)`.
Unfolding `below(ZERO, x)` gives a nonnegative gap `d` with `ZERO + succ(d) = x`;
since `add(ZERO, succ(d)) = succ(d)` and the successor of a nonnegative is
nonnegative, `x` itself is nonnegative.

```bpa
theorem positiveIsNonneg: forall x: Int; below(ZERO, x) -> is_nonneg(x)
proof
  @generalize-x |
    fix x: Int {
      @given-x-positive |
        assume below(ZERO, x) {
          @x-positive |
            below(ZERO, x)
            [by hypothesis given-x-positive]
          @less-than-elim |
            forall a, b: Int; below(a, b) -> exists d: Int; is_nonneg(d) and add(a, succ(d)) = b
            [by axiom lessThanElim]
          @less-than-elim-at-zero-x |
            below(ZERO, x) -> exists d: Int; is_nonneg(d) and add(ZERO, succ(d)) = x
            [by forall_elim(ZERO, x) less-than-elim]
          @gap-exists |
            exists d: Int; is_nonneg(d) and add(ZERO, succ(d)) = x
            [by modus_ponens less-than-elim-at-zero-x x-positive]
          @with-gap-d |
            unpack d: Int from gap-exists {
              @gap-nonneg-and-sums |
                is_nonneg(d) and add(ZERO, succ(d)) = x
                [by hypothesis with-gap-d]
              @gap-nonneg |
                is_nonneg(d)
                [by and_elim_left gap-nonneg-and-sums]
              @gap-sums-to-x |
                add(ZERO, succ(d)) = x
                [by and_elim_right gap-nonneg-and-sums]
              @add-zero-left |
                forall n: Int; add(ZERO, n) = n
                [by axiom addZeroLeft]
              @zero-plus-succ-is-succ |
                add(ZERO, succ(d)) = succ(d)
                [by forall_elim(succ(d)) add-zero-left]
              @succ-gap-is-x |
                succ(d) = x
                [by rewrite zero-plus-succ-is-succ gap-sums-to-x]
              @nonneg-succ |
                forall n: Int; is_nonneg(n) -> is_nonneg(succ(n))
                [by axiom nonnegSucc]
              @succ-of-nonneg-is-nonneg |
                is_nonneg(d) -> is_nonneg(succ(d))
                [by forall_elim(d) nonneg-succ]
              @succ-gap-nonneg |
                is_nonneg(succ(d))
                [by modus_ponens succ-of-nonneg-is-nonneg gap-nonneg]
              @conclusion-x-nonneg |
                is_nonneg(x)
                [by rewrite succ-gap-is-x succ-gap-nonneg]
            }
          @x-nonneg |
            is_nonneg(x)
            [by exists_elim with-gap-d]
        }
      @positive-implies-nonneg |
        below(ZERO, x) -> is_nonneg(x)
        [by implies_intro given-x-positive]
    }
  @conclusion |
    forall x: Int; below(ZERO, x) -> is_nonneg(x)
    [by forall_intro generalize-x]
qed
```

The Bézout argument will, at its crux, learn of a remainder `r'` that is both
nonnegative and *not* positive, and must conclude `r' = ZERO`. A nonnegative
integer splits (`nonnegCases`) into `ZERO` or a successor `succ(m)` of a
nonnegative `m`; a successor is positive (`add(ZERO, succ(m)) = succ(m)`, so
`lessThanIntro` gives `below(ZERO, succ(m))`), so if the integer is *not*
positive the successor case is impossible and it must be `ZERO`.

```bpa
theorem nonnegNotPositiveIsZero: forall x: Int; is_nonneg(x) -> (not below(ZERO, x)) -> x = ZERO
proof
  @generalize-x |
    fix x: Int {
      @given-x-nonneg |
        assume is_nonneg(x) {
          @given-x-not-positive |
            assume not below(ZERO, x) {
              @x-nonneg |
                is_nonneg(x)
                [by hypothesis given-x-nonneg]
              @x-not-positive |
                not below(ZERO, x)
                [by hypothesis given-x-not-positive]
              @nonneg-cases |
                forall n: Int; is_nonneg(n) -> (n = ZERO or (exists m: Int; is_nonneg(m) and n = succ(m)))
                [by theorem nonnegCases]
              @x-cases-if-nonneg |
                is_nonneg(x) -> (x = ZERO or (exists m: Int; is_nonneg(m) and x = succ(m)))
                [by forall_elim(x) nonneg-cases]
              @x-zero-or-successor |
                x = ZERO or (exists m: Int; is_nonneg(m) and x = succ(m))
                [by modus_ponens x-cases-if-nonneg x-nonneg]
              @conclusion-x-is-zero |
                x = ZERO
                case on x-zero-or-successor {
                  @when-x-is-zero |
                    assume x = ZERO {
                      @conclusion-x-is-zero |
                        x = ZERO
                        [by hypothesis when-x-is-zero]
                    }
                  @when-x-is-successor |
                    assume exists m: Int; is_nonneg(m) and x = succ(m) {
                      @successor-exists |
                        exists m: Int; is_nonneg(m) and x = succ(m)
                        [by hypothesis when-x-is-successor]
                      @with-predecessor-m |
                        unpack m: Int from successor-exists {
                          @gap-nonneg-and-x-is-successor |
                            is_nonneg(m) and x = succ(m)
                            [by hypothesis with-predecessor-m]
                          @gap-nonneg |
                            is_nonneg(m)
                            [by and_elim_left gap-nonneg-and-x-is-successor]
                          @x-is-successor |
                            x = succ(m)
                            [by and_elim_right gap-nonneg-and-x-is-successor]
                          @add-zero-left |
                            forall n: Int; add(ZERO, n) = n
                            [by axiom addZeroLeft]
                          @zero-plus-successor-is-successor |
                            add(ZERO, succ(m)) = succ(m)
                            [by forall_elim(succ(m)) add-zero-left]
                          @successor-is-x |
                            succ(m) = x
                            [by symmetry x-is-successor]
                          @zero-plus-successor-is-x |
                            add(ZERO, succ(m)) = x
                            [by rewrite successor-is-x zero-plus-successor-is-successor]
                          @less-than-intro |
                            forall a, d, b: Int; is_nonneg(d) -> add(a, succ(d)) = b -> below(a, b)
                            [by axiom lessThanIntro]
                          @successor-is-positive-if-summed |
                            is_nonneg(m) -> add(ZERO, succ(m)) = x -> below(ZERO, x)
                            [by forall_elim(ZERO, m, x) less-than-intro]
                          @x-is-positive |
                            below(ZERO, x)
                            [by tautology successor-is-positive-if-summed gap-nonneg zero-plus-successor-is-x]
                          @conclusion-x-is-zero |
                            x = ZERO
                            [by absurd x-is-positive x-not-positive]
                        }
                      @conclusion-x-is-zero |
                        x = ZERO
                        [by exists_elim with-predecessor-m]
                    }
                }
            }
          @not-positive-implies-zero |
            (not below(ZERO, x)) -> x = ZERO
            [by implies_intro given-x-not-positive]
        }
      @nonneg-implies-not-positive-implies-zero |
        is_nonneg(x) -> (not below(ZERO, x)) -> x = ZERO
        [by implies_intro given-x-nonneg]
    }
  @conclusion |
    forall x: Int; is_nonneg(x) -> (not below(ZERO, x)) -> x = ZERO
    [by forall_intro generalize-x]
qed
```

Judson's nonemptiness argument splits on the sign of `a`: when `a` is positive
the witness `a·1 + b·0 = a` is a positive member; when `a` is negative the
witness `a·(−1) + b·0 = −a` is, and this needs that the negation of a negative
integer is positive. Unfolding `below(a, ZERO)` gives a nonnegative gap `d` with
`add(a, succ(d)) = ZERO`; adding `−a` on the left and cancelling `a` shows
`succ(d) = −a`, and `lessThanIntro` reads `below(ZERO, −a)` off that.

```bpa
theorem negativeNegIsPositive: forall a: Int; below(a, ZERO) -> below(ZERO, neg(a))
proof
  @generalize-a |
    fix a: Int {
      @given-a-negative |
        assume below(a, ZERO) {
          @a-negative |
            below(a, ZERO)
            [by hypothesis given-a-negative]
          @less-than-elim |
            forall x, y: Int; below(x, y) -> exists d: Int; is_nonneg(d) and add(x, succ(d)) = y
            [by axiom lessThanElim]
          @gap-below-a-zero |
            below(a, ZERO) -> exists d: Int; is_nonneg(d) and add(a, succ(d)) = ZERO
            [by forall_elim(a, ZERO) less-than-elim]
          @gap-exists |
            exists d: Int; is_nonneg(d) and add(a, succ(d)) = ZERO
            [by modus_ponens gap-below-a-zero a-negative]
          @with-gap-d |
            unpack d: Int from gap-exists {
              @gap-nonneg-and-sums |
                is_nonneg(d) and add(a, succ(d)) = ZERO
                [by hypothesis with-gap-d]
              @gap-nonneg |
                is_nonneg(d)
                [by and_elim_left gap-nonneg-and-sums]
              @a-plus-successor-is-zero |
                add(a, succ(d)) = ZERO
                [by and_elim_right gap-nonneg-and-sums]
              // succ(d) = -a: add -a on the left and cancel a.
              @neg-a-sum-reflexive |
                add(neg(a), add(a, succ(d))) = add(neg(a), add(a, succ(d)))
                [by reflexivity]
              @neg-a-times-sum-is-neg-a-times-zero |
                add(neg(a), add(a, succ(d))) = add(neg(a), ZERO)
                [by rewrite a-plus-successor-is-zero neg-a-sum-reflexive]
              @add-is-associative |
                forall x, y, z: Int; add(add(x, y), z) = add(x, add(y, z))
                [by theorem addIsAssociative]
              @regroup |
                add(add(neg(a), a), succ(d)) = add(neg(a), add(a, succ(d)))
                [by forall_elim(neg(a), a, succ(d)) add-is-associative]
              @add-neg-left |
                forall n: Int; add(neg(n), n) = ZERO
                [by theorem addNegLeft]
              @neg-a-plus-a-is-zero |
                add(neg(a), a) = ZERO
                [by forall_elim(a) add-neg-left]
              @regroup-with-zero |
                add(ZERO, succ(d)) = add(neg(a), add(a, succ(d)))
                [by rewrite neg-a-plus-a-is-zero regroup]
              @add-zero-left-lemma |
                forall n: Int; add(ZERO, n) = n
                [by axiom addZeroLeft]
              @zero-plus-successor-collapses |
                add(ZERO, succ(d)) = succ(d)
                [by forall_elim(succ(d)) add-zero-left-lemma]
              @cancelled-sum-is-successor |
                add(neg(a), add(a, succ(d))) = succ(d)
                [by rewrite regroup-with-zero zero-plus-successor-collapses]
              @add-zero-right-lemma |
                forall n: Int; add(n, ZERO) = n
                [by theorem addZeroRight]
              @neg-a-plus-zero-is-neg-a |
                add(neg(a), ZERO) = neg(a)
                [by forall_elim(neg(a)) add-zero-right-lemma]
              @successor-is-neg-a-step |
                succ(d) = add(neg(a), ZERO)
                [by rewrite cancelled-sum-is-successor neg-a-times-sum-is-neg-a-times-zero]
              @successor-is-neg-a |
                succ(d) = neg(a)
                [by rewrite neg-a-plus-zero-is-neg-a successor-is-neg-a-step]
              // read below(ZERO, -a) off add(ZERO, succ(d)) = -a.
              @zero-plus-successor-is-neg-a |
                add(ZERO, succ(d)) = neg(a)
                [by rewrite successor-is-neg-a zero-plus-successor-collapses]
              @less-than-intro |
                forall x, e, y: Int; is_nonneg(e) -> add(x, succ(e)) = y -> below(x, y)
                [by axiom lessThanIntro]
              @neg-a-positive-if-summed |
                is_nonneg(d) -> add(ZERO, succ(d)) = neg(a) -> below(ZERO, neg(a))
                [by forall_elim(ZERO, d, neg(a)) less-than-intro]
              @conclusion-neg-a-positive |
                below(ZERO, neg(a))
                [by tautology neg-a-positive-if-summed gap-nonneg zero-plus-successor-is-neg-a]
            }
          @neg-a-positive |
            below(ZERO, neg(a))
            [by exists_elim with-gap-d]
        }
      @negative-implies-neg-positive |
        below(a, ZERO) -> below(ZERO, neg(a))
        [by implies_intro given-a-negative]
    }
  @conclusion |
    forall a: Int; below(a, ZERO) -> below(ZERO, neg(a))
    [by forall_intro generalize-a]
qed
```

The heart of Judson's argument that `d = ar + bs` divides `a` runs the Division
Algorithm to write `a = dq + r'` and shows the remainder `r'` is *itself* a
member of `S`: substituting `d = ar + bs`, Judson computes `r' = a − dq =
a − (ar + bs)q = a(1 − rq) + b(−sq)` in one line. We isolate that elided ring
identity here. From `a = dq + r'` we recover `r' = a − dq` by cancelling `dq`
(via `addDiffReaches` and `addCancelLeft`); substituting `d` and rearranging by
distributing and collecting the `a` and `b` coefficients (`simplify` over the
ring lemmas) gives the member form `r' = a(1 − rq) + b(−sq)`.

```bpa
theorem remainderIsMember(a: Int, b: Int, d: Int, r: Int, s: Int, q: Int, remainder: Int):
  a = add(mul(d, q), remainder) -> d = add(mul(a, r), mul(b, s))
  -> remainder = add(mul(a, sub(ONE, mul(r, q))), mul(b, neg(mul(s, q))))
proof
  @given-a-decomposes |
    assume a = add(mul(d, q), remainder) {
      @given-d-value |
        assume d = add(mul(a, r), mul(b, s)) {
          @a-decomposes |
            a = add(mul(d, q), remainder)
            [by hypothesis given-a-decomposes]
          @d-value |
            d = add(mul(a, r), mul(b, s))
            [by hypothesis given-d-value]
          // remainder = a - dq, by cancelling dq off a = dq + remainder.
          @difference-reaches |
            forall x, y: Int; add(x, sub(y, x)) = y
            [by theorem addDiffReaches]
          @dq-plus-difference-is-a |
            add(mul(d, q), sub(a, mul(d, q))) = a
            [by forall_elim(mul(d, q), a) difference-reaches]
          @dq-plus-difference-is-decomposition |
            add(mul(d, q), sub(a, mul(d, q))) = add(mul(d, q), remainder)
            [by rewrite a-decomposes dq-plus-difference-is-a]
          @cancel-left |
            forall c, x, y: Int; add(c, x) = add(c, y) -> x = y
            [by theorem addCancelLeft]
          @cancel-the-quotient-term |
            add(mul(d, q), sub(a, mul(d, q))) = add(mul(d, q), remainder) -> sub(a, mul(d, q)) = remainder
            [by forall_elim(mul(d, q), sub(a, mul(d, q)), remainder) cancel-left]
          @difference-is-remainder |
            sub(a, mul(d, q)) = remainder
            [by modus_ponens cancel-the-quotient-term dq-plus-difference-is-decomposition]
          @remainder-is-difference |
            remainder = sub(a, mul(d, q))
            [by symmetry difference-is-remainder]
          // substitute d = ar + bs into the difference a - dq.
          @remainder-with-d-expanded |
            remainder = sub(a, mul(add(mul(a, r), mul(b, s)), q))
            [by rewrite d-value remainder-is-difference]
          // the elided algebra: a - (ar + bs)q = a(1 - rq) + b(-sq).
          @difference-collects-coefficients |
            sub(a, mul(add(mul(a, r), mul(b, s)), q)) = add(mul(a, sub(ONE, mul(r, q))), mul(b, neg(mul(s, q))))
            [by simplify subDef mulAddDistribLeft mulAddDistribRight mulNegRight mulOneRight mulIsAssociative addIsAssociative negAdd]
          @conclusion-remainder-is-member |
            remainder = add(mul(a, sub(ONE, mul(r, q))), mul(b, neg(mul(s, q))))
            [by rewrite difference-collects-coefficients remainder-with-d-expanded]
        }
      @d-value-implies-member |
        d = add(mul(a, r), mul(b, s)) -> remainder = add(mul(a, sub(ONE, mul(r, q))), mul(b, neg(mul(s, q))))
        [by implies_intro given-d-value]
    }
  @conclusion |
    a = add(mul(d, q), remainder) -> d = add(mul(a, r), mul(b, s)) -> remainder = add(mul(a, sub(ONE, mul(r, q))), mul(b, neg(mul(s, q))))
    [by implies_intro given-a-decomposes]
qed
```

The coprime corollary will produce a positive common divisor `d` that must equal
`ONE` or `−ONE`; the second alternative is ruled out because `−1` is *below*
zero, so it cannot also be positive. We record that `−1 < 0` here: `−1` is
nonnegatively-gapped below `0` by `succ(ZERO) = ONE`, since
`add(neg(ONE), succ(ZERO)) = add(neg(ONE), ONE) = ZERO`, and `lessThanIntro`
reads `below(neg(ONE), ZERO)` off that.

```bpa
theorem negOneBelowZero: below(neg(ONE), ZERO)
proof
  @one-is-succ-zero |
    ONE = succ(ZERO)
    [by axiom oneIsSuccZero]
  @add-neg-left |
    forall n: Int; add(neg(n), n) = ZERO
    [by theorem addNegLeft]
  @neg-one-plus-one-is-zero |
    add(neg(ONE), ONE) = ZERO
    [by forall_elim(ONE) add-neg-left]
  @neg-one-plus-succ-zero-is-zero |
    add(neg(ONE), succ(ZERO)) = ZERO
    [by rewrite one-is-succ-zero neg-one-plus-one-is-zero]
  @zero-is-nonneg |
    is_nonneg(ZERO)
    [by axiom nonnegZero]
  @less-than-intro |
    forall a, d, b: Int; is_nonneg(d) -> add(a, succ(d)) = b -> below(a, b)
    [by axiom lessThanIntro]
  @neg-one-negative-if-summed |
    is_nonneg(ZERO) -> add(neg(ONE), succ(ZERO)) = ZERO -> below(neg(ONE), ZERO)
    [by forall_elim(neg(ONE), ZERO, ZERO) less-than-intro]
  @conclusion |
    below(neg(ONE), ZERO)
    [by tautology neg-one-negative-if-summed zero-is-nonneg neg-one-plus-succ-zero-is-zero]
qed
```

Before invoking Well-Ordering, Judson must exhibit *some* positive member of
`S = {am + bn : am + bn > 0}` — the set is nonempty because `|a| ∈ S`. Since
`a ≠ 0`, trichotomy splits `a` into positive or negative (the `a = 0` case is
excluded). If `a > 0`, the combination `a·1 + b·0 = a` is a positive member; if
`a < 0`, then `−a > 0` (`negativeNegIsPositive`) and `a·(−1) + b·0 = −a` is a
positive member. Either way the witness is positive, hence nonnegative
(`positiveIsNonneg`), discharging the schema's guard. We package this nonemptiness
as a schema in `a`, `b`, so its conclusion matches the exact shape the
Well-Ordering instance below consumes.

```bpa
theorem combinationSetNonempty(a: Int, b: Int):
  a != ZERO
  -> exists n: Int; is_nonneg(n) and (below(ZERO, n) and (exists mm: Int; exists nn: Int; n = add(mul(a, mm), mul(b, nn))))
proof
  @given-a-nonzero |
    assume a != ZERO {
      @a-nonzero |
        a != ZERO
        [by hypothesis given-a-nonzero]
      @order-is-trichotomous |
        forall x, y: Int; below(x, y) or x = y or below(y, x)
        [by theorem trichotomy]
      @a-sign-split |
        below(a, ZERO) or a = ZERO or below(ZERO, a)
        [by forall_elim(a, ZERO) order-is-trichotomous]
      @conclusion-set-nonempty |
        exists n: Int; is_nonneg(n) and (below(ZERO, n) and (exists mm: Int; exists nn: Int; n = add(mul(a, mm), mul(b, nn))))
        case on a-sign-split {
          @when-a-negative |
            assume below(a, ZERO) {
              @a-negative |
                below(a, ZERO)
                [by hypothesis when-a-negative]
              @negative-neg-is-positive |
                forall x: Int; below(x, ZERO) -> below(ZERO, neg(x))
                [by theorem negativeNegIsPositive]
              @negative-neg-is-positive-at-a |
                below(a, ZERO) -> below(ZERO, neg(a))
                [by forall_elim(a) negative-neg-is-positive]
              @neg-a-positive |
                below(ZERO, neg(a))
                [by modus_ponens negative-neg-is-positive-at-a a-negative]
              @positive-is-nonneg |
                forall x: Int; below(ZERO, x) -> is_nonneg(x)
                [by theorem positiveIsNonneg]
              @positive-is-nonneg-at-neg-a |
                below(ZERO, neg(a)) -> is_nonneg(neg(a))
                [by forall_elim(neg(a)) positive-is-nonneg]
              @neg-a-nonneg |
                is_nonneg(neg(a))
                [by modus_ponens positive-is-nonneg-at-neg-a neg-a-positive]
              @neg-a-is-combination |
                neg(a) = add(mul(a, neg(ONE)), mul(b, ZERO))
                [by simplify mulNegRight mulOneRight mulZeroRight addZeroRight]
              @neg-a-is-some-combination-in-nn |
                exists nn: Int; neg(a) = add(mul(a, neg(ONE)), mul(b, nn))
                [by exists_intro(ZERO) neg-a-is-combination]
              @neg-a-is-a-combination |
                exists mm: Int; exists nn: Int; neg(a) = add(mul(a, mm), mul(b, nn))
                [by exists_intro(neg(ONE)) neg-a-is-some-combination-in-nn]
              @neg-a-positive-and-combination |
                below(ZERO, neg(a)) and (exists mm: Int; exists nn: Int; neg(a) = add(mul(a, mm), mul(b, nn)))
                [by and_intro neg-a-positive neg-a-is-a-combination]
              @neg-a-is-nonneg-member |
                is_nonneg(neg(a)) and (below(ZERO, neg(a)) and (exists mm: Int; exists nn: Int; neg(a) = add(mul(a, mm), mul(b, nn))))
                [by and_intro neg-a-nonneg neg-a-positive-and-combination]
              @conclusion-set-nonempty |
                exists n: Int; is_nonneg(n) and (below(ZERO, n) and (exists mm: Int; exists nn: Int; n = add(mul(a, mm), mul(b, nn))))
                [by exists_intro(neg(a)) neg-a-is-nonneg-member]
            }
          @when-a-zero |
            assume a = ZERO {
              @a-is-zero |
                a = ZERO
                [by hypothesis when-a-zero]
              @conclusion-set-nonempty |
                exists n: Int; is_nonneg(n) and (below(ZERO, n) and (exists mm: Int; exists nn: Int; n = add(mul(a, mm), mul(b, nn))))
                [by absurd a-is-zero a-nonzero]
            }
          @when-a-positive |
            assume below(ZERO, a) {
              @a-positive |
                below(ZERO, a)
                [by hypothesis when-a-positive]
              @positive-is-nonneg |
                forall x: Int; below(ZERO, x) -> is_nonneg(x)
                [by theorem positiveIsNonneg]
              @positive-is-nonneg-at-a |
                below(ZERO, a) -> is_nonneg(a)
                [by forall_elim(a) positive-is-nonneg]
              @a-nonneg |
                is_nonneg(a)
                [by modus_ponens positive-is-nonneg-at-a a-positive]
              @a-is-combination |
                a = add(mul(a, ONE), mul(b, ZERO))
                [by simplify mulOneRight mulZeroRight addZeroRight]
              @a-is-some-combination-in-nn |
                exists nn: Int; a = add(mul(a, ONE), mul(b, nn))
                [by exists_intro(ZERO) a-is-combination]
              @a-is-a-combination |
                exists mm: Int; exists nn: Int; a = add(mul(a, mm), mul(b, nn))
                [by exists_intro(ONE) a-is-some-combination-in-nn]
              @a-positive-and-combination |
                below(ZERO, a) and (exists mm: Int; exists nn: Int; a = add(mul(a, mm), mul(b, nn)))
                [by and_intro a-positive a-is-a-combination]
              @a-is-nonneg-member |
                is_nonneg(a) and (below(ZERO, a) and (exists mm: Int; exists nn: Int; a = add(mul(a, mm), mul(b, nn))))
                [by and_intro a-nonneg a-positive-and-combination]
              @conclusion-set-nonempty |
                exists n: Int; is_nonneg(n) and (below(ZERO, n) and (exists mm: Int; exists nn: Int; n = add(mul(a, mm), mul(b, nn))))
                [by exists_intro(a) a-is-nonneg-member]
            }
        }
    }
  @conclusion |
    a != ZERO
      -> exists n: Int; is_nonneg(n) and (below(ZERO, n) and (exists mm: Int; exists nn: Int; n = add(mul(a, mm), mul(b, nn))))
    [by implies_intro given-a-nonzero]
qed
```

## The GCD / Bézout Theorem

> **Theorem 2.10.** Let $a$ and $b$ be nonzero integers. Then there exist integers
> $r$ and $s$ such that $\gcd(a,b) = ar + bs$. Furthermore, the greatest common
> divisor of $a$ and $b$ is unique.

There is no `gcd` *function* in this development, so we prove the theorem in the
form that *characterizes* the gcd by its defining properties. `bezout` asserts a
single positive integer `d` that (i) divides `a` and `b`, (ii) is divisible by
every common divisor `e`, and (iii) is an integer combination `d = ar + bs`.
Uniqueness is then automatic: any two integers with property (ii) divide each
other, and — being positive — are equal; and (iii) is Bézout's identity itself.

Judson's proof: let `S = {am + bn : am + bn > 0}`. `S` is nonempty
(`combinationSetNonempty`), and every member is positive hence nonnegative, so
Well-Ordering hands us a *least* member `d = ar + bs`. We claim `d = gcd(a,b)`.
Running the Division Algorithm on `a` by `d` gives `a = dq + r'` with
`0 ≤ r' < d`. Were `r' > 0`, the identity `r' = a(1 − rq) + b(−sq)`
(`remainderIsMember`) would make `r'` a *member of `S` smaller than `d`*,
contradicting minimality; so `r' = 0` and `d ∣ a`. Symmetrically `d ∣ b`. Finally
any common divisor `e` of `a`, `b` divides `ar + bs = d`, so `d` is the greatest.

```bpa

  exists d: Int;

  and does_divide(d, a) and does_divide(d, b)
  and (forall e: Int; does_divide(e, a) -> does_divide(e, b) -> does_divide(e, d))

                      // name the coefficients: d = ar + bs.

                        unpack r: Int from d-is-a-combination {

                            exists nn: Int; d = add(mul(a, r), mul(b, nn))

                                            [by theorem lessOrEqualSplit]
                                          @less-or-equal-split-at-d-remainder |
                                            at_most(d, rem2) -> (below(d, rem2) or d = rem2)
                                            [by forall_elim(d, rem2) less-or-equal-split]

                                                    below(d, rem2) -> below(rem2, d) -> below(d, d)
                                                    [by forall_elim(d, rem2, d) less-than-transitive]
                                                  @conclusion-d-below-itself |
                                                    below(d, d)
                                                    [by tautology transitive-at-d-remainder-d d-below-remainder remainder-below-d]
                                                }
                                              @when-d-equals-remainder |
                                                assume d = rem2 {
                                                  @d-equals-remainder |
                                                    d = rem2
                                                    [by hypothesis when-d-equals-remainder]
                                                  @remainder-equals-d |
                                                    rem2 = d
                                                    [by symmetry d-equals-remainder]
                                                  @conclusion-d-below-itself |
                                                    below(d, d)
                                                    [by rewrite remainder-equals-d remainder-below-d]
                                                }
                                            }
                                        }
                                      @remainder-not-positive |
                                        not below(ZERO, rem2)
                                        [by not_intro suppose-remainder-positive remainder-would-be-a-smaller-member d-not-below-itself]
                                      @nonneg-not-positive-forces-zero |
                                        forall x: Int; is_nonneg(x) -> (not below(ZERO, x)) -> x = ZERO
                                        [by theorem nonnegNotPositiveIsZero]
                                      @nonneg-not-positive-is-zero |
                                        is_nonneg(rem2) -> (not below(ZERO, rem2)) -> rem2 = ZERO
                                        [by forall_elim(rem2) nonneg-not-positive-forces-zero]
                                      @remainder-is-zero |
                                        rem2 = ZERO
                                        [by tautology nonneg-not-positive-is-zero remainder-nonneg remainder-not-positive]
                                      @b-is-dq-plus-zero |
                                        b = add(mul(d, q2), ZERO)
                                        [by rewrite remainder-is-zero b-decomposes]
                                      @add-zero-right |
                                        forall n: Int; add(n, ZERO) = n
                                        [by theorem addZeroRight]
                                      @dq-plus-zero-is-dq |
                                        add(mul(d, q2), ZERO) = mul(d, q2)
                                        [by forall_elim(mul(d, q2)) add-zero-right]
                                      @b-is-dq |
                                        b = mul(d, q2)
                                        [by rewrite dq-plus-zero-is-dq b-is-dq-plus-zero]
                                      @divides-intro |
                                        forall n, dd, k: Int; n = mul(dd, k) -> does_divide(dd, n)
                                        [by axiom dividesIntro]
                                      @d-divides-b-if-product |
                                        b = mul(d, q2) -> does_divide(d, b)
                                        [by forall_elim(b, d, q2) divides-intro]
                                      @conclusion-d-divides-b |
                                        does_divide(d, b)
                                        [by modus_ponens d-divides-b-if-product b-is-dq]
                                    }
                                  @conclusion-d-divides-b |
                                    does_divide(d, b)
                                    [by exists_elim with-remainder-of-b]
                                }
                              @d-divides-b |
                                does_divide(d, b)
                                [by exists_elim with-quotient-q2]
                              // any common divisor e divides d = ar + bs.
                              @generalize-e |
                                fix e: Int {
                                  @given-e-divides-a |
                                    assume does_divide(e, a) {
                                      @given-e-divides-b |
                                        assume does_divide(e, b) {
                                          @e-divides-a |
                                            does_divide(e, a)
                                            [by hypothesis given-e-divides-a]
                                          @e-divides-b |
                                            does_divide(e, b)
                                            [by hypothesis given-e-divides-b]
                                          @divides-mul |
                                            forall dd, x, c: Int; does_divide(dd, x) -> does_divide(dd, mul(x, c))
                                            [by theorem dividesMul]
                                          @e-divides-a-times-r |
                                            does_divide(e, a) -> does_divide(e, mul(a, r))
                                            [by forall_elim(e, a, r) divides-mul]
                                          @e-divides-ar |
                                            does_divide(e, mul(a, r))
                                            [by modus_ponens e-divides-a-times-r e-divides-a]
                                          @e-divides-b-times-s |
                                            does_divide(e, b) -> does_divide(e, mul(b, s))
                                            [by forall_elim(e, b, s) divides-mul]
                                          @e-divides-bs |
                                            does_divide(e, mul(b, s))
                                            [by modus_ponens e-divides-b-times-s e-divides-b]
                                          @divides-add |
                                            forall dd, x, y: Int; does_divide(dd, x) -> does_divide(dd, y) -> does_divide(dd, add(x, y))
                                            [by theorem dividesAdd]
                                          @e-divides-sum-if-parts |
                                            does_divide(e, mul(a, r)) -> does_divide(e, mul(b, s)) -> does_divide(e, add(mul(a, r), mul(b, s)))
                                            [by forall_elim(e, mul(a, r), mul(b, s)) divides-add]
                                          @e-divides-combination |
                                            does_divide(e, add(mul(a, r), mul(b, s)))
                                            [by tautology e-divides-sum-if-parts e-divides-ar e-divides-bs]
                                          @combination-is-d |
                                            add(mul(a, r), mul(b, s)) = d
                                            [by symmetry d-equals-combination]
                                          @conclusion-e-divides-d |
                                            does_divide(e, d)
                                            [by rewrite combination-is-d e-divides-combination]
                                        }
                                      @e-divides-b-implies-e-divides-d |
                                        does_divide(e, b) -> does_divide(e, d)
                                        [by implies_intro given-e-divides-b]
                                    }
                                  @e-divides-a-implies-rest |
                                    does_divide(e, a) -> does_divide(e, b) -> does_divide(e, d)
                                    [by implies_intro given-e-divides-a]
                                }
                              @common-divisor-divides-d |
                                forall e: Int; does_divide(e, a) -> does_divide(e, b) -> does_divide(e, d)
                                [by forall_intro generalize-e]
                              // assemble the five defining properties of the gcd.
                              @d-is-some-combination-in-s |
                                exists s2: Int; d = add(mul(a, r), mul(b, s2))
                                [by exists_intro(s) d-equals-combination]
                              @d-is-a-combination-again |
                                exists r2: Int; exists s2: Int; d = add(mul(a, r2), mul(b, s2))
                                [by exists_intro(r) d-is-some-combination-in-s]
                              @d-positive-and-divides-a |
                                below(ZERO, d) and does_divide(d, a)
                                [by and_intro d-is-positive d-divides-a]
                              @d-divides-a-and-b |
                                below(ZERO, d) and does_divide(d, a) and does_divide(d, b)
                                [by and_intro d-positive-and-divides-a d-divides-b]
                              @d-divides-and-greatest |
                                below(ZERO, d) and does_divide(d, a) and does_divide(d, b) and (forall e: Int; does_divide(e, a) -> does_divide(e, b) -> does_divide(e, d))
                                [by and_intro d-divides-a-and-b common-divisor-divides-d]
                              @d-has-all-gcd-properties |
                                below(ZERO, d) and does_divide(d, a) and does_divide(d, b) and (forall e: Int; does_divide(e, a) -> does_divide(e, b) -> does_divide(e, d)) and (exists r2: Int; exists s2: Int; d = add(mul(a, r2), mul(b, s2)))
                                [by and_intro d-divides-and-greatest d-is-a-combination-again]
                              @conclusion-bezout |
                                exists d2: Int; below(ZERO, d2) and does_divide(d2, a) and does_divide(d2, b) and (forall e: Int; does_divide(e, a) -> does_divide(e, b) -> does_divide(e, d2)) and (exists r2: Int; exists s2: Int; d2 = add(mul(a, r2), mul(b, s2)))
                                [by exists_intro(d) d-has-all-gcd-properties]
                            }
                          @conclusion-bezout |
                            exists d2: Int; below(ZERO, d2) and does_divide(d2, a) and does_divide(d2, b) and (forall e: Int; does_divide(e, a) -> does_divide(e, b) -> does_divide(e, d2)) and (exists r2: Int; exists s2: Int; d2 = add(mul(a, r2), mul(b, s2)))
                            [by exists_elim with-coefficient-s]
                        }
                      @conclusion-bezout |
                        exists d2: Int; below(ZERO, d2) and does_divide(d2, a) and does_divide(d2, b) and (forall e: Int; does_divide(e, a) -> does_divide(e, b) -> does_divide(e, d2)) and (exists r2: Int; exists s2: Int; d2 = add(mul(a, r2), mul(b, s2)))
                        [by exists_elim with-coefficient-r]
                    }
                  @conclusion-bezout |
                    exists d2: Int; below(ZERO, d2) and does_divide(d2, a) and does_divide(d2, b) and (forall e: Int; does_divide(e, a) -> does_divide(e, b) -> does_divide(e, d2)) and (exists r2: Int; exists s2: Int; d2 = add(mul(a, r2), mul(b, s2)))
                    [by exists_elim with-least-member-d]
                }
              @b-nonzero-gives-bezout |
                (b != ZERO)
                  -> exists d: Int; below(ZERO, d) and does_divide(d, a) and does_divide(d, b) and (forall e: Int; does_divide(e, a) -> does_divide(e, b) -> does_divide(e, d)) and (exists r: Int; exists s: Int; d = add(mul(a, r), mul(b, s)))
                [by implies_intro given-b-nonzero]
            }
          @a-nonzero-gives-bezout |
            (a != ZERO)
              -> (b != ZERO) -> exists d: Int; below(ZERO, d) and does_divide(d, a) and does_divide(d, b) and (forall e: Int; does_divide(e, a) -> does_divide(e, b) -> does_divide(e, d)) and (exists r: Int; exists s: Int; d = add(mul(a, r), mul(b, s)))
            [by implies_intro given-a-nonzero]
        }
      @discharge-b |
        forall b: Int; (a != ZERO) -> (b != ZERO) -> exists d: Int; below(ZERO, d) and does_divide(d, a) and does_divide(d, b) and (forall e: Int; does_divide(e, a) -> does_divide(e, b) -> does_divide(e, d)) and (exists r: Int; exists s: Int; d = add(mul(a, r), mul(b, s)))
        [by forall_intro generalize-b]
    }
  @conclusion |
    forall a, b: Int; (a != ZERO) -> (b != ZERO) -> exists d: Int; below(ZERO, d) and does_divide(d, a) and does_divide(d, b) and (forall e: Int; does_divide(e, a) -> does_divide(e, b) -> does_divide(e, d)) and (exists r: Int; exists s: Int; d = add(mul(a, r), mul(b, s)))
    [by forall_intro generalize-a]
qed
```

## The Coprime Corollary

> **Corollary 2.11.** Let $a$ and $b$ be two integers that are relatively prime.
> Then there exist integers $r$ and $s$ such that $ar + bs = 1$.

If `a` and `b` are coprime — every common divisor is `±1` — Bézout's positive
common divisor `d = gcd(a,b)` must itself be `1` or `−1`. It is positive
(`below(ZERO, d)`), and `−1` is *not* positive (`negOneBelowZero` puts `−1 < 0`,
which together with `0 < −1` and transitivity would give `0 < 0`), so `d = 1` and
Bézout's identity `d = ar + bs` becomes `ar + bs = 1`.

```bpa
theorem coprimeBezout: forall a, b: Int; a != ZERO -> b != ZERO ->
  (forall e: Int; does_divide(e, a) -> does_divide(e, b) -> (e = ONE or e = neg(ONE)))
  -> exists r: Int; exists s: Int; add(mul(a, r), mul(b, s)) = ONE
proof
  @generalize-a |
    fix a: Int {
      @generalize-b |
        fix b: Int {
          @given-a-nonzero |
            assume a != ZERO {
              @given-b-nonzero |
                assume b != ZERO {
                  @given-coprime |
                    assume forall e: Int; does_divide(e, a) -> does_divide(e, b) -> (e = ONE or e = neg(ONE)) {
                      @a-nonzero |
                        a != ZERO
                        [by hypothesis given-a-nonzero]
                      @b-nonzero |
                        b != ZERO
                        [by hypothesis given-b-nonzero]
                      @coprime |
                        forall e: Int; does_divide(e, a) -> does_divide(e, b) -> (e = ONE or e = neg(ONE))
                        [by hypothesis given-coprime]
                      // Bézout supplies a positive gcd d = ar + bs dividing a and b.
                      @bezout-for-all |
                        forall a2, b2: Int; a2 != ZERO -> b2 != ZERO -> exists d: Int; below(ZERO, d) and does_divide(d, a2) and does_divide(d, b2) and (forall e: Int; does_divide(e, a2) -> does_divide(e, b2) -> does_divide(e, d)) and (exists r: Int; exists s: Int; d = add(mul(a2, r), mul(b2, s)))
                        [by theorem bezout]
                      @bezout-at-a-b |
                        a != ZERO -> b != ZERO -> exists d: Int; below(ZERO, d) and does_divide(d, a) and does_divide(d, b) and (forall e: Int; does_divide(e, a) -> does_divide(e, b) -> does_divide(e, d)) and (exists r: Int; exists s: Int; d = add(mul(a, r), mul(b, s)))
                        [by forall_elim(a, b) bezout-for-all]
                      @gcd-exists |
                        exists d: Int; below(ZERO, d) and does_divide(d, a) and does_divide(d, b) and (forall e: Int; does_divide(e, a) -> does_divide(e, b) -> does_divide(e, d)) and (exists r: Int; exists s: Int; d = add(mul(a, r), mul(b, s)))
                        [by tautology bezout-at-a-b a-nonzero b-nonzero]
                      @with-gcd-d |
                        unpack d: Int from gcd-exists {
                          @d-has-all-gcd-properties |
                            below(ZERO, d) and does_divide(d, a) and does_divide(d, b) and (forall e: Int; does_divide(e, a) -> does_divide(e, b) -> does_divide(e, d)) and (exists r: Int; exists s: Int; d = add(mul(a, r), mul(b, s)))
                            [by hypothesis with-gcd-d]
                          @d-is-positive |
                            below(ZERO, d)
                            [by tautology d-has-all-gcd-properties]
                          @d-divides-a |
                            does_divide(d, a)
                            [by tautology d-has-all-gcd-properties]
                          @d-divides-b |
                            does_divide(d, b)
                            [by tautology d-has-all-gcd-properties]
                          @d-is-a-combination |
                            exists r: Int; exists s: Int; d = add(mul(a, r), mul(b, s))
                            [by tautology d-has-all-gcd-properties]
                          // coprimality forces the gcd to be 1 or -1.
                          @coprime-at-d |
                            does_divide(d, a) -> does_divide(d, b) -> (d = ONE or d = neg(ONE))
                            [by forall_elim(d) coprime]
                          @d-is-one-or-neg-one |
                            d = ONE or d = neg(ONE)
                            [by tautology coprime-at-d d-divides-a d-divides-b]
                          @conclusion-bezout-identity |
                            exists r: Int; exists s: Int; add(mul(a, r), mul(b, s)) = ONE
                            case on d-is-one-or-neg-one {
                              @when-d-is-one |
                                assume d = ONE {
                                  @d-is-one |
                                    d = ONE
                                    [by hypothesis when-d-is-one]
                                  @with-coefficient-r |
                                    unpack r: Int from d-is-a-combination {
                                      @d-is-combination-in-r |
                                        exists s: Int; d = add(mul(a, r), mul(b, s))
                                        [by hypothesis with-coefficient-r]
                                      @with-coefficient-s |
                                        unpack s: Int from d-is-combination-in-r {
                                          @d-equals-combination |
                                            d = add(mul(a, r), mul(b, s))
                                            [by hypothesis with-coefficient-s]
                                          @one-equals-combination |
                                            ONE = add(mul(a, r), mul(b, s))
                                            [by rewrite d-is-one d-equals-combination]
                                          @combination-equals-one |
                                            add(mul(a, r), mul(b, s)) = ONE
                                            [by symmetry one-equals-combination]
                                          @combination-in-s-is-one |
                                            exists s2: Int; add(mul(a, r), mul(b, s2)) = ONE
                                            [by exists_intro(s) combination-equals-one]
                                          @conclusion-bezout-identity |
                                            exists r2: Int; exists s2: Int; add(mul(a, r2), mul(b, s2)) = ONE
                                            [by exists_intro(r) combination-in-s-is-one]
                                        }
                                      @conclusion-bezout-identity |
                                        exists r2: Int; exists s2: Int; add(mul(a, r2), mul(b, s2)) = ONE
                                        [by exists_elim with-coefficient-s]
                                    }
                                  @conclusion-bezout-identity |
                                    exists r2: Int; exists s2: Int; add(mul(a, r2), mul(b, s2)) = ONE
                                    [by exists_elim with-coefficient-r]
                                }
                              @when-d-is-neg-one |
                                assume d = neg(ONE) {
                                  @d-is-neg-one |
                                    d = neg(ONE)
                                    [by hypothesis when-d-is-neg-one]
                                  // d positive but d = -1 < 0 is impossible.
                                  @neg-one-is-positive |
                                    below(ZERO, neg(ONE))
                                    [by rewrite d-is-neg-one d-is-positive]
                                  @neg-one-is-negative |
                                    below(neg(ONE), ZERO)
                                    [by theorem negOneBelowZero]
                                  @less-than-transitive |
                                    forall x, y, z: Int; below(x, y) -> below(y, z) -> below(x, z)
                                    [by theorem lessThanTransitive]
                                  @transitive-through-neg-one |
                                    below(ZERO, neg(ONE)) -> below(neg(ONE), ZERO) -> below(ZERO, ZERO)
                                    [by forall_elim(ZERO, neg(ONE), ZERO) less-than-transitive]
                                  @zero-below-itself |
                                    below(ZERO, ZERO)
                                    [by tautology transitive-through-neg-one neg-one-is-positive neg-one-is-negative]
                                  @less-than-is-irreflexive |
                                    forall n: Int; not below(n, n)
                                    [by theorem lessThanIrreflexive]
                                  @zero-not-below-itself |
                                    not below(ZERO, ZERO)
                                    [by forall_elim(ZERO) less-than-is-irreflexive]
                                  @conclusion-bezout-identity |
                                    exists r2: Int; exists s2: Int; add(mul(a, r2), mul(b, s2)) = ONE
                                    [by absurd zero-below-itself zero-not-below-itself]
                                }
                            }
                        }
                      @conclusion-bezout-identity |
                        exists r2: Int; exists s2: Int; add(mul(a, r2), mul(b, s2)) = ONE
                        [by exists_elim with-gcd-d]
                    }
                  @coprime-implies-bezout-identity |
                    (forall e: Int; does_divide(e, a) -> does_divide(e, b) -> (e = ONE or e = neg(ONE)))
                      -> exists r: Int; exists s: Int; add(mul(a, r), mul(b, s)) = ONE
                    [by implies_intro given-coprime]
                }
              @b-nonzero-implies-coprime-bezout |
                (b != ZERO)
                  -> (forall e: Int; does_divide(e, a) -> does_divide(e, b) -> (e = ONE or e = neg(ONE)))
                  -> exists r: Int; exists s: Int; add(mul(a, r), mul(b, s)) = ONE
                [by implies_intro given-b-nonzero]
            }
          @a-nonzero-implies-coprime-bezout |
            (a != ZERO)
              -> (b != ZERO)
              -> (forall e: Int; does_divide(e, a) -> does_divide(e, b) -> (e = ONE or e = neg(ONE)))
              -> exists r: Int; exists s: Int; add(mul(a, r), mul(b, s)) = ONE
            [by implies_intro given-a-nonzero]
        }
      @discharge-b |
        forall b: Int; (a != ZERO) -> (b != ZERO) -> (forall e: Int; does_divide(e, a) -> does_divide(e, b) -> (e = ONE or e = neg(ONE))) -> exists r: Int; exists s: Int; add(mul(a, r), mul(b, s)) = ONE
        [by forall_intro generalize-b]
    }
  @conclusion |
    forall a, b: Int; (a != ZERO) -> (b != ZERO) -> (forall e: Int; does_divide(e, a) -> does_divide(e, b) -> (e = ONE or e = neg(ONE))) -> exists r: Int; exists s: Int; add(mul(a, r), mul(b, s)) = ONE
    [by forall_intro generalize-a]
qed
```

## Prime Numbers

A **prime** is an integer `p > 1` whose only *positive* divisors are `1` and `p`
itself (Judson, Definition 2.10). Since `bpa` predicates are opaque, we spell the
condition out inline as the conjunction

```
below(ONE, p) and (forall d: Int; below(ZERO, d) -> does_divide(d, p) -> (d = ONE or d = p))
```

wherever "`p` is prime" is needed. This section proves the two theorems that make
primes the multiplicative atoms of `ℤ`: **Euclid's Lemma** — a prime dividing a
product divides one of the factors — and, as the classical corollary, a note on
the **infinitude of primes**. Euclid's Lemma rests on `coprimeBezout` (proved
above) and on the ℤ number-theory library; we bring in the last few names the
argument spells out, plus the finite-product sequence library for the
infinitude discussion.

```bpa
import sequence <<< "std/integer-sequence.bpa"

axiom mulZeroLeft = ring.mulZeroLeft
axiom mulSuccLeft = ring.mulSuccLeft
axiom negZero = division.negZero
theorem mulIsCommutative = order.mulIsCommutative
theorem mulNegLeft = order.mulNegLeft
theorem nonnegNotBelowZero = wellordering.nonnegNotBelowZero
theorem dividesRefl = divides.dividesRefl

sort Seq = sequence.Seq
func at = sequence.at
func productUpTo = sequence.productUpTo
axiom productUpToZero = sequence.productUpToZero
axiom productUpToSucc = sequence.productUpToSucc
theorem everyEntryDividesProduct = sequence.everyEntryDividesProduct
```

The elided ring algebra Euclid's Lemma needs — collapsing `b·(ar+ps)` to a
sum of two `p`-related products — is a nonlinear identity handled by the
`polynomial` tactic. That tactic expects the ring's associativity/commutativity
lemmas *and their left-swap forms* in scope; ℤ has the swaps only implicitly, so
we prove the three names it looks up (`mulOneLeft`, `mulLeftSwap`, `addLeftSwap`)
first. `mul(1, n) = n` mirrors `mulOneRight` on the left, unfolding `1 = succ 0`
through `mulSuccLeft`.

```bpa
theorem mulOneLeft: forall n: Int; mul(ONE, n) = n
proof
  @generalize-n |
    fix n: Int {
      @one-is-succ-zero |
        ONE = succ(ZERO)
        [by axiom oneIsSuccZero]
      @succ-zero-is-one |
        succ(ZERO) = ONE
        [by symmetry one-is-succ-zero]
      @mul-succ-left |
        forall a, b: Int; mul(succ(a), b) = add(mul(a, b), b)
        [by axiom mulSuccLeft]
      @mul-succ-zero-n |
        mul(succ(ZERO), n) = add(mul(ZERO, n), n)
        [by forall_elim(ZERO, n) mul-succ-left]
      @mul-one-n-expanded |
        mul(ONE, n) = add(mul(ZERO, n), n)
        [by rewrite succ-zero-is-one mul-succ-zero-n]
      @mul-zero-left |
        forall b: Int; mul(ZERO, b) = ZERO
        [by axiom mulZeroLeft]
      @mul-zero-n-is-zero |
        mul(ZERO, n) = ZERO
        [by forall_elim(n) mul-zero-left]
      @mul-one-n-is-zero-plus-n |
        mul(ONE, n) = add(ZERO, n)
        [by rewrite mul-zero-n-is-zero mul-one-n-expanded]
      @add-zero-left |
        forall b: Int; add(ZERO, b) = b
        [by axiom addZeroLeft]
      @zero-plus-n-is-n |
        add(ZERO, n) = n
        [by forall_elim(n) add-zero-left]
      @conclusion-mul-one-left |
        mul(ONE, n) = n
        [by rewrite zero-plus-n-is-n mul-one-n-is-zero-plus-n]
    }
  @conclusion |
    forall n: Int; mul(ONE, n) = n
    [by forall_intro generalize-n]
```

The left-swap forms `a·(b·c) = b·(a·c)` and `a+(b+c) = b+(a+c)` reassociate,
commute the exposed pair, then reassociate back.

```bpa
theorem mulLeftSwap: forall a, b, c: Int; mul(a, mul(b, c)) = mul(b, mul(a, c))
proof
  @generalize-a |
    fix a: Int {
      @generalize-b |
        fix b: Int {
          @generalize-c |
            fix c: Int {
              @mul-associative |
                forall x, y, z: Int; mul(mul(x, y), z) = mul(x, mul(y, z))
                [by theorem mulIsAssociative]
              @abc-regroups-flat |
                mul(mul(a, b), c) = mul(a, mul(b, c))
                [by forall_elim(a, b, c) mul-associative]
              @a-bc-regroups |
                mul(a, mul(b, c)) = mul(mul(a, b), c)
                [by symmetry abc-regroups-flat]
              @mul-commutative |
                forall x, y: Int; mul(x, y) = mul(y, x)
                [by theorem mulIsCommutative]
              @a-b-swaps |
                mul(a, b) = mul(b, a)
                [by forall_elim(a, b) mul-commutative]
              @a-bc-is-ba-grouped |
                mul(a, mul(b, c)) = mul(mul(b, a), c)
                [by rewrite a-b-swaps a-bc-regroups]
              @ba-c-regroups |
                mul(mul(b, a), c) = mul(b, mul(a, c))
                [by forall_elim(b, a, c) mul-associative]
              @conclusion-mul-left-swap |
                mul(a, mul(b, c)) = mul(b, mul(a, c))
                [by rewrite ba-c-regroups a-bc-is-ba-grouped]
            }
          @discharge-c |
            forall c: Int; mul(a, mul(b, c)) = mul(b, mul(a, c))
            [by forall_intro generalize-c]
        }
      @discharge-b |
        forall b, c: Int; mul(a, mul(b, c)) = mul(b, mul(a, c))
        [by forall_intro generalize-b]
    }
  @conclusion |
    forall a, b, c: Int; mul(a, mul(b, c)) = mul(b, mul(a, c))
    [by forall_intro generalize-a]
qed
```

A small positivity fact used repeatedly: `0 < 1`, the gap being `0`, since
`add(0, succ 0) = succ 0 = 1`.

```bpa
theorem zeroBelowOne: below(ZERO, ONE)
```

`neg(e)` divides whatever `e` divides: unfolding `n = e·k` gives
`n = neg(e)·neg(k)` (`mulNegLeft`, `mulNegRight`, `negNeg` cancel the two sign
flips), so `neg(e) | n`. This lets the coprimality argument reduce a negative
common divisor to its positive counterpart.

```bpa
theorem negDivides: forall e, n: Int; does_divide(e, n) -> does_divide(neg(e), n)
proof
  @generalize-e |
    fix e: Int {
      @generalize-n |
        fix n: Int {
          @given-e-divides-n |
            assume does_divide(e, n) {
              @e-divides-n |
                does_divide(e, n)
                [by hypothesis given-e-divides-n]
              @divides-elim |
                forall d, m: Int; does_divide(d, m) -> exists k: Int; m = mul(d, k)
                [by axiom dividesElim]
              @quotient-of-n-by-e-exists |
                does_divide(e, n) -> exists k: Int; n = mul(e, k)
                [by forall_elim(e, n) divides-elim]
              @quotient-exists |
                exists k: Int; n = mul(e, k)
                [by modus_ponens quotient-of-n-by-e-exists e-divides-n]
              @with-quotient-k |
                unpack k: Int from quotient-exists {
                  @n-is-e-times-k |
                    n = mul(e, k)
                    [by hypothesis with-quotient-k]
                  @e-times-k-is-neg-e-times-neg-k |
                    mul(e, k) = mul(neg(e), neg(k))
                    [by simplify mulNegLeft mulNegRight negNeg]
                  @n-is-neg-e-times-neg-k |
                    n = mul(neg(e), neg(k))
                    [by rewrite e-times-k-is-neg-e-times-neg-k n-is-e-times-k]
                  @divides-intro |
                    forall m, d, j: Int; m = mul(d, j) -> does_divide(d, m)
                    [by axiom dividesIntro]
                  @neg-e-divides-n-if-product |
                    n = mul(neg(e), neg(k)) -> does_divide(neg(e), n)
                    [by forall_elim(n, neg(e), neg(k)) divides-intro]
                  @neg-e-divides-n |
                    does_divide(neg(e), n)
                    [by modus_ponens neg-e-divides-n-if-product n-is-neg-e-times-neg-k]
                }
              @neg-e-divides-n |
                does_divide(neg(e), n)
                [by exists_elim with-quotient-k]
            }
          @e-divides-implies-neg-e-divides |
            does_divide(e, n) -> does_divide(neg(e), n)
            [by implies_intro given-e-divides-n]
        }
      @discharge-n |
        forall n: Int; does_divide(e, n) -> does_divide(neg(e), n)
        [by forall_intro generalize-n]
    }
  @conclusion |
    forall e, n: Int; does_divide(e, n) -> does_divide(neg(e), n)
    [by forall_intro generalize-e]
qed
```

A negative integer negates to a positive one: `negBelowZero` gives
`neg(e) ≥ 0`, and `neg(e)` is not `0` (that would force `e = 0`), so `nonnegCases`
exhibits it as a successor `succ(m)` of a nonnegative `m`, whence `0 < succ(m) =
neg(e)`.

```bpa
theorem positiveOfNegative: forall e: Int; below(e, ZERO) -> below(ZERO, neg(e))
proof
  @generalize-e |
    fix e: Int {
      @given-e-negative |
        assume below(e, ZERO) {
          @e-negative |
            below(e, ZERO)
            [by hypothesis given-e-negative]
          @neg-nonneg-if-negative |
            forall n: Int; below(n, ZERO) -> is_nonneg(neg(n))
            [by theorem negBelowZero]
          @neg-e-nonneg-if-e-negative |
            below(e, ZERO) -> is_nonneg(neg(e))
            [by forall_elim(e) neg-nonneg-if-negative]
          @neg-e-is-nonneg |
            is_nonneg(neg(e))
            [by modus_ponens neg-e-nonneg-if-e-negative e-negative]
          @nonneg-splits |
            forall n: Int; is_nonneg(n) -> (n = ZERO or (exists m: Int; is_nonneg(m) and n = succ(m)))
            [by theorem nonnegCases]
          @neg-e-is-zero-or-successor |
            is_nonneg(neg(e)) -> (neg(e) = ZERO or (exists m: Int; is_nonneg(m) and neg(e) = succ(m)))
            [by forall_elim(neg(e)) nonneg-splits]
          @neg-e-zero-or-successor |
            neg(e) = ZERO or (exists m: Int; is_nonneg(m) and neg(e) = succ(m))
            [by modus_ponens neg-e-is-zero-or-successor neg-e-is-nonneg]
          @neg-e-positive |
            below(ZERO, neg(e))
            case on neg-e-zero-or-successor {
              @when-neg-e-zero |
                assume neg(e) = ZERO {
                  // neg(e)=0 forces e=neg(neg(e))=0, contradicting e<0.
                  @neg-e-is-zero |
                    neg(e) = ZERO
                    [by hypothesis when-neg-e-zero]
                  @neg-neg-is-identity |
                    forall n: Int; neg(neg(n)) = n
                    [by theorem negNeg]
                  @e-is-neg-neg-e |
                    neg(neg(e)) = e
                    [by forall_elim(e) neg-neg-is-identity]
                  @neg-zero-is-e |
                    neg(ZERO) = e
                    [by rewrite neg-e-is-zero e-is-neg-neg-e]
                  @neg-of-zero-is-zero |
                    neg(ZERO) = ZERO
                    [by axiom negZero]
                  @zero-is-e |
                    ZERO = e
                    [by rewrite neg-of-zero-is-zero neg-zero-is-e]
                  @e-is-zero |
                    e = ZERO
                    [by symmetry zero-is-e]
                  @zero-is-negative |
                    below(ZERO, ZERO)
                    [by rewrite e-is-zero e-negative]
                  @less-than-irreflexive |
                    forall n: Int; not below(n, n)
                    [by theorem lessThanIrreflexive]
                  @zero-not-below-zero |
                    not below(ZERO, ZERO)
                    [by forall_elim(ZERO) less-than-irreflexive]
                  @neg-e-positive |
                    below(ZERO, neg(e))
                    [by absurd zero-is-negative zero-not-below-zero]
                }
              @when-neg-e-successor |
                assume exists m: Int; is_nonneg(m) and neg(e) = succ(m) {
                  @neg-e-is-a-successor |
                    exists m: Int; is_nonneg(m) and neg(e) = succ(m)
                    [by hypothesis when-neg-e-successor]
                  @with-predecessor-m |
                    unpack m: Int from neg-e-is-a-successor {
                      @m-nonneg-and-neg-e-is-succ |
                        is_nonneg(m) and neg(e) = succ(m)
                        [by hypothesis with-predecessor-m]
                      @m-is-nonneg |
                        is_nonneg(m)
                        [by and_elim_left m-nonneg-and-neg-e-is-succ]
                      @neg-e-is-succ-m |
                        neg(e) = succ(m)
                        [by and_elim_right m-nonneg-and-neg-e-is-succ]
                      @add-zero-left |
                        forall b: Int; add(ZERO, b) = b
                        [by axiom addZeroLeft]
                      @zero-plus-succ-m-is-succ-m |
                        add(ZERO, succ(m)) = succ(m)
                        [by forall_elim(succ(m)) add-zero-left]
                      @less-than-intro |
                        forall a, d, b: Int; is_nonneg(d) -> add(a, succ(d)) = b -> below(a, b)
                        [by axiom lessThanIntro]
                      @zero-below-succ-m-if-summed |
                        is_nonneg(m) -> add(ZERO, succ(m)) = succ(m) -> below(ZERO, succ(m))
                        [by forall_elim(ZERO, m, succ(m)) less-than-intro]
                      @zero-below-succ-m |
                        below(ZERO, succ(m))
                        [by tautology zero-below-succ-m-if-summed m-is-nonneg zero-plus-succ-m-is-succ-m]
                      @succ-m-is-neg-e |
                        succ(m) = neg(e)
                        [by symmetry neg-e-is-succ-m]
                      @neg-e-positive |
                        below(ZERO, neg(e))
                        [by rewrite succ-m-is-neg-e zero-below-succ-m]
                    }
                  @neg-e-positive |
                    below(ZERO, neg(e))
                    [by exists_elim with-predecessor-m]
                }
            }
        }
      @e-negative-implies-neg-e-positive |
        below(e, ZERO) -> below(ZERO, neg(e))
        [by implies_intro given-e-negative]
    }
  @conclusion |
    forall e: Int; below(e, ZERO) -> below(ZERO, neg(e))
    [by forall_intro generalize-e]
qed
```

Euclid's Lemma proceeds by cases on whether `p | a`, and `ℤ`'s intuitionistic
kernel offers no free excluded middle — so we first establish that divisibility
by a positive integer *is decidable*. Run the Division Algorithm: `a = pq + r`
with `0 ≤ r < p`. By trichotomy the remainder `r` is `< 0` (impossible, `r` is
nonnegative), `= 0` (then `a = p·q`, so `p | a`), or `> 0`. In the last case,
were `p | a` we would have a second decomposition `a = p·m + 0`; the Division
Algorithm's *uniqueness* forces `r = 0`, contradicting `r > 0` — so `p ∤ a`.

```bpa
theorem dividesDecidable: forall p, a: Int; below(ZERO, p) -> (does_divide(p, a) or (not does_divide(p, a)))
proof
  @generalize-p |
    fix p: Int {
      @generalize-a |
        fix a: Int {
          @given-p-positive |
            assume below(ZERO, p) {
              @p-positive |
                below(ZERO, p)
                [by hypothesis given-p-positive]
              @division-exists |
                forall x, y: Int; below(ZERO, y) -> exists q: Int; exists r: Int; x = add(mul(y, q), r) and is_nonneg(r) and below(r, y)
                [by theorem divisionAlgorithmExists]
              @division-of-a-by-p |
                below(ZERO, p) -> exists q: Int; exists r: Int; a = add(mul(p, q), r) and is_nonneg(r) and below(r, p)
                [by forall_elim(a, p) division-exists]
              @quotient-remainder-exist |
                exists q: Int; exists r: Int; a = add(mul(p, q), r) and is_nonneg(r) and below(r, p)
                [by modus_ponens division-of-a-by-p p-positive]
              @with-quotient-q |
                unpack q: Int from quotient-remainder-exist {
                  @remainder-exists |
                    exists r: Int; a = add(mul(p, q), r) and is_nonneg(r) and below(r, p)
                    [by hypothesis with-quotient-q]
                  @with-remainder-r |
                    unpack r: Int from remainder-exists {
                      @decomposition-and-bounds |
                        a = add(mul(p, q), r) and is_nonneg(r) and below(r, p)
                        [by hypothesis with-remainder-r]
                      @decomposition-and-remainder-nonneg |
                        a = add(mul(p, q), r) and is_nonneg(r)
                        [by and_elim_left decomposition-and-bounds]
                      @decomposition |
                        a = add(mul(p, q), r)
                        [by and_elim_left decomposition-and-remainder-nonneg]
                      @remainder-nonneg |
                        is_nonneg(r)
                        [by and_elim_right decomposition-and-remainder-nonneg]
                      @remainder-below-p |
                        below(r, p)
                        [by and_elim_right decomposition-and-bounds]
                      @trichotomy-of-r |
                        forall x, y: Int; below(x, y) or x = y or below(y, x)
                        [by theorem trichotomy]
                      @r-against-zero |
                        below(r, ZERO) or r = ZERO or below(ZERO, r)
                        [by forall_elim(r, ZERO) trichotomy-of-r]
                      @divides-decidable |
                        does_divide(p, a) or (not does_divide(p, a))
                        case on r-against-zero {
                          @when-remainder-below-zero |
                            assume below(r, ZERO) {
                              @remainder-below-zero |
                                below(r, ZERO)
                                [by hypothesis when-remainder-below-zero]
                              @nonneg-not-below-zero |
                                forall m: Int; is_nonneg(m) -> (not below(m, ZERO))
                                [by theorem nonnegNotBelowZero]
                              @remainder-not-below-zero-if-nonneg |
                                is_nonneg(r) -> (not below(r, ZERO))
                                [by forall_elim(r) nonneg-not-below-zero]
                              @remainder-not-below-zero |
                                not below(r, ZERO)
                                [by modus_ponens remainder-not-below-zero-if-nonneg remainder-nonneg]
                              @divides-decidable |
                                does_divide(p, a) or (not does_divide(p, a))
                                [by absurd remainder-below-zero remainder-not-below-zero]
                            }
                          @when-remainder-zero |
                            assume r = ZERO {
                              @remainder-zero |
                                r = ZERO
                                [by hypothesis when-remainder-zero]
                              @decomposition-with-zero |
                                a = add(mul(p, q), ZERO)
                                [by rewrite remainder-zero decomposition]
                              @add-zero-right |
                                forall n: Int; add(n, ZERO) = n
                                [by theorem addZeroRight]
                              @product-plus-zero |
                                add(mul(p, q), ZERO) = mul(p, q)
                                [by forall_elim(mul(p, q)) add-zero-right]
                              @a-is-p-times-q |
                                a = mul(p, q)
                                [by rewrite product-plus-zero decomposition-with-zero]
                              @divides-intro |
                                forall n, d, k: Int; n = mul(d, k) -> does_divide(d, n)
                                [by axiom dividesIntro]
                              @p-divides-a-if-product |
                                a = mul(p, q) -> does_divide(p, a)
                                [by forall_elim(a, p, q) divides-intro]
                              @p-divides-a |
                                does_divide(p, a)
                                [by modus_ponens p-divides-a-if-product a-is-p-times-q]
                              @divides-decidable |
                                does_divide(p, a) or (not does_divide(p, a))
                                [by or_intro_left p-divides-a]
                            }
                          @when-remainder-positive |
                            assume below(ZERO, r) {
                              @remainder-positive |
                                below(ZERO, r)
                                [by hypothesis when-remainder-positive]
                              @given-p-divides-a |
                                assume does_divide(p, a) {
                                  @p-divides-a |
                                    does_divide(p, a)
                                    [by hypothesis given-p-divides-a]
                                  @divides-elim |
                                    forall d, n: Int; does_divide(d, n) -> exists k: Int; n = mul(d, k)
                                    [by axiom dividesElim]
                                  @quotient-of-a-exists |
                                    does_divide(p, a) -> exists k: Int; a = mul(p, k)
                                    [by forall_elim(p, a) divides-elim]
                                  @exact-quotient-exists |
                                    exists k: Int; a = mul(p, k)
                                    [by modus_ponens quotient-of-a-exists p-divides-a]
                                  @with-exact-quotient-m |
                                    unpack m: Int from exact-quotient-exists {
                                      @a-is-p-times-m |
                                        a = mul(p, m)
                                        [by hypothesis with-exact-quotient-m]
                                      @add-zero-right |
                                        forall n: Int; add(n, ZERO) = n
                                        [by theorem addZeroRight]
                                      @product-m-plus-zero |
                                        add(mul(p, m), ZERO) = mul(p, m)
                                        [by forall_elim(mul(p, m)) add-zero-right]
                                      @product-m-is-sum |
                                        mul(p, m) = add(mul(p, m), ZERO)
                                        [by symmetry product-m-plus-zero]
                                      @a-is-p-times-m-plus-zero |
                                        a = add(mul(p, m), ZERO)
                                        [by rewrite product-m-is-sum a-is-p-times-m]
                                      @zero-is-nonneg |
                                        is_nonneg(ZERO)
                                        [by axiom nonnegZero]
                                      @uniqueness |
                                        forall x, y, q1, r1, q2, r2: Int; below(ZERO, y) -> x = add(mul(y, q1), r1) -> is_nonneg(r1) -> below(r1, y) -> x = add(mul(y, q2), r2) -> is_nonneg(r2) -> below(r2, y) -> (q1 = q2 and r1 = r2)
                                        [by theorem divisionAlgorithmUnique]
                                      @uniqueness-for-a |
                                        below(ZERO, p) -> a = add(mul(p, q), r) -> is_nonneg(r) -> below(r, p) -> a = add(mul(p, m), ZERO) -> is_nonneg(ZERO) -> below(ZERO, p) -> (q = m and r = ZERO)
                                        [by forall_elim(a, p, q, r, m, ZERO) uniqueness]
                                      @quotient-and-remainder-agree |
                                        q = m and r = ZERO
                                        [by tautology uniqueness-for-a p-positive decomposition remainder-nonneg remainder-below-p a-is-p-times-m-plus-zero zero-is-nonneg]
                                      @remainder-is-zero |
                                        r = ZERO
                                        [by and_elim_right quotient-and-remainder-agree]
                                      @zero-below-zero |
                                        below(ZERO, ZERO)
                                        [by rewrite remainder-is-zero remainder-positive]
                                      @less-than-irreflexive |
                                        forall n: Int; not below(n, n)
                                        [by theorem lessThanIrreflexive]
                                      @zero-not-below-zero |
                                        not below(ZERO, ZERO)
                                        [by forall_elim(ZERO) less-than-irreflexive]
                                      @contradiction |
                                        not does_divide(p, a)
                                        [by absurd zero-below-zero zero-not-below-zero]
                                    }
                                  @p-does-not-divide-a-inner |
                                    not does_divide(p, a)
                                    [by exists_elim with-exact-quotient-m]
                                }
                              @p-does-not-divide-a |
                                not does_divide(p, a)
                                [by not_intro given-p-divides-a p-divides-a p-does-not-divide-a-inner]
                              @divides-decidable |
                                does_divide(p, a) or (not does_divide(p, a))
                                [by or_intro_right p-does-not-divide-a]
                            }
                        }
                    }
                  @divides-decidable |
                    does_divide(p, a) or (not does_divide(p, a))
                    [by exists_elim with-remainder-r]
                }
              @divides-decidable |
                does_divide(p, a) or (not does_divide(p, a))
                [by exists_elim with-quotient-q]
            }
          @positive-p-gives-decidable |
            below(ZERO, p) -> (does_divide(p, a) or (not does_divide(p, a)))
            [by implies_intro given-p-positive]
        }
      @discharge-a |
        forall a: Int; below(ZERO, p) -> (does_divide(p, a) or (not does_divide(p, a)))
        [by forall_intro generalize-a]
    }
  @conclusion |
    forall p, a: Int; below(ZERO, p) -> (does_divide(p, a) or (not does_divide(p, a)))
    [by forall_intro generalize-p]
qed
```

The bridge from primality to Bézout's coprimality hypothesis. Judson takes
`gcd(a, p) = 1` for granted when `p ∤ a`; over `ℤ` the common divisors come with
signs, so we prove it: any common divisor `e` of `a` and `p` is `±1`. Trichotomy
splits `e`. If `e > 0`, primality gives `e = 1` or `e = p`, and `e = p` would
make `p | a` (via `e | a`), against the hypothesis — so `e = 1`. If `e < 0`,
`neg(e) > 0` divides both (`negDivides`), so the same argument gives `neg(e) = 1`,
i.e. `e = -1`. And `e = 0` is impossible, since `0 | p` forces `p = 0 < p`.

```bpa
theorem coprimalityFromPrime: forall p, a: Int;
  below(ZERO, p)
  -> (forall d: Int; below(ZERO, d) -> does_divide(d, p) -> (d = ONE or d = p))
  -> (not does_divide(p, a))
  -> (forall e: Int; does_divide(e, a) -> does_divide(e, p) -> (e = ONE or e = neg(ONE)))
proof
  @generalize-p |
    fix p: Int {
      @generalize-a |
        fix a: Int {
          @given-p-positive |
            assume below(ZERO, p) {
              @given-p-prime |
                assume forall d: Int; below(ZERO, d) -> does_divide(d, p) -> (d = ONE or d = p) {
                  @given-p-not-divide-a |
                    assume not does_divide(p, a) {
                      @p-positive |
                        below(ZERO, p)
                        [by hypothesis given-p-positive]
                      @only-positive-divisors-are-one-and-p |
                        forall d: Int; below(ZERO, d) -> does_divide(d, p) -> (d = ONE or d = p)
                        [by hypothesis given-p-prime]
                      @p-does-not-divide-a |
                        not does_divide(p, a)
                        [by hypothesis given-p-not-divide-a]
                      @common-divisors-are-units |
                        fix e: Int {
                          @given-e-divides-a |
                            assume does_divide(e, a) {
                              @given-e-divides-p |
                                assume does_divide(e, p) {
                                  @e-divides-a |
                                    does_divide(e, a)
                                    [by hypothesis given-e-divides-a]
                                  @e-divides-p |
                                    does_divide(e, p)
                                    [by hypothesis given-e-divides-p]
                                  @trichotomy-of-e |
                                    forall x, y: Int; below(x, y) or x = y or below(y, x)
                                    [by theorem trichotomy]
                                  @e-against-zero |
                                    below(e, ZERO) or e = ZERO or below(ZERO, e)
                                    [by forall_elim(e, ZERO) trichotomy-of-e]
                                  @e-is-unit |
                                    e = ONE or e = neg(ONE)
                                    case on e-against-zero {
                                      @when-e-negative |
                                        assume below(e, ZERO) {
                                          @e-negative |
                                            below(e, ZERO)
                                            [by hypothesis when-e-negative]
                                          @negation-of-negative-is-positive |
                                            forall x: Int; below(x, ZERO) -> below(ZERO, neg(x))
                                            [by theorem positiveOfNegative]
                                          @neg-e-positive-if-e-negative |
                                            below(e, ZERO) -> below(ZERO, neg(e))
                                            [by forall_elim(e) negation-of-negative-is-positive]
                                          @neg-e-is-positive |
                                            below(ZERO, neg(e))
                                            [by modus_ponens neg-e-positive-if-e-negative e-negative]
                                          @neg-divides |
                                            forall x, n: Int; does_divide(x, n) -> does_divide(neg(x), n)
                                            [by theorem negDivides]
                                          @neg-e-divides-p-if-e-divides |
                                            does_divide(e, p) -> does_divide(neg(e), p)
                                            [by forall_elim(e, p) neg-divides]
                                          @neg-e-divides-p |
                                            does_divide(neg(e), p)
                                            [by modus_ponens neg-e-divides-p-if-e-divides e-divides-p]
                                          @neg-e-divides-a-if-e-divides |
                                            does_divide(e, a) -> does_divide(neg(e), a)
                                            [by forall_elim(e, a) neg-divides]
                                          @neg-e-divides-a |
                                            does_divide(neg(e), a)
                                            [by modus_ponens neg-e-divides-a-if-e-divides e-divides-a]
                                          @primality-at-neg-e |
                                            below(ZERO, neg(e)) -> does_divide(neg(e), p) -> (neg(e) = ONE or neg(e) = p)
                                            [by forall_elim(neg(e)) only-positive-divisors-are-one-and-p]
                                          @neg-e-is-one-or-p |
                                            neg(e) = ONE or neg(e) = p
                                            [by tautology primality-at-neg-e neg-e-is-positive neg-e-divides-p]
                                          @e-is-unit |
                                            e = ONE or e = neg(ONE)
                                            case on neg-e-is-one-or-p {
                                              @when-neg-e-is-one |
                                                assume neg(e) = ONE {
                                                  // neg(e)=1 => e = neg(neg(e)) = neg(1).
                                                  @neg-e-is-one |
                                                    neg(e) = ONE
                                                    [by hypothesis when-neg-e-is-one]
                                                  @neg-neg-is-identity |
                                                    forall n: Int; neg(neg(n)) = n
                                                    [by theorem negNeg]
                                                  @e-is-neg-neg-e |
                                                    neg(neg(e)) = e
                                                    [by forall_elim(e) neg-neg-is-identity]
                                                  @neg-one-is-e |
                                                    neg(ONE) = e
                                                    [by rewrite neg-e-is-one e-is-neg-neg-e]
                                                  @e-is-neg-one |
                                                    e = neg(ONE)
                                                    [by symmetry neg-one-is-e]
                                                  @e-is-unit |
                                                    e = ONE or e = neg(ONE)
                                                    [by or_intro_right e-is-neg-one]
                                                }
                                              @when-neg-e-is-p |
                                                assume neg(e) = p {
                                                  // neg(e)=p and neg(e)|a => p|a, contradiction.
                                                  @neg-e-is-p |
                                                    neg(e) = p
                                                    [by hypothesis when-neg-e-is-p]
                                                  @p-divides-a |
                                                    does_divide(p, a)
                                                    [by rewrite neg-e-is-p neg-e-divides-a]
                                                  @e-is-unit |
                                                    e = ONE or e = neg(ONE)
                                                    [by absurd p-divides-a p-does-not-divide-a]
                                                }
                                            }
                                        }
                                      @when-e-zero |
                                        assume e = ZERO {
                                          // e=0 and e|p => p = 0*k = 0, but p>0 is irreflexive-absurd.
                                          @e-is-zero |
                                            e = ZERO
                                            [by hypothesis when-e-zero]
                                          @zero-divides-p |
                                            does_divide(ZERO, p)
                                            [by rewrite e-is-zero e-divides-p]
                                          @divides-elim |
                                            forall d, n: Int; does_divide(d, n) -> exists k: Int; n = mul(d, k)
                                            [by axiom dividesElim]
                                          @quotient-of-p-by-zero-exists |
                                            does_divide(ZERO, p) -> exists k: Int; p = mul(ZERO, k)
                                            [by forall_elim(ZERO, p) divides-elim]
                                          @zero-quotient-exists |
                                            exists k: Int; p = mul(ZERO, k)
                                            [by modus_ponens quotient-of-p-by-zero-exists zero-divides-p]
                                          @with-zero-quotient-k |
                                            unpack k: Int from zero-quotient-exists {
                                              @p-is-zero-times-k |
                                                p = mul(ZERO, k)
                                                [by hypothesis with-zero-quotient-k]
                                              @mul-zero-left |
                                                forall b: Int; mul(ZERO, b) = ZERO
                                                [by axiom mulZeroLeft]
                                              @zero-times-k-is-zero |
                                                mul(ZERO, k) = ZERO
                                                [by forall_elim(k) mul-zero-left]
                                              @p-is-zero |
                                                p = ZERO
                                                [by rewrite zero-times-k-is-zero p-is-zero-times-k]
                                              @zero-is-positive |
                                                below(ZERO, ZERO)
                                                [by rewrite p-is-zero p-positive]
                                              @less-than-irreflexive |
                                                forall n: Int; not below(n, n)
                                                [by theorem lessThanIrreflexive]
                                              @zero-not-below-zero |
                                                not below(ZERO, ZERO)
                                                [by forall_elim(ZERO) less-than-irreflexive]
                                              @e-is-unit |
                                                e = ONE or e = neg(ONE)
                                                [by absurd zero-is-positive zero-not-below-zero]
                                            }
                                          @e-is-unit |
                                            e = ONE or e = neg(ONE)
                                            [by exists_elim with-zero-quotient-k]
                                        }
                                      @when-e-positive |
                                        assume below(ZERO, e) {
                                          @e-positive |
                                            below(ZERO, e)
                                            [by hypothesis when-e-positive]
                                          @primality-at-e |
                                            below(ZERO, e) -> does_divide(e, p) -> (e = ONE or e = p)
                                            [by forall_elim(e) only-positive-divisors-are-one-and-p]
                                          @e-is-one-or-p |
                                            e = ONE or e = p
                                            [by tautology primality-at-e e-positive e-divides-p]
                                          @e-is-unit |
                                            e = ONE or e = neg(ONE)
                                            case on e-is-one-or-p {
                                              @when-e-is-one |
                                                assume e = ONE {
                                                  @e-is-one |
                                                    e = ONE
                                                    [by hypothesis when-e-is-one]
                                                  @e-is-unit |
                                                    e = ONE or e = neg(ONE)
                                                    [by or_intro_left e-is-one]
                                                }
                                              @when-e-is-p |
                                                assume e = p {
                                                  @e-is-p |
                                                    e = p
                                                    [by hypothesis when-e-is-p]
                                                  @p-divides-a |
                                                    does_divide(p, a)
                                                    [by rewrite e-is-p e-divides-a]
                                                  @e-is-unit |
                                                    e = ONE or e = neg(ONE)
                                                    [by absurd p-divides-a p-does-not-divide-a]
                                                }
                                            }
                                        }
                                    }
                                }
                              @e-divides-p-gives-unit |
                                does_divide(e, p) -> (e = ONE or e = neg(ONE))
                                [by implies_intro given-e-divides-p]
                            }
                          @e-divides-a-gives-unit |
                            does_divide(e, a) -> does_divide(e, p) -> (e = ONE or e = neg(ONE))
                            [by implies_intro given-e-divides-a]
                        }
                      @common-divisors-are-units-for-all |
                        forall e: Int; does_divide(e, a) -> does_divide(e, p) -> (e = ONE or e = neg(ONE))
                        [by forall_intro common-divisors-are-units]
                    }
                  @not-divide-gives-coprime |
                    (not does_divide(p, a))
                      -> (forall e: Int; does_divide(e, a) -> does_divide(e, p) -> (e = ONE or e = neg(ONE)))
                    [by implies_intro given-p-not-divide-a]
                }
              @prime-gives-coprime |
                (forall d: Int; below(ZERO, d) -> does_divide(d, p) -> (d = ONE or d = p))
                  -> (not does_divide(p, a))
                  -> (forall e: Int; does_divide(e, a) -> does_divide(e, p) -> (e = ONE or e = neg(ONE)))
                [by implies_intro given-p-prime]
            }
          @positive-p-gives-coprime |
            below(ZERO, p)
              -> (forall d: Int; below(ZERO, d) -> does_divide(d, p) -> (d = ONE or d = p))
              -> (not does_divide(p, a))
              -> (forall e: Int; does_divide(e, a) -> does_divide(e, p) -> (e = ONE or e = neg(ONE)))
            [by implies_intro given-p-positive]
        }
      @discharge-a |
        forall a: Int; below(ZERO, p)
          -> (forall d: Int; below(ZERO, d) -> does_divide(d, p) -> (d = ONE or d = p))
          -> (not does_divide(p, a))
          -> (forall e: Int; does_divide(e, a) -> does_divide(e, p) -> (e = ONE or e = neg(ONE)))
        [by forall_intro generalize-a]
    }
  @conclusion |
    forall p, a: Int; below(ZERO, p)
      -> (forall d: Int; below(ZERO, d) -> does_divide(d, p) -> (d = ONE or d = p))
      -> (not does_divide(p, a))
      -> (forall e: Int; does_divide(e, a) -> does_divide(e, p) -> (e = ONE or e = neg(ONE)))
    [by forall_intro generalize-p]
qed
```

**Euclid's Lemma** (Judson, Lemma 2.11). Suppose the prime `p` divides `a·b`.
If `p | a` we are done; otherwise `p ∤ a`, so `a` and `p` are coprime and
`coprimeBezout` yields `r, s` with `a·r + p·s = 1` (the hypotheses `a ≠ 0` and
`p ≠ 0` come from `p ∤ a` — `p | 0` always holds — and from `p > 0`). Multiplying
by `b`, `b = b·1 = b·(a·r + p·s) = (a·b)·r + p·(b·s)`, the last identity the only
elided ring algebra (discharged by `polynomial`). Now `p | (a·b)·r` because
`p | a·b`, and `p | p·(b·s)` because `p | p`; by `dividesAdd` their sum, which is
`b`, is divisible by `p`. So `p | b`.

```bpa
theorem euclidsLemma: forall a, b, p: Int;
  (below(ONE, p) and (forall d: Int; below(ZERO, d) -> does_divide(d, p) -> (d = ONE or d = p)))
  -> does_divide(p, mul(a, b))
  -> (does_divide(p, a) or does_divide(p, b))
proof
  @generalize-a |
    fix a: Int {
      @generalize-b |
        fix b: Int {
          @generalize-p |
            fix p: Int {
              @given-p-prime |
                assume below(ONE, p) and (forall d: Int; below(ZERO, d) -> does_divide(d, p) -> (d = ONE or d = p)) {
                  @given-p-divides-product |
                    assume does_divide(p, mul(a, b)) {
                      @prime-conjunction |
                        below(ONE, p) and (forall d: Int; below(ZERO, d) -> does_divide(d, p) -> (d = ONE or d = p))
                        [by hypothesis given-p-prime]
                      @one-below-p |
                        below(ONE, p)
                        [by and_elim_left prime-conjunction]
                      @only-positive-divisors-are-one-and-p |
                        forall d: Int; below(ZERO, d) -> does_divide(d, p) -> (d = ONE or d = p)
                        [by and_elim_right prime-conjunction]
                      @p-divides-product |
                        does_divide(p, mul(a, b))
                        [by hypothesis given-p-divides-product]
                      // p > 0, from 0 < 1 < p.
                      @zero-below-one |
                        below(ZERO, ONE)
                        [by theorem zeroBelowOne]
                      @less-than-transitive |
                        forall x, y, z: Int; below(x, y) -> below(y, z) -> below(x, z)
                        [by theorem lessThanTransitive]
                      @zero-below-p-if-chained |
                        below(ZERO, ONE) -> below(ONE, p) -> below(ZERO, p)
                        [by forall_elim(ZERO, ONE, p) less-than-transitive]
                      @p-positive |
                        below(ZERO, p)
                        [by tautology zero-below-p-if-chained zero-below-one one-below-p]
                      // decide whether p | a.
                      @divides-decidable |
                        forall x, y: Int; below(ZERO, x) -> (does_divide(x, y) or (not does_divide(x, y)))
                        [by theorem dividesDecidable]
                      @p-divides-a-decidable |
                        below(ZERO, p) -> (does_divide(p, a) or (not does_divide(p, a)))
                        [by forall_elim(p, a) divides-decidable]
                      @p-divides-a-or-not |
                        does_divide(p, a) or (not does_divide(p, a))
                        [by modus_ponens p-divides-a-decidable p-positive]
                      @p-divides-a-or-b |
                        does_divide(p, a) or does_divide(p, b)
                        case on p-divides-a-or-not {
                          @when-p-divides-a |
                            assume does_divide(p, a) {
                              @p-divides-a |
                                does_divide(p, a)
                                [by hypothesis when-p-divides-a]
                              @p-divides-a-or-b |
                                does_divide(p, a) or does_divide(p, b)
                                [by or_intro_left p-divides-a]
                            }
                          @when-p-does-not-divide-a |
                            assume not does_divide(p, a) {
                              @p-does-not-divide-a |
                                not does_divide(p, a)
                                [by hypothesis when-p-does-not-divide-a]
                              // a != 0: else p | 0 = a, against the branch.
                              @given-a-zero |
                                assume a = ZERO {
                                  @a-is-zero |
                                    a = ZERO
                                    [by hypothesis given-a-zero]
                                  @zero-is-p-times-zero |
                                    ZERO = mul(p, ZERO)
                                    [by simplify mulZeroRight]
                                  @a-is-p-times-zero |
                                    a = mul(p, ZERO)
                                    [by rewrite zero-is-p-times-zero a-is-zero]
                                  @divides-intro |
                                    forall n, d, k: Int; n = mul(d, k) -> does_divide(d, n)
                                    [by axiom dividesIntro]
                                  @p-divides-a-if-product |
                                    a = mul(p, ZERO) -> does_divide(p, a)
                                    [by forall_elim(a, p, ZERO) divides-intro]
                                  @p-divides-a |
                                    does_divide(p, a)
                                    [by modus_ponens p-divides-a-if-product a-is-p-times-zero]
                                  @a-not-zero-inner |
                                    a != ZERO
                                    [by absurd p-divides-a p-does-not-divide-a]
                                }
                              @a-not-zero |
                                a != ZERO
                                [by not_intro given-a-zero a-is-zero a-not-zero-inner]
                              // p != 0, from p > 0.
                              @given-p-zero |
                                assume p = ZERO {
                                  @p-is-zero |
                                    p = ZERO
                                    [by hypothesis given-p-zero]
                                  @zero-below-zero |
                                    below(ZERO, ZERO)
                                    [by rewrite p-is-zero p-positive]
                                  @less-than-irreflexive |
                                    forall n: Int; not below(n, n)
                                    [by theorem lessThanIrreflexive]
                                  @zero-not-below-zero |
                                    not below(ZERO, ZERO)
                                    [by forall_elim(ZERO) less-than-irreflexive]
                                  @p-not-zero-inner |
                                    p != ZERO
                                    [by absurd zero-below-zero zero-not-below-zero]
                                }
                              @p-not-zero |
                                p != ZERO
                                [by not_intro given-p-zero p-is-zero p-not-zero-inner]
                              // a and p are coprime.
                              @coprimality-from-prime |
                                forall q, x: Int; below(ZERO, q) -> (forall d: Int; below(ZERO, d) -> does_divide(d, q) -> (d = ONE or d = q)) -> (not does_divide(q, x)) -> (forall e: Int; does_divide(e, x) -> does_divide(e, q) -> (e = ONE or e = neg(ONE)))
                                [by theorem coprimalityFromPrime]
                              @coprimality-for-a-and-p |
                                below(ZERO, p) -> (forall d: Int; below(ZERO, d) -> does_divide(d, p) -> (d = ONE or d = p)) -> (not does_divide(p, a)) -> (forall e: Int; does_divide(e, a) -> does_divide(e, p) -> (e = ONE or e = neg(ONE)))
                                [by forall_elim(p, a) coprimality-from-prime]
                              @a-and-p-coprime |
                                forall e: Int; does_divide(e, a) -> does_divide(e, p) -> (e = ONE or e = neg(ONE))
                                [by tautology coprimality-for-a-and-p p-positive only-positive-divisors-are-one-and-p p-does-not-divide-a]
                              // Bezout: a*r + p*s = 1.
                              @bezout-identity |
                                forall x, y: Int; x != ZERO -> y != ZERO -> (forall e: Int; does_divide(e, x) -> does_divide(e, y) -> (e = ONE or e = neg(ONE))) -> exists r: Int; exists s: Int; add(mul(x, r), mul(y, s)) = ONE
                                [by theorem coprimeBezout]
                              @bezout-for-a-and-p |
                                a != ZERO -> p != ZERO -> (forall e: Int; does_divide(e, a) -> does_divide(e, p) -> (e = ONE or e = neg(ONE))) -> exists r: Int; exists s: Int; add(mul(a, r), mul(p, s)) = ONE
                                [by forall_elim(a, p) bezout-identity]
                              @bezout-coefficients-exist |
                                exists r: Int; exists s: Int; add(mul(a, r), mul(p, s)) = ONE
                                [by tautology bezout-for-a-and-p a-not-zero p-not-zero a-and-p-coprime]
                              @with-bezout-r |
                                unpack r: Int from bezout-coefficients-exist {
                                  @bezout-s-exists |
                                    exists s: Int; add(mul(a, r), mul(p, s)) = ONE
                                    [by hypothesis with-bezout-r]
                                  @with-bezout-s |
                                    unpack s: Int from bezout-s-exists {
                                      @bezout-holds |
                                        add(mul(a, r), mul(p, s)) = ONE
                                        [by hypothesis with-bezout-s]
                                      // b = b*1 = b*(a*r + p*s) = (a*b)*r + p*(b*s).
                                      @mul-one-right |
                                        forall n: Int; mul(n, ONE) = n
                                        [by theorem mulOneRight]
                                      @b-times-one-is-b |
                                        mul(b, ONE) = b
                                        [by forall_elim(b) mul-one-right]
                                      @b-is-b-times-one |
                                        b = mul(b, ONE)
                                        [by symmetry b-times-one-is-b]
                                      @one-is-bezout |
                                        ONE = add(mul(a, r), mul(p, s))
                                        [by symmetry bezout-holds]
                                      @b-is-b-times-bezout |
                                        b = mul(b, add(mul(a, r), mul(p, s)))
                                        [by rewrite one-is-bezout b-is-b-times-one]
                                      @product-distributes |
                                        mul(b, add(mul(a, r), mul(p, s))) = add(mul(mul(a, b), r), mul(p, mul(b, s)))
                                        [by polynomial]
                                      @b-splits-into-product-and-p-multiple |
                                        b = add(mul(mul(a, b), r), mul(p, mul(b, s)))
                                        [by rewrite product-distributes b-is-b-times-bezout]
                                      // p | (a*b)*r, since p | a*b.
                                      @divides-mul |
                                        forall d, x, c: Int; does_divide(d, x) -> does_divide(d, mul(x, c))
                                        [by theorem dividesMul]
                                      @p-divides-product-times-r-if |
                                        does_divide(p, mul(a, b)) -> does_divide(p, mul(mul(a, b), r))
                                        [by forall_elim(p, mul(a, b), r) divides-mul]
                                      @p-divides-product-times-r |
                                        does_divide(p, mul(mul(a, b), r))
                                        [by modus_ponens p-divides-product-times-r-if p-divides-product]
                                      // p | p*(b*s), since p | p.
                                      @divides-refl |
                                        forall d: Int; does_divide(d, d)
                                        [by theorem dividesRefl]
                                      @p-divides-p |
                                        does_divide(p, p)
                                        [by forall_elim(p) divides-refl]
                                      @p-divides-p-times-bs-if |
                                        does_divide(p, p) -> does_divide(p, mul(p, mul(b, s)))
                                        [by forall_elim(p, p, mul(b, s)) divides-mul]
                                      @p-divides-p-times-bs |
                                        does_divide(p, mul(p, mul(b, s)))
                                        [by modus_ponens p-divides-p-times-bs-if p-divides-p]
                                      // p | their sum, which is b.
                                      @divides-add |
                                        forall d, x, y: Int; does_divide(d, x) -> does_divide(d, y) -> does_divide(d, add(x, y))
                                        [by theorem dividesAdd]
                                      @p-divides-sum-if |
                                        does_divide(p, mul(mul(a, b), r)) -> does_divide(p, mul(p, mul(b, s))) -> does_divide(p, add(mul(mul(a, b), r), mul(p, mul(b, s))))
                                        [by forall_elim(p, mul(mul(a, b), r), mul(p, mul(b, s))) divides-add]
                                      @p-divides-sum |
                                        does_divide(p, add(mul(mul(a, b), r), mul(p, mul(b, s))))
                                        [by tautology p-divides-sum-if p-divides-product-times-r p-divides-p-times-bs]
                                      @sum-is-b |
                                        add(mul(mul(a, b), r), mul(p, mul(b, s))) = b
                                        [by symmetry b-splits-into-product-and-p-multiple]
                                      @p-divides-b |
                                        does_divide(p, b)
                                        [by rewrite sum-is-b p-divides-sum]
                                      @p-divides-a-or-b |
                                        does_divide(p, a) or does_divide(p, b)
                                        [by or_intro_right p-divides-b]
                                    }
                                  @p-divides-a-or-b |
                                    does_divide(p, a) or does_divide(p, b)
                                    [by exists_elim with-bezout-s]
                                }
                              @p-divides-a-or-b |
                                does_divide(p, a) or does_divide(p, b)
                                [by exists_elim with-bezout-r]
                            }
                        }
                    }
                  @product-implies-divides-factor |
                    does_divide(p, mul(a, b)) -> (does_divide(p, a) or does_divide(p, b))
                    [by implies_intro given-p-divides-product]
                }
              @prime-implies-divides-factor |
                (below(ONE, p) and (forall d: Int; below(ZERO, d) -> does_divide(d, p) -> (d = ONE or d = p)))
                  -> does_divide(p, mul(a, b)) -> (does_divide(p, a) or does_divide(p, b))
                [by implies_intro given-p-prime]
            }
          @discharge-p |
            forall p: Int; (below(ONE, p) and (forall d: Int; below(ZERO, d) -> does_divide(d, p) -> (d = ONE or d = p))) -> does_divide(p, mul(a, b)) -> (does_divide(p, a) or does_divide(p, b))
            [by forall_intro generalize-p]
        }
      @discharge-b |
        forall b, p: Int; (below(ONE, p) and (forall d: Int; below(ZERO, d) -> does_divide(d, p) -> (d = ONE or d = p))) -> does_divide(p, mul(a, b)) -> (does_divide(p, a) or does_divide(p, b))
        [by forall_intro generalize-b]
    }
  @conclusion |
    forall a, b, p: Int; (below(ONE, p) and (forall d: Int; below(ZERO, d) -> does_divide(d, p) -> (d = ONE or d = p))) -> does_divide(p, mul(a, b)) -> (does_divide(p, a) or does_divide(p, b))
    [by forall_intro generalize-a]
qed
```

### The Infinitude of Primes

Euclid's classical argument (Judson, Theorem 2.12) is the intended capstone:
were there only finitely many primes `p₁, …, pₙ`, the number
`P = p₁·p₂·⋯·pₙ + 1` is divisible by no `pᵢ` — each `pᵢ` divides the product
`p₁·⋯·pₙ`, so if it also divided `P` it would divide `P − (product) = 1`, which
is impossible. Hence `P` has a prime factor outside the list, contradicting
completeness. The finite product is exactly what `std/integer-sequence.bpa`
reifies: a complete enumeration of primes is a `Seq`, `productUpTo(primes, n)` is
`p₁·⋯·pₙ`, and `everyEntryDividesProduct` (imported above) is precisely the step
"each `pᵢ` divides the product".

Formalizing the *contradiction* form nonetheless needs two ingredients this
chapter does not yet build, and which are each a well-ordering-scale development
in their own right:

1. **Every integer `> 1` has a prime divisor.** This is a strong-induction /
   well-ordering argument (the least divisor exceeding `1` is prime), on the
   order of `divisionAlgorithmExists` in `std/integer-division.bpa`. Without it
   we cannot exhibit the prime factor of `P`.
2. **A reflection principle tying the abstract `Seq` to "all primes".** The
   contradiction hypothesis "`primes` enumerates *every* prime" must be stated so
   that the new prime factor of `P`, once produced, is forced to be some
   `at(primes, i)` with `i` below the count — the membership fact that
   `everyEntryDividesProduct` then consumes.

Both are self-contained and orthogonal to Euclid's Lemma; landing them (a
`primeFactorExists` well-ordering theorem, plus the enumeration predicate) is the
natural next Ch2-D increment. The sequence library and `everyEntryDividesProduct`
are staged here so that step is a direct continuation rather than a rebuild. We
therefore record the infinitude of primes as the stated theorem above and defer
its `bpa` proof, rather than leave a placeholder in the checked file.

## The Euclidean Algorithm

Judson closes §2.2 with the **Euclidean Algorithm**: to compute `gcd(a, b)`
concretely, repeatedly apply the Division Algorithm — `a = bq₁ + r₁`,
`b = r₁q₂ + r₂`, `r₁ = r₂q₃ + r₃`, … — until a zero remainder is reached; the
last nonzero remainder is `gcd(a, b)`, and back-substituting up the chain recovers
the Bézout coefficients `r`, `s` of the previous theorem. This is a *computation*
on particular integers rather than a universally-quantified statement, so we do
not transcribe a numeric instance here; `bezout` already establishes, for every
nonzero `a`, `b`, the existence and defining properties of the gcd that the
algorithm computes.

```bpa
// The Euclidean Algorithm (illustrative, not transcribed):

// It terminates because the nonnegative remainders strictly decrease
// (Well-Ordering), and back-substitution through the division steps yields the
// Bézout coefficients r, s with gcd(a, b) = a*r + b*s established by `bezout`.
```
