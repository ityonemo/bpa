# The Integers — Primes

A literate `bpa` transliteration of **Chapter 2 ("The Integers"), §2.2 (Greatest
Common Divisors and Primes)** of Thomas W. Judson's *Abstract Algebra* (source:
`vendor/aata/src/integers.xml`; © 1997–2026 Judson, GFDL 1.3). Run
`bpa check aata/2.3-primes.md`.

This section proves the **GCD / Bézout theorem** and its **coprime corollary**,
following Judson's argument. They build on the Division Algorithm proved in
`std/integer-division.bpa` (§2.2). We bring in that library, the ℤ order,
divisibility, and the Well-Ordering schema, naming the arithmetic vocabulary
this section will use. Because there is no `gcd` function, we *characterize* the
greatest common divisor by its defining properties (positive, a common divisor,
divisible by every common divisor).

A positive integer is in particular nonnegative — the fact that lets the
Well-Ordering schema's guard (`is_nonneg`) be discharged from `below(ZERO, x)`.
Unfolding `below(ZERO, x)` gives a nonnegative gap `d` with `ZERO + succ(d) = x`;
since `add(ZERO, succ(d)) = succ(d)` and the successor of a nonnegative is
nonnegative, `x` itself is nonnegative.

```bpa
theorem positiveIsNonneg: forall x: Int; below(ZERO, x) -> is_nonneg(x)
proof
  @generalize-x |
    fix x: Int {
      @given-x-positive |
        assume below(ZERO, x) {
          @x-positive |
            below(ZERO, x)
            [by hypothesis given-x-positive]
          @less-than-elim |
            forall a, b: Int; below(a, b) -> exists d: Int; is_nonneg(d) and add(a, succ(d)) = b
            [by axiom lessThanElim]
          @less-than-elim-at-zero-x |
            below(ZERO, x) -> exists d: Int; is_nonneg(d) and add(ZERO, succ(d)) = x
            [by forall_elim(ZERO, x) less-than-elim]
          @gap-exists |
            exists d: Int; is_nonneg(d) and add(ZERO, succ(d)) = x
            [by modus_ponens less-than-elim-at-zero-x x-positive]
          @with-gap-d |
            unpack d: Int from gap-exists {
              @gap-nonneg-and-sums |
                is_nonneg(d) and add(ZERO, succ(d)) = x
                [by hypothesis with-gap-d]
              @gap-nonneg |
                is_nonneg(d)
                [by and_elim_left gap-nonneg-and-sums]
              @gap-sums-to-x |
                add(ZERO, succ(d)) = x
                [by and_elim_right gap-nonneg-and-sums]
              @add-zero-left |
                forall n: Int; add(ZERO, n) = n
                [by axiom addZeroLeft]
              @zero-plus-succ-is-succ |
                add(ZERO, succ(d)) = succ(d)
                [by forall_elim(succ(d)) add-zero-left]
              @succ-gap-is-x |
                succ(d) = x
                [by rewrite zero-plus-succ-is-succ gap-sums-to-x]
              @nonneg-succ |
                forall n: Int; is_nonneg(n) -> is_nonneg(succ(n))
                [by axiom nonnegSucc]
              @succ-of-nonneg-is-nonneg |
                is_nonneg(d) -> is_nonneg(succ(d))
                [by forall_elim(d) nonneg-succ]
              @succ-gap-nonneg |
                is_nonneg(succ(d))
                [by modus_ponens succ-of-nonneg-is-nonneg gap-nonneg]
              @conclusion-x-nonneg |
                is_nonneg(x)
                [by rewrite succ-gap-is-x succ-gap-nonneg]
            }
          @x-nonneg |
            is_nonneg(x)
            [by exists_elim with-gap-d]
        }
      @positive-implies-nonneg |
        below(ZERO, x) -> is_nonneg(x)
        [by implies_intro given-x-positive]
    }
  @conclusion |
    forall x: Int; below(ZERO, x) -> is_nonneg(x)
    [by forall_intro generalize-x]
qed
```

The Bézout argument will, at its crux, learn of a remainder `r'` that is both
nonnegative and *not* positive, and must conclude `r' = ZERO`. A nonnegative
integer splits (`nonnegCases`) into `ZERO` or a successor `succ(m)` of a
nonnegative `m`; a successor is positive (`add(ZERO, succ(m)) = succ(m)`, so
`lessThanIntro` gives `below(ZERO, succ(m))`), so if the integer is *not*
positive the successor case is impossible and it must be `ZERO`.

```bpa
theorem nonnegNotPositiveIsZero: forall x: Int; is_nonneg(x) -> (not below(ZERO, x)) -> x = ZERO
proof
  @generalize-x |
    fix x: Int {
      @given-x-nonneg |
        assume is_nonneg(x) {
          @given-x-not-positive |
            assume not below(ZERO, x) {
              @x-nonneg |
                is_nonneg(x)
                [by hypothesis given-x-nonneg]
              @x-not-positive |
                not below(ZERO, x)
                [by hypothesis given-x-not-positive]
              @nonneg-cases |
                forall n: Int; is_nonneg(n) -> (n = ZERO or (exists m: Int; is_nonneg(m) and n = succ(m)))
                [by theorem nonnegCases]
              @x-cases-if-nonneg |
                is_nonneg(x) -> (x = ZERO or (exists m: Int; is_nonneg(m) and x = succ(m)))
                [by forall_elim(x) nonneg-cases]
              @x-zero-or-successor |
                x = ZERO or (exists m: Int; is_nonneg(m) and x = succ(m))
                [by modus_ponens x-cases-if-nonneg x-nonneg]
              @conclusion-x-is-zero |
                x = ZERO
                case on x-zero-or-successor {
                  @when-x-is-zero |
                    assume x = ZERO {
                      @conclusion-x-is-zero |
                        x = ZERO
                        [by hypothesis when-x-is-zero]
                    }
                  @when-x-is-successor |
                    assume exists m: Int; is_nonneg(m) and x = succ(m) {
                      @successor-exists |
                        exists m: Int; is_nonneg(m) and x = succ(m)
                        [by hypothesis when-x-is-successor]
                      @with-predecessor-m |
                        unpack m: Int from successor-exists {
                          @gap-nonneg-and-x-is-successor |
                            is_nonneg(m) and x = succ(m)
                            [by hypothesis with-predecessor-m]
                          @gap-nonneg |
                            is_nonneg(m)
                            [by and_elim_left gap-nonneg-and-x-is-successor]
                          @x-is-successor |
                            x = succ(m)
                            [by and_elim_right gap-nonneg-and-x-is-successor]
                          @add-zero-left |
                            forall n: Int; add(ZERO, n) = n
                            [by axiom addZeroLeft]
                          @zero-plus-successor-is-successor |
                            add(ZERO, succ(m)) = succ(m)
                            [by forall_elim(succ(m)) add-zero-left]
                          @successor-is-x |
                            succ(m) = x
                            [by symmetry x-is-successor]
                          @zero-plus-successor-is-x |
                            add(ZERO, succ(m)) = x
                            [by rewrite successor-is-x zero-plus-successor-is-successor]
                          @less-than-intro |
                            forall a, d, b: Int; is_nonneg(d) -> add(a, succ(d)) = b -> below(a, b)
                            [by axiom lessThanIntro]
                          @successor-is-positive-if-summed |
                            is_nonneg(m) -> add(ZERO, succ(m)) = x -> below(ZERO, x)
                            [by forall_elim(ZERO, m, x) less-than-intro]
                          @x-is-positive |
                            below(ZERO, x)
                            [by tautology successor-is-positive-if-summed gap-nonneg zero-plus-successor-is-x]
                          @conclusion-x-is-zero |
                            x = ZERO
                            [by absurd x-is-positive x-not-positive]
                        }
                      @conclusion-x-is-zero |
                        x = ZERO
                        [by exists_elim with-predecessor-m]
                    }
                }
            }
          @not-positive-implies-zero |
            (not below(ZERO, x)) -> x = ZERO
            [by implies_intro given-x-not-positive]
        }
      @nonneg-implies-not-positive-implies-zero |
        is_nonneg(x) -> (not below(ZERO, x)) -> x = ZERO
        [by implies_intro given-x-nonneg]
    }
  @conclusion |
    forall x: Int; is_nonneg(x) -> (not below(ZERO, x)) -> x = ZERO
    [by forall_intro generalize-x]
qed
```

Judson's nonemptiness argument splits on the sign of `a`: when `a` is positive
the witness `a·1 + b·0 = a` is a positive member; when `a` is negative the
witness `a·(−1) + b·0 = −a` is, and this needs that the negation of a negative
integer is positive. Unfolding `below(a, ZERO)` gives a nonnegative gap `d` with
`add(a, succ(d)) = ZERO`; adding `−a` on the left and cancelling `a` shows
`succ(d) = −a`, and `lessThanIntro` reads `below(ZERO, −a)` off that.

```bpa
theorem negativeNegIsPositive: forall a: Int; below(a, ZERO) -> below(ZERO, neg(a))
proof
  @generalize-a |
    fix a: Int {
      @given-a-negative |
        assume below(a, ZERO) {
          @a-negative |
            below(a, ZERO)
            [by hypothesis given-a-negative]
          @less-than-elim |
            forall x, y: Int; below(x, y) -> exists d: Int; is_nonneg(d) and add(x, succ(d)) = y
            [by axiom lessThanElim]
          @gap-below-a-zero |
            below(a, ZERO) -> exists d: Int; is_nonneg(d) and add(a, succ(d)) = ZERO
            [by forall_elim(a, ZERO) less-than-elim]
          @gap-exists |
            exists d: Int; is_nonneg(d) and add(a, succ(d)) = ZERO
            [by modus_ponens gap-below-a-zero a-negative]
          @with-gap-d |
            unpack d: Int from gap-exists {
              @gap-nonneg-and-sums |
                is_nonneg(d) and add(a, succ(d)) = ZERO
                [by hypothesis with-gap-d]
              @gap-nonneg |
                is_nonneg(d)
                [by and_elim_left gap-nonneg-and-sums]
              @a-plus-successor-is-zero |
                add(a, succ(d)) = ZERO
                [by and_elim_right gap-nonneg-and-sums]
              // succ(d) = -a: add -a on the left and cancel a.
              @neg-a-sum-reflexive |
                add(neg(a), add(a, succ(d))) = add(neg(a), add(a, succ(d)))
                [by reflexivity]
              @neg-a-times-sum-is-neg-a-times-zero |
                add(neg(a), add(a, succ(d))) = add(neg(a), ZERO)
                [by rewrite a-plus-successor-is-zero neg-a-sum-reflexive]
              @add-is-associative |
                forall x, y, z: Int; add(add(x, y), z) = add(x, add(y, z))
                [by theorem addIsAssociative]
              @regroup |
                add(add(neg(a), a), succ(d)) = add(neg(a), add(a, succ(d)))
                [by forall_elim(neg(a), a, succ(d)) add-is-associative]
              @add-neg-left |
                forall n: Int; add(neg(n), n) = ZERO
                [by theorem addNegLeft]
              @neg-a-plus-a-is-zero |
                add(neg(a), a) = ZERO
                [by forall_elim(a) add-neg-left]
              @regroup-with-zero |
                add(ZERO, succ(d)) = add(neg(a), add(a, succ(d)))
                [by rewrite neg-a-plus-a-is-zero regroup]
              @add-zero-left-lemma |
                forall n: Int; add(ZERO, n) = n
                [by axiom addZeroLeft]
              @zero-plus-successor-collapses |
                add(ZERO, succ(d)) = succ(d)
                [by forall_elim(succ(d)) add-zero-left-lemma]
              @cancelled-sum-is-successor |
                add(neg(a), add(a, succ(d))) = succ(d)
                [by rewrite regroup-with-zero zero-plus-successor-collapses]
              @add-zero-right-lemma |
                forall n: Int; add(n, ZERO) = n
                [by theorem addZeroRight]
              @neg-a-plus-zero-is-neg-a |
                add(neg(a), ZERO) = neg(a)
                [by forall_elim(neg(a)) add-zero-right-lemma]
              @successor-is-neg-a-step |
                succ(d) = add(neg(a), ZERO)
                [by rewrite cancelled-sum-is-successor neg-a-times-sum-is-neg-a-times-zero]
              @successor-is-neg-a |
                succ(d) = neg(a)
                [by rewrite neg-a-plus-zero-is-neg-a successor-is-neg-a-step]
              // read below(ZERO, -a) off add(ZERO, succ(d)) = -a.
              @zero-plus-successor-is-neg-a |
                add(ZERO, succ(d)) = neg(a)
                [by rewrite successor-is-neg-a zero-plus-successor-collapses]
              @less-than-intro |
                forall x, e, y: Int; is_nonneg(e) -> add(x, succ(e)) = y -> below(x, y)
                [by axiom lessThanIntro]
              @neg-a-positive-if-summed |
                is_nonneg(d) -> add(ZERO, succ(d)) = neg(a) -> below(ZERO, neg(a))
                [by forall_elim(ZERO, d, neg(a)) less-than-intro]
              @conclusion-neg-a-positive |
                below(ZERO, neg(a))
                [by tautology neg-a-positive-if-summed gap-nonneg zero-plus-successor-is-neg-a]
            }
          @neg-a-positive |
            below(ZERO, neg(a))
            [by exists_elim with-gap-d]
        }
      @negative-implies-neg-positive |
        below(a, ZERO) -> below(ZERO, neg(a))
        [by implies_intro given-a-negative]
    }
  @conclusion |
    forall a: Int; below(a, ZERO) -> below(ZERO, neg(a))
    [by forall_intro generalize-a]
qed
```

The heart of Judson's argument that `d = ar + bs` divides `a` runs the Division
Algorithm to write `a = dq + r'` and shows the remainder `r'` is *itself* a
member of `S`: substituting `d = ar + bs`, Judson computes `r' = a − dq =
a − (ar + bs)q = a(1 − rq) + b(−sq)` in one line. We isolate that elided ring
identity here. From `a = dq + r'` we recover `r' = a − dq` by cancelling `dq`
(via `addDiffReaches` and `addCancelLeft`); substituting `d` and rearranging by
distributing and collecting the `a` and `b` coefficients (`simplify` over the
ring lemmas) gives the member form `r' = a(1 − rq) + b(−sq)`.

```bpa
theorem remainderIsMember(a: Int, b: Int, d: Int, r: Int, s: Int, q: Int, remainder: Int):
  a = add(mul(d, q), remainder) -> d = add(mul(a, r), mul(b, s))
  -> remainder = add(mul(a, sub(ONE, mul(r, q))), mul(b, neg(mul(s, q))))
proof
  @given-a-decomposes |
    assume a = add(mul(d, q), remainder) {
      @given-d-value |
        assume d = add(mul(a, r), mul(b, s)) {
          @a-decomposes |
            a = add(mul(d, q), remainder)
            [by hypothesis given-a-decomposes]
          @d-value |
            d = add(mul(a, r), mul(b, s))
            [by hypothesis given-d-value]
          // remainder = a - dq, by cancelling dq off a = dq + remainder.
          @difference-reaches |
            forall x, y: Int; add(x, sub(y, x)) = y
            [by theorem addDiffReaches]
          @dq-plus-difference-is-a |
            add(mul(d, q), sub(a, mul(d, q))) = a
            [by forall_elim(mul(d, q), a) difference-reaches]
          @dq-plus-difference-is-decomposition |
            add(mul(d, q), sub(a, mul(d, q))) = add(mul(d, q), remainder)
            [by rewrite a-decomposes dq-plus-difference-is-a]
          @cancel-left |
            forall c, x, y: Int; add(c, x) = add(c, y) -> x = y
            [by theorem addCancelLeft]
          @cancel-the-quotient-term |
            add(mul(d, q), sub(a, mul(d, q))) = add(mul(d, q), remainder) -> sub(a, mul(d, q)) = remainder
            [by forall_elim(mul(d, q), sub(a, mul(d, q)), remainder) cancel-left]
          @difference-is-remainder |
            sub(a, mul(d, q)) = remainder
            [by modus_ponens cancel-the-quotient-term dq-plus-difference-is-decomposition]
          @remainder-is-difference |
            remainder = sub(a, mul(d, q))
            [by symmetry difference-is-remainder]
          // substitute d = ar + bs into the difference a - dq.
          @remainder-with-d-expanded |
            remainder = sub(a, mul(add(mul(a, r), mul(b, s)), q))
            [by rewrite d-value remainder-is-difference]
          // the elided algebra: a - (ar + bs)q = a(1 - rq) + b(-sq).
          @difference-collects-coefficients |
            sub(a, mul(add(mul(a, r), mul(b, s)), q)) = add(mul(a, sub(ONE, mul(r, q))), mul(b, neg(mul(s, q))))
            [by simplify subDef mulAddDistribLeft mulAddDistribRight mulNegRight mulOneRight mulIsAssociative addIsAssociative negAdd]
          @conclusion-remainder-is-member |
            remainder = add(mul(a, sub(ONE, mul(r, q))), mul(b, neg(mul(s, q))))
            [by rewrite difference-collects-coefficients remainder-with-d-expanded]
        }
      @d-value-implies-member |
        d = add(mul(a, r), mul(b, s)) -> remainder = add(mul(a, sub(ONE, mul(r, q))), mul(b, neg(mul(s, q))))
        [by implies_intro given-d-value]
    }
  @conclusion |
    a = add(mul(d, q), remainder) -> d = add(mul(a, r), mul(b, s)) -> remainder = add(mul(a, sub(ONE, mul(r, q))), mul(b, neg(mul(s, q))))
    [by implies_intro given-a-decomposes]
qed
```

The coprime corollary will produce a positive common divisor `d` that must equal
`ONE` or `−ONE`; the second alternative is ruled out because `−1` is *below*
zero, so it cannot also be positive. We record that `−1 < 0` here: `−1` is
nonnegatively-gapped below `0` by `succ(ZERO) = ONE`, since
`add(neg(ONE), succ(ZERO)) = add(neg(ONE), ONE) = ZERO`, and `lessThanIntro`
reads `below(neg(ONE), ZERO)` off that.

```bpa
theorem negOneBelowZero: below(neg(ONE), ZERO)
proof
  @one-is-succ-zero |
    ONE = succ(ZERO)
    [by axiom oneIsSuccZero]
  @add-neg-left |
    forall n: Int; add(neg(n), n) = ZERO
    [by theorem addNegLeft]
  @neg-one-plus-one-is-zero |
    add(neg(ONE), ONE) = ZERO
    [by forall_elim(ONE) add-neg-left]
  @neg-one-plus-succ-zero-is-zero |
    add(neg(ONE), succ(ZERO)) = ZERO
    [by rewrite one-is-succ-zero neg-one-plus-one-is-zero]
  @zero-is-nonneg |
    is_nonneg(ZERO)
    [by axiom nonnegZero]
  @less-than-intro |
    forall a, d, b: Int; is_nonneg(d) -> add(a, succ(d)) = b -> below(a, b)
    [by axiom lessThanIntro]
  @neg-one-negative-if-summed |
    is_nonneg(ZERO) -> add(neg(ONE), succ(ZERO)) = ZERO -> below(neg(ONE), ZERO)
    [by forall_elim(neg(ONE), ZERO, ZERO) less-than-intro]
  @conclusion |
    below(neg(ONE), ZERO)
    [by tautology neg-one-negative-if-summed zero-is-nonneg neg-one-plus-succ-zero-is-zero]
qed
```

Before invoking Well-Ordering, Judson must exhibit *some* positive member of
`S = {am + bn : am + bn > 0}` — the set is nonempty because `|a| ∈ S`. Since
`a ≠ 0`, trichotomy splits `a` into positive or negative (the `a = 0` case is
excluded). If `a > 0`, the combination `a·1 + b·0 = a` is a positive member; if
`a < 0`, then `−a > 0` (`negativeNegIsPositive`) and `a·(−1) + b·0 = −a` is a
positive member. Either way the witness is positive, hence nonnegative
(`positiveIsNonneg`), discharging the schema's guard. We package this nonemptiness
as a schema in `a`, `b`, so its conclusion matches the exact shape the
Well-Ordering instance below consumes.

```bpa
theorem combinationSetNonempty(a: Int, b: Int):
  a != ZERO
  -> exists n: Int; is_nonneg(n) and (below(ZERO, n) and (exists mm: Int; exists nn: Int; n = add(mul(a, mm), mul(b, nn))))
proof
  @given-a-nonzero |
    assume a != ZERO {
      @a-nonzero |
        a != ZERO
        [by hypothesis given-a-nonzero]
      @order-is-trichotomous |
        forall x, y: Int; below(x, y) or x = y or below(y, x)
        [by theorem trichotomy]
      @a-sign-split |
        below(a, ZERO) or a = ZERO or below(ZERO, a)
        [by forall_elim(a, ZERO) order-is-trichotomous]
      @conclusion-set-nonempty |
        exists n: Int; is_nonneg(n) and (below(ZERO, n) and (exists mm: Int; exists nn: Int; n = add(mul(a, mm), mul(b, nn))))
        case on a-sign-split {
          @when-a-negative |
            assume below(a, ZERO) {
              @a-negative |
                below(a, ZERO)
                [by hypothesis when-a-negative]
              @negative-neg-is-positive |
                forall x: Int; below(x, ZERO) -> below(ZERO, neg(x))
                [by theorem negativeNegIsPositive]
              @negative-neg-is-positive-at-a |
                below(a, ZERO) -> below(ZERO, neg(a))
                [by forall_elim(a) negative-neg-is-positive]
              @neg-a-positive |
                below(ZERO, neg(a))
                [by modus_ponens negative-neg-is-positive-at-a a-negative]
              @positive-is-nonneg |
                forall x: Int; below(ZERO, x) -> is_nonneg(x)
                [by theorem positiveIsNonneg]
              @positive-is-nonneg-at-neg-a |
                below(ZERO, neg(a)) -> is_nonneg(neg(a))
                [by forall_elim(neg(a)) positive-is-nonneg]
              @neg-a-nonneg |
                is_nonneg(neg(a))
                [by modus_ponens positive-is-nonneg-at-neg-a neg-a-positive]
              @neg-a-is-combination |
                neg(a) = add(mul(a, neg(ONE)), mul(b, ZERO))
                [by simplify mulNegRight mulOneRight mulZeroRight addZeroRight]
              @neg-a-is-some-combination-in-nn |
                exists nn: Int; neg(a) = add(mul(a, neg(ONE)), mul(b, nn))
                [by exists_intro(ZERO) neg-a-is-combination]
              @neg-a-is-a-combination |
                exists mm: Int; exists nn: Int; neg(a) = add(mul(a, mm), mul(b, nn))
                [by exists_intro(neg(ONE)) neg-a-is-some-combination-in-nn]
              @neg-a-positive-and-combination |
                below(ZERO, neg(a)) and (exists mm: Int; exists nn: Int; neg(a) = add(mul(a, mm), mul(b, nn)))
                [by and_intro neg-a-positive neg-a-is-a-combination]
              @neg-a-is-nonneg-member |
                is_nonneg(neg(a)) and (below(ZERO, neg(a)) and (exists mm: Int; exists nn: Int; neg(a) = add(mul(a, mm), mul(b, nn))))
                [by and_intro neg-a-nonneg neg-a-positive-and-combination]
              @conclusion-set-nonempty |
                exists n: Int; is_nonneg(n) and (below(ZERO, n) and (exists mm: Int; exists nn: Int; n = add(mul(a, mm), mul(b, nn))))
                [by exists_intro(neg(a)) neg-a-is-nonneg-member]
            }
          @when-a-zero |
            assume a = ZERO {
              @a-is-zero |
                a = ZERO
                [by hypothesis when-a-zero]
              @conclusion-set-nonempty |
                exists n: Int; is_nonneg(n) and (below(ZERO, n) and (exists mm: Int; exists nn: Int; n = add(mul(a, mm), mul(b, nn))))
                [by absurd a-is-zero a-nonzero]
            }
          @when-a-positive |
            assume below(ZERO, a) {
              @a-positive |
                below(ZERO, a)
                [by hypothesis when-a-positive]
              @positive-is-nonneg |
                forall x: Int; below(ZERO, x) -> is_nonneg(x)
                [by theorem positiveIsNonneg]
              @positive-is-nonneg-at-a |
                below(ZERO, a) -> is_nonneg(a)
                [by forall_elim(a) positive-is-nonneg]
              @a-nonneg |
                is_nonneg(a)
                [by modus_ponens positive-is-nonneg-at-a a-positive]
              @a-is-combination |
                a = add(mul(a, ONE), mul(b, ZERO))
                [by simplify mulOneRight mulZeroRight addZeroRight]
              @a-is-some-combination-in-nn |
                exists nn: Int; a = add(mul(a, ONE), mul(b, nn))
                [by exists_intro(ZERO) a-is-combination]
              @a-is-a-combination |
                exists mm: Int; exists nn: Int; a = add(mul(a, mm), mul(b, nn))
                [by exists_intro(ONE) a-is-some-combination-in-nn]
              @a-positive-and-combination |
                below(ZERO, a) and (exists mm: Int; exists nn: Int; a = add(mul(a, mm), mul(b, nn)))
                [by and_intro a-positive a-is-a-combination]
              @a-is-nonneg-member |
                is_nonneg(a) and (below(ZERO, a) and (exists mm: Int; exists nn: Int; a = add(mul(a, mm), mul(b, nn))))
                [by and_intro a-nonneg a-positive-and-combination]
              @conclusion-set-nonempty |
                exists n: Int; is_nonneg(n) and (below(ZERO, n) and (exists mm: Int; exists nn: Int; n = add(mul(a, mm), mul(b, nn))))
                [by exists_intro(a) a-is-nonneg-member]
            }
        }
    }
  @conclusion |
    a != ZERO
      -> exists n: Int; is_nonneg(n) and (below(ZERO, n) and (exists mm: Int; exists nn: Int; n = add(mul(a, mm), mul(b, nn))))
    [by implies_intro given-a-nonzero]
qed
```

## The GCD / Bézout Theorem

> **Theorem 2.10.** Let $a$ and $b$ be nonzero integers. Then there exist integers
> $r$ and $s$ such that $\gcd(a,b) = ar + bs$. Furthermore, the greatest common
> divisor of $a$ and $b$ is unique.

There is no `gcd` *function* in this development, so we prove the theorem in the
form that *characterizes* the gcd by its defining properties. `bezout` asserts a
single positive integer `d` that (i) divides `a` and `b`, (ii) is divisible by
every common divisor `e`, and (iii) is an integer combination `d = ar + bs`.
Uniqueness is then automatic: any two integers with property (ii) divide each
other, and — being positive — are equal; and (iii) is Bézout's identity itself.

Judson's proof: let `S = {am + bn : am + bn > 0}`. `S` is nonempty
(`combinationSetNonempty`), and every member is positive hence nonnegative, so
Well-Ordering hands us a *least* member `d = ar + bs`. We claim `d = gcd(a,b)`.
Running the Division Algorithm on `a` by `d` gives `a = dq + r'` with
`0 ≤ r' < d`. Were `r' > 0`, the identity `r' = a(1 − rq) + b(−sq)`
(`remainderIsMember`) would make `r'` a *member of `S` smaller than `d`*,
contradicting minimality; so `r' = 0` and `d ∣ a`. Symmetrically `d ∣ b`. Finally
any common divisor `e` of `a`, `b` divides `ar + bs = d`, so `d` is the greatest.

```bpa

  exists d: Int;

  and does_divide(d, a) and does_divide(d, b)
  and (forall e: Int; does_divide(e, a) -> does_divide(e, b) -> does_divide(e, d))

                      // name the coefficients: d = ar + bs.

                        unpack r: Int from d-is-a-combination {

                            exists nn: Int; d = add(mul(a, r), mul(b, nn))

                                            [by theorem lessOrEqualSplit]
                                          @less-or-equal-split-at-d-remainder |
                                            at_most(d, rem2) -> (below(d, rem2) or d = rem2)
                                            [by forall_elim(d, rem2) less-or-equal-split]

                                                    below(d, rem2) -> below(rem2, d) -> below(d, d)
                                                    [by forall_elim(d, rem2, d) less-than-transitive]
                                                  @conclusion-d-below-itself |
                                                    below(d, d)
                                                    [by tautology transitive-at-d-remainder-d d-below-remainder remainder-below-d]
                                                }
                                              @when-d-equals-remainder |
                                                assume d = rem2 {
                                                  @d-equals-remainder |
                                                    d = rem2
                                                    [by hypothesis when-d-equals-remainder]
                                                  @remainder-equals-d |
                                                    rem2 = d
                                                    [by symmetry d-equals-remainder]
                                                  @conclusion-d-below-itself |
                                                    below(d, d)
                                                    [by rewrite remainder-equals-d remainder-below-d]
                                                }
                                            }
                                        }
                                      @remainder-not-positive |
                                        not below(ZERO, rem2)
                                        [by not_intro suppose-remainder-positive remainder-would-be-a-smaller-member d-not-below-itself]
                                      @nonneg-not-positive-forces-zero |
                                        forall x: Int; is_nonneg(x) -> (not below(ZERO, x)) -> x = ZERO
                                        [by theorem nonnegNotPositiveIsZero]
                                      @nonneg-not-positive-is-zero |
                                        is_nonneg(rem2) -> (not below(ZERO, rem2)) -> rem2 = ZERO
                                        [by forall_elim(rem2) nonneg-not-positive-forces-zero]
                                      @remainder-is-zero |
                                        rem2 = ZERO
                                        [by tautology nonneg-not-positive-is-zero remainder-nonneg remainder-not-positive]
                                      @b-is-dq-plus-zero |
                                        b = add(mul(d, q2), ZERO)
                                        [by rewrite remainder-is-zero b-decomposes]
                                      @add-zero-right |
                                        forall n: Int; add(n, ZERO) = n
                                        [by theorem addZeroRight]
                                      @dq-plus-zero-is-dq |
                                        add(mul(d, q2), ZERO) = mul(d, q2)
                                        [by forall_elim(mul(d, q2)) add-zero-right]
                                      @b-is-dq |
                                        b = mul(d, q2)
                                        [by rewrite dq-plus-zero-is-dq b-is-dq-plus-zero]
                                      @divides-intro |
                                        forall n, dd, k: Int; n = mul(dd, k) -> does_divide(dd, n)
                                        [by axiom dividesIntro]
                                      @d-divides-b-if-product |
                                        b = mul(d, q2) -> does_divide(d, b)
                                        [by forall_elim(b, d, q2) divides-intro]
                                      @conclusion-d-divides-b |
                                        does_divide(d, b)
                                        [by modus_ponens d-divides-b-if-product b-is-dq]
                                    }
                                  @conclusion-d-divides-b |
                                    does_divide(d, b)
                                    [by exists_elim with-remainder-of-b]
                                }
                              @d-divides-b |
                                does_divide(d, b)
                                [by exists_elim with-quotient-q2]
                              // any common divisor e divides d = ar + bs.
                              @generalize-e |
                                fix e: Int {
                                  @given-e-divides-a |
                                    assume does_divide(e, a) {
                                      @given-e-divides-b |
                                        assume does_divide(e, b) {
                                          @e-divides-a |
                                            does_divide(e, a)
                                            [by hypothesis given-e-divides-a]
                                          @e-divides-b |
                                            does_divide(e, b)
                                            [by hypothesis given-e-divides-b]
                                          @divides-mul |
                                            forall dd, x, c: Int; does_divide(dd, x) -> does_divide(dd, mul(x, c))
                                            [by theorem dividesMul]
                                          @e-divides-a-times-r |
                                            does_divide(e, a) -> does_divide(e, mul(a, r))
                                            [by forall_elim(e, a, r) divides-mul]
                                          @e-divides-ar |
                                            does_divide(e, mul(a, r))
                                            [by modus_ponens e-divides-a-times-r e-divides-a]
                                          @e-divides-b-times-s |
                                            does_divide(e, b) -> does_divide(e, mul(b, s))
                                            [by forall_elim(e, b, s) divides-mul]
                                          @e-divides-bs |
                                            does_divide(e, mul(b, s))
                                            [by modus_ponens e-divides-b-times-s e-divides-b]
                                          @divides-add |
                                            forall dd, x, y: Int; does_divide(dd, x) -> does_divide(dd, y) -> does_divide(dd, add(x, y))
                                            [by theorem dividesAdd]
                                          @e-divides-sum-if-parts |
                                            does_divide(e, mul(a, r)) -> does_divide(e, mul(b, s)) -> does_divide(e, add(mul(a, r), mul(b, s)))
                                            [by forall_elim(e, mul(a, r), mul(b, s)) divides-add]
                                          @e-divides-combination |
                                            does_divide(e, add(mul(a, r), mul(b, s)))
                                            [by tautology e-divides-sum-if-parts e-divides-ar e-divides-bs]
                                          @combination-is-d |
                                            add(mul(a, r), mul(b, s)) = d
                                            [by symmetry d-equals-combination]
                                          @conclusion-e-divides-d |
                                            does_divide(e, d)
                                            [by rewrite combination-is-d e-divides-combination]
                                        }
                                      @e-divides-b-implies-e-divides-d |
                                        does_divide(e, b) -> does_divide(e, d)
                                        [by implies_intro given-e-divides-b]
                                    }
                                  @e-divides-a-implies-rest |
                                    does_divide(e, a) -> does_divide(e, b) -> does_divide(e, d)
                                    [by implies_intro given-e-divides-a]
                                }
                              @common-divisor-divides-d |
                                forall e: Int; does_divide(e, a) -> does_divide(e, b) -> does_divide(e, d)
                                [by forall_intro generalize-e]
                              // assemble the five defining properties of the gcd.
                              @d-is-some-combination-in-s |
                                exists s2: Int; d = add(mul(a, r), mul(b, s2))
                                [by exists_intro(s) d-equals-combination]
                              @d-is-a-combination-again |
                                exists r2: Int; exists s2: Int; d = add(mul(a, r2), mul(b, s2))
                                [by exists_intro(r) d-is-some-combination-in-s]
                              @d-positive-and-divides-a |
                                below(ZERO, d) and does_divide(d, a)
                                [by and_intro d-is-positive d-divides-a]
                              @d-divides-a-and-b |
                                below(ZERO, d) and does_divide(d, a) and does_divide(d, b)
                                [by and_intro d-positive-and-divides-a d-divides-b]
                              @d-divides-and-greatest |
                                below(ZERO, d) and does_divide(d, a) and does_divide(d, b) and (forall e: Int; does_divide(e, a) -> does_divide(e, b) -> does_divide(e, d))
                                [by and_intro d-divides-a-and-b common-divisor-divides-d]
                              @d-has-all-gcd-properties |
                                below(ZERO, d) and does_divide(d, a) and does_divide(d, b) and (forall e: Int; does_divide(e, a) -> does_divide(e, b) -> does_divide(e, d)) and (exists r2: Int; exists s2: Int; d = add(mul(a, r2), mul(b, s2)))
                                [by and_intro d-divides-and-greatest d-is-a-combination-again]
                              @conclusion-bezout |
                                exists d2: Int; below(ZERO, d2) and does_divide(d2, a) and does_divide(d2, b) and (forall e: Int; does_divide(e, a) -> does_divide(e, b) -> does_divide(e, d2)) and (exists r2: Int; exists s2: Int; d2 = add(mul(a, r2), mul(b, s2)))
                                [by exists_intro(d) d-has-all-gcd-properties]
                            }
                          @conclusion-bezout |
                            exists d2: Int; below(ZERO, d2) and does_divide(d2, a) and does_divide(d2, b) and (forall e: Int; does_divide(e, a) -> does_divide(e, b) -> does_divide(e, d2)) and (exists r2: Int; exists s2: Int; d2 = add(mul(a, r2), mul(b, s2)))
                            [by exists_elim with-coefficient-s]
                        }
                      @conclusion-bezout |
                        exists d2: Int; below(ZERO, d2) and does_divide(d2, a) and does_divide(d2, b) and (forall e: Int; does_divide(e, a) -> does_divide(e, b) -> does_divide(e, d2)) and (exists r2: Int; exists s2: Int; d2 = add(mul(a, r2), mul(b, s2)))
                        [by exists_elim with-coefficient-r]
                    }
                  @conclusion-bezout |
                    exists d2: Int; below(ZERO, d2) and does_divide(d2, a) and does_divide(d2, b) and (forall e: Int; does_divide(e, a) -> does_divide(e, b) -> does_divide(e, d2)) and (exists r2: Int; exists s2: Int; d2 = add(mul(a, r2), mul(b, s2)))
                    [by exists_elim with-least-member-d]
                }
              @b-nonzero-gives-bezout |
                (b != ZERO)
                  -> exists d: Int; below(ZERO, d) and does_divide(d, a) and does_divide(d, b) and (forall e: Int; does_divide(e, a) -> does_divide(e, b) -> does_divide(e, d)) and (exists r: Int; exists s: Int; d = add(mul(a, r), mul(b, s)))
                [by implies_intro given-b-nonzero]
            }
          @a-nonzero-gives-bezout |
            (a != ZERO)
              -> (b != ZERO) -> exists d: Int; below(ZERO, d) and does_divide(d, a) and does_divide(d, b) and (forall e: Int; does_divide(e, a) -> does_divide(e, b) -> does_divide(e, d)) and (exists r: Int; exists s: Int; d = add(mul(a, r), mul(b, s)))
            [by implies_intro given-a-nonzero]
        }
      @discharge-b |
        forall b: Int; (a != ZERO) -> (b != ZERO) -> exists d: Int; below(ZERO, d) and does_divide(d, a) and does_divide(d, b) and (forall e: Int; does_divide(e, a) -> does_divide(e, b) -> does_divide(e, d)) and (exists r: Int; exists s: Int; d = add(mul(a, r), mul(b, s)))
        [by forall_intro generalize-b]
    }
  @conclusion |
    forall a, b: Int; (a != ZERO) -> (b != ZERO) -> exists d: Int; below(ZERO, d) and does_divide(d, a) and does_divide(d, b) and (forall e: Int; does_divide(e, a) -> does_divide(e, b) -> does_divide(e, d)) and (exists r: Int; exists s: Int; d = add(mul(a, r), mul(b, s)))
    [by forall_intro generalize-a]
qed
```

## The Coprime Corollary

> **Corollary 2.11.** Let $a$ and $b$ be two integers that are relatively prime.
> Then there exist integers $r$ and $s$ such that $ar + bs = 1$.

If `a` and `b` are coprime — every common divisor is `±1` — Bézout's positive
common divisor `d = gcd(a,b)` must itself be `1` or `−1`. It is positive
(`below(ZERO, d)`), and `−1` is *not* positive (`negOneBelowZero` puts `−1 < 0`,
which together with `0 < −1` and transitivity would give `0 < 0`), so `d = 1` and
Bézout's identity `d = ar + bs` becomes `ar + bs = 1`.

```bpa
theorem coprimeBezout: forall a, b: Int; a != ZERO -> b != ZERO ->
  (forall e: Int; does_divide(e, a) -> does_divide(e, b) -> (e = ONE or e = neg(ONE)))
  -> exists r: Int; exists s: Int; add(mul(a, r), mul(b, s)) = ONE
proof
  @generalize-a |
    fix a: Int {
      @generalize-b |
        fix b: Int {
          @given-a-nonzero |
            assume a != ZERO {
              @given-b-nonzero |
                assume b != ZERO {
                  @given-coprime |
                    assume forall e: Int; does_divide(e, a) -> does_divide(e, b) -> (e = ONE or e = neg(ONE)) {
                      @a-nonzero |
                        a != ZERO
                        [by hypothesis given-a-nonzero]
                      @b-nonzero |
                        b != ZERO
                        [by hypothesis given-b-nonzero]
                      @coprime |
                        forall e: Int; does_divide(e, a) -> does_divide(e, b) -> (e = ONE or e = neg(ONE))
                        [by hypothesis given-coprime]
                      // Bézout supplies a positive gcd d = ar + bs dividing a and b.
                      @bezout-for-all |
                        forall a2, b2: Int; a2 != ZERO -> b2 != ZERO -> exists d: Int; below(ZERO, d) and does_divide(d, a2) and does_divide(d, b2) and (forall e: Int; does_divide(e, a2) -> does_divide(e, b2) -> does_divide(e, d)) and (exists r: Int; exists s: Int; d = add(mul(a2, r), mul(b2, s)))
                        [by theorem bezout]
                      @bezout-at-a-b |
                        a != ZERO -> b != ZERO -> exists d: Int; below(ZERO, d) and does_divide(d, a) and does_divide(d, b) and (forall e: Int; does_divide(e, a) -> does_divide(e, b) -> does_divide(e, d)) and (exists r: Int; exists s: Int; d = add(mul(a, r), mul(b, s)))
                        [by forall_elim(a, b) bezout-for-all]
                      @gcd-exists |
                        exists d: Int; below(ZERO, d) and does_divide(d, a) and does_divide(d, b) and (forall e: Int; does_divide(e, a) -> does_divide(e, b) -> does_divide(e, d)) and (exists r: Int; exists s: Int; d = add(mul(a, r), mul(b, s)))
                        [by tautology bezout-at-a-b a-nonzero b-nonzero]
                      @with-gcd-d |
                        unpack d: Int from gcd-exists {
                          @d-has-all-gcd-properties |
                            below(ZERO, d) and does_divide(d, a) and does_divide(d, b) and (forall e: Int; does_divide(e, a) -> does_divide(e, b) -> does_divide(e, d)) and (exists r: Int; exists s: Int; d = add(mul(a, r), mul(b, s)))
                            [by hypothesis with-gcd-d]
                          @d-is-positive |
                            below(ZERO, d)
                            [by tautology d-has-all-gcd-properties]
                          @d-divides-a |
                            does_divide(d, a)
                            [by tautology d-has-all-gcd-properties]
                          @d-divides-b |
                            does_divide(d, b)
                            [by tautology d-has-all-gcd-properties]
                          @d-is-a-combination |
                            exists r: Int; exists s: Int; d = add(mul(a, r), mul(b, s))
                            [by tautology d-has-all-gcd-properties]
                          // coprimality forces the gcd to be 1 or -1.
                          @coprime-at-d |
                            does_divide(d, a) -> does_divide(d, b) -> (d = ONE or d = neg(ONE))
                            [by forall_elim(d) coprime]
                          @d-is-one-or-neg-one |
                            d = ONE or d = neg(ONE)
                            [by tautology coprime-at-d d-divides-a d-divides-b]
                          @conclusion-bezout-identity |
                            exists r: Int; exists s: Int; add(mul(a, r), mul(b, s)) = ONE
                            case on d-is-one-or-neg-one {
                              @when-d-is-one |
                                assume d = ONE {
                                  @d-is-one |
                                    d = ONE
                                    [by hypothesis when-d-is-one]
                                  @with-coefficient-r |
                                    unpack r: Int from d-is-a-combination {
                                      @d-is-combination-in-r |
                                        exists s: Int; d = add(mul(a, r), mul(b, s))
                                        [by hypothesis with-coefficient-r]
                                      @with-coefficient-s |
                                        unpack s: Int from d-is-combination-in-r {
                                          @d-equals-combination |
                                            d = add(mul(a, r), mul(b, s))
                                            [by hypothesis with-coefficient-s]
                                          @one-equals-combination |
                                            ONE = add(mul(a, r), mul(b, s))
                                            [by rewrite d-is-one d-equals-combination]
                                          @combination-equals-one |
                                            add(mul(a, r), mul(b, s)) = ONE
                                            [by symmetry one-equals-combination]
                                          @combination-in-s-is-one |
                                            exists s2: Int; add(mul(a, r), mul(b, s2)) = ONE
                                            [by exists_intro(s) combination-equals-one]
                                          @conclusion-bezout-identity |
                                            exists r2: Int; exists s2: Int; add(mul(a, r2), mul(b, s2)) = ONE
                                            [by exists_intro(r) combination-in-s-is-one]
                                        }
                                      @conclusion-bezout-identity |
                                        exists r2: Int; exists s2: Int; add(mul(a, r2), mul(b, s2)) = ONE
                                        [by exists_elim with-coefficient-s]
                                    }
                                  @conclusion-bezout-identity |
                                    exists r2: Int; exists s2: Int; add(mul(a, r2), mul(b, s2)) = ONE
                                    [by exists_elim with-coefficient-r]
                                }
                              @when-d-is-neg-one |
                                assume d = neg(ONE) {
                                  @d-is-neg-one |
                                    d = neg(ONE)
                                    [by hypothesis when-d-is-neg-one]
                                  // d positive but d = -1 < 0 is impossible.
                                  @neg-one-is-positive |
                                    below(ZERO, neg(ONE))
                                    [by rewrite d-is-neg-one d-is-positive]
                                  @neg-one-is-negative |
                                    below(neg(ONE), ZERO)
                                    [by theorem negOneBelowZero]
                                  @less-than-transitive |
                                    forall x, y, z: Int; below(x, y) -> below(y, z) -> below(x, z)
                                    [by theorem lessThanTransitive]
                                  @transitive-through-neg-one |
                                    below(ZERO, neg(ONE)) -> below(neg(ONE), ZERO) -> below(ZERO, ZERO)
                                    [by forall_elim(ZERO, neg(ONE), ZERO) less-than-transitive]
                                  @zero-below-itself |
                                    below(ZERO, ZERO)
                                    [by tautology transitive-through-neg-one neg-one-is-positive neg-one-is-negative]
                                  @less-than-is-irreflexive |
                                    forall n: Int; not below(n, n)
                                    [by theorem lessThanIrreflexive]
                                  @zero-not-below-itself |
                                    not below(ZERO, ZERO)
                                    [by forall_elim(ZERO) less-than-is-irreflexive]
                                  @conclusion-bezout-identity |
                                    exists r2: Int; exists s2: Int; add(mul(a, r2), mul(b, s2)) = ONE
                                    [by absurd zero-below-itself zero-not-below-itself]
                                }
                            }
                        }
                      @conclusion-bezout-identity |
                        exists r2: Int; exists s2: Int; add(mul(a, r2), mul(b, s2)) = ONE
                        [by exists_elim with-gcd-d]
                    }
                  @coprime-implies-bezout-identity |
                    (forall e: Int; does_divide(e, a) -> does_divide(e, b) -> (e = ONE or e = neg(ONE)))
                      -> exists r: Int; exists s: Int; add(mul(a, r), mul(b, s)) = ONE
                    [by implies_intro given-coprime]
                }
              @b-nonzero-implies-coprime-bezout |
                (b != ZERO)
                  -> (forall e: Int; does_divide(e, a) -> does_divide(e, b) -> (e = ONE or e = neg(ONE)))
                  -> exists r: Int; exists s: Int; add(mul(a, r), mul(b, s)) = ONE
                [by implies_intro given-b-nonzero]
            }
          @a-nonzero-implies-coprime-bezout |
            (a != ZERO)
              -> (b != ZERO)
              -> (forall e: Int; does_divide(e, a) -> does_divide(e, b) -> (e = ONE or e = neg(ONE)))
              -> exists r: Int; exists s: Int; add(mul(a, r), mul(b, s)) = ONE
            [by implies_intro given-a-nonzero]
        }
      @discharge-b |
        forall b: Int; (a != ZERO) -> (b != ZERO) -> (forall e: Int; does_divide(e, a) -> does_divide(e, b) -> (e = ONE or e = neg(ONE))) -> exists r: Int; exists s: Int; add(mul(a, r), mul(b, s)) = ONE
        [by forall_intro generalize-b]
    }
  @conclusion |
    forall a, b: Int; (a != ZERO) -> (b != ZERO) -> (forall e: Int; does_divide(e, a) -> does_divide(e, b) -> (e = ONE or e = neg(ONE))) -> exists r: Int; exists s: Int; add(mul(a, r), mul(b, s)) = ONE
    [by forall_intro generalize-a]
qed
```

## The Euclidean Algorithm

Judson closes §2.2 with the **Euclidean Algorithm**: to compute `gcd(a, b)`
concretely, repeatedly apply the Division Algorithm — `a = bq₁ + r₁`,
`b = r₁q₂ + r₂`, `r₁ = r₂q₃ + r₃`, … — until a zero remainder is reached; the
last nonzero remainder is `gcd(a, b)`, and back-substituting up the chain recovers
the Bézout coefficients `r`, `s` of the previous theorem. This is a *computation*
on particular integers rather than a universally-quantified statement, so we do
not transcribe a numeric instance here; `bezout` already establishes, for every
nonzero `a`, `b`, the existence and defining properties of the gcd that the
algorithm computes.

```bpa
// The Euclidean Algorithm (illustrative, not transcribed):
//   gcd(a, b): while b != 0 { (a, b) := (b, a mod b) }; return a
// It terminates because the nonnegative remainders strictly decrease
// (Well-Ordering), and back-substitution through the division steps yields the
// Bézout coefficients r, s with gcd(a, b) = a*r + b*s established by `bezout`.
```
