# The Integers — Primes

A literate `bpa` transliteration of **Chapter 2 ("The Integers"), §2.2 (Greatest
Common Divisors and Primes)** of Thomas W. Judson's *Abstract Algebra* (source:
`vendor/aata/src/integers.xml`; © 1997–2026 Judson, GFDL 1.3). Run
`bpa check aata/2.3-primes.md`.

*Coming next: GCD/Bézout, the Euclidean algorithm, primes, and the Fundamental
Theorem of Arithmetic.* These build on the Division Algorithm proved in
`std/integer-division.bpa` (§2.2). We bring in that library, the ℤ order, and
divisibility, naming the arithmetic vocabulary this section will use.

```bpa
import division <<< "std/integer-division.bpa"
import order <<< "std/integer-order.bpa"
import divides <<< "std/integer-divides.bpa"

sort Int = division.Int
const ZERO = division.ZERO
const ONE = division.ONE
func add = division.add
func mul = division.mul
func sub = division.sub
pred below = division.below
pred at_most = division.at_most
pred does_divide = division.does_divide

theorem divisionAlgorithmExists = division.divisionAlgorithmExists
theorem divisionAlgorithmUnique = division.divisionAlgorithmUnique
```
