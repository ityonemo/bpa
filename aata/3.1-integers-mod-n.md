# Integer Equivalence Classes and Symmetries

A literate `bpa` transliteration of **Chapter 3 ("Groups"), §3.1 "Integer
Equivalence Classes and Symmetries"** of Thomas W. Judson's *Abstract Algebra:
Theory and Applications* (source: `vendor/aata/src/groups.xml`; © 1997–2026
Judson, GFDL 1.3). Run `bpa check aata/3.1-integers-mod-n.md` to verify every
proof block below.

This section motivates the definition of a group (which does not arrive until
§3.2) with two families of concrete examples: the **integers mod $n$** and the
**symmetries** of a plane figure. Judson does *not* yet have the word "group",
"subgroup", or "quotient" available here — so the one result he proves, the
proposition on arithmetic modulo $n$, is proved entirely at the level of the
**integers and the congruence relation** $a \equiv b \pmod n$. We transliterate
it the same way: congruence is a relation on $\mathbb Z$, defined by
$n \mid (a - b)$, and the proposition's arithmetic is ordinary integer algebra.

Everything rests on the integer theory built up through Chapter 2 — the ring
$(\mathbb Z, +, \cdot)$, divisibility, and the gcd/Bézout theory — which Judson
has in hand by this point in the book.

## Congruence modulo $n$

Recall from Chapter 1 (§1.2, Example) the equivalence relation of **congruence
modulo $n$** on the integers: $a$ is congruent to $b$ modulo $n$, written
$a \equiv b \pmod n$, exactly when $n$ divides $a - b$. The equivalence classes
under this relation are the sets

$$[a] = \{ \ldots, a - 2n,\ a - n,\ a,\ a + n,\ a + 2n, \ldots \},$$

and $\mathbb Z_n = \{[0], [1], \ldots, [n-1]\}$ is the set of these $n$ classes.

We encode $a \equiv b \pmod n$ directly as the relation on $\mathbb Z$; the
packaging of the classes into the set $\mathbb Z_n$ (a set of sets) is not
needed for the proposition Judson proves.

```bpa
// a ≡ b (mod n)  ⟺  n | (a − b).
define congruent(a: Int, b: Int, n: Int) = does_divide(n, sub(a, b))
```

## The proposition on equivalence classes in $\mathbb Z_n$

> **Proposition.** Let $\mathbb Z_n$ be the set of equivalence classes of the
> integers mod $n$ and $a, b, c \in \mathbb Z_n$.
>
> 1. Addition and multiplication are commutative modulo $n$:
>    $$a + b \equiv b + a \pmod n \qquad ab \equiv ba \pmod n.$$
> 2. Addition and multiplication are associative modulo $n$.
> 3. There are additive and multiplicative identities.
> 4. Multiplication distributes over addition.
> 5. For every integer $a$ there is an additive inverse $-a$.
> 6. Let $a$ be a nonzero integer. Then $\gcd(a, n) = 1$ if and only if there
>    exists a multiplicative inverse $b$ for $a$ modulo $n$; that is, a nonzero
>    integer $b$ such that $ab \equiv 1 \pmod n$.
>
> *We will prove (1) and (6) and leave the remaining properties to be proven in
> the exercises.*

Judson proves (1) and (6) in the running text and leaves parts (2)–(5) as this
section's exercises. We prove all six properties inline in the main text here; a
dedicated exercises pass over the AATA corpus (not yet run for the Chapter 2–3
main-text sections) will later fold (2)–(5) into an `## Exercises` section as
pointers back to these proofs. Each of (1)–(5) goes through by the same argument:
the two sides are *equal* integers (a ring law of $\mathbb Z$), so their difference
is $0$ and $n \mid 0$; (6) is the Bézout argument for multiplicative inverses.

### (1) Addition and multiplication are commutative modulo $n$

> Addition and multiplication are commutative modulo $n$ since the remainder of
> $a + b$ divided by $n$ is the same as the remainder of $b + a$ divided by $n$.

At the level of the congruence relation this is immediate: $a + b$ and $b + a$
are *equal* integers (commutativity of $+$ in $\mathbb Z$), so their difference
is $0$, and $n \mid 0$. Same for multiplication.

```bpa
// n | 0 for every n: 0 = n·0.  (The additive-commutativity witness below.)
theorem dividesZero: forall n: Int; does_divide(n, ZERO)
proof
  @generalize-n |
    fix n: Int {
      @n-times-zero-is-zero |
        mul(n, ZERO) = ZERO
        [by specialize mulZeroRight(n)]
      @zero-is-multiple |
        ZERO = mul(n, ZERO)
        [by symmetry n-times-zero-is-zero]
      @n-divides-zero |
        does_divide(n, ZERO)
        [by specialize dividesIntro(ZERO, n, ZERO) zero-is-multiple]
    }
  @conclusion |
    forall n: Int; does_divide(n, ZERO)
    [by forall_intro generalize-n]
qed
```

The recurring move in Judson's proof of (1)–(5) is: *the two sides are the same
integer, so their difference is $0$ and $n \mid 0$.* We capture it once — if
$a = b$ then $a \equiv b \pmod n$ — and reuse it for each part. The difference
$a - b$ collapses to $0$ (`arithmetic`), which is $n \cdot 0$, so $n$ divides it.

```bpa
theorem congruentOfEqual: forall a, b, n: Int; a = b -> congruent(a, b, n)
proof
  @generalize-a |
    fix a: Int {
      @generalize-b |
        fix b: Int {
          @generalize-n |
            fix n: Int {
              @given-equal |
                assume a = b {
                  @a-equals-b |
                    a = b
                    [by hypothesis given-equal]
                  // a − b = a − a = 0 once b is rewritten to a.
                  @self-difference-is-zero |
                    sub(a, a) = ZERO
                    [by arithmetic]
                  @difference-is-zero |
                    sub(a, b) = ZERO
                    [by rewrite a-equals-b self-difference-is-zero]
                  @n-times-zero |
                    mul(n, ZERO) = ZERO
                    [by specialize mulZeroRight(n)]
                  @zero-is-n-times-zero |
                    ZERO = mul(n, ZERO)
                    [by symmetry n-times-zero]
                  @difference-is-a-multiple |
                    sub(a, b) = mul(n, ZERO)
                    [by chain difference-is-zero zero-is-n-times-zero]
                  @conclusion-congruent |
                    congruent(a, b, n)
                    [by specialize dividesIntro(sub(a, b), n, ZERO) difference-is-a-multiple]
                }
              @conclusion-implication |
                a = b -> congruent(a, b, n)
                [by implies_intro given-equal]
            }
          @discharge-n |
            forall n: Int; a = b -> congruent(a, b, n)
            [by forall_intro generalize-n]
        }
      @discharge-b |
        forall b, n: Int; a = b -> congruent(a, b, n)
        [by forall_intro generalize-b]
    }
  @conclusion |
    forall a, b, n: Int; a = b -> congruent(a, b, n)
    [by forall_intro generalize-a]
qed
```

**Addition is commutative modulo $n$.** $a + b$ and $b + a$ are the *same*
integer, so their difference is $0$ and $n \mid 0$.

```bpa
theorem addCongruentCommutes: forall a, b, n: Int; congruent(add(a, b), add(b, a), n)
proof
  @generalize-a |
    fix a: Int {
      @generalize-b |
        fix b: Int {
          @generalize-n |
            fix n: Int {
              // add(a, b) and add(b, a) are the same integer.
              @sum-commutes |
                add(a, b) = add(b, a)
                [by specialize addIsCommutative(a, b)]
              @conclusion-congruent |
                congruent(add(a, b), add(b, a), n)
                [by specialize congruentOfEqual(add(a, b), add(b, a), n) sum-commutes]
            }
          @discharge-n |
            forall n: Int; congruent(add(a, b), add(b, a), n)
            [by forall_intro generalize-n]
        }
      @discharge-b |
        forall b, n: Int; congruent(add(a, b), add(b, a), n)
        [by forall_intro generalize-b]
    }
  @conclusion |
    forall a, b, n: Int; congruent(add(a, b), add(b, a), n)
    [by forall_intro generalize-a]
qed
```

**Multiplication is commutative modulo $n$.** Identical: $ab$ and $ba$ are the
*same* integer (commutativity of $\cdot$ in $\mathbb Z$), so their difference is
$0$ and $n \mid 0$.

```bpa
theorem mulCongruentCommutes: forall a, b, n: Int; congruent(mul(a, b), mul(b, a), n)
```

### (2) Addition and multiplication are associative modulo $n$

> $(a + b) + c \equiv a + (b + c) \pmod n$ and $(ab)c \equiv a(bc) \pmod n$.

Again the two sides are *equal* integers — associativity of $+$ and $\cdot$ in
$\mathbb Z$ — so `congruentOfEqual` applies.

```bpa
theorem addCongruentAssociates:
  forall a, b, c, n: Int; congruent(add(add(a, b), c), add(a, add(b, c)), n)
proof
  @generalize-a |
    fix a: Int {
      @generalize-b |
        fix b: Int {
          @generalize-c |
            fix c: Int {
              @generalize-n |
                fix n: Int {
                  @sum-associates |
                    add(add(a, b), c) = add(a, add(b, c))
                    [by specialize addIsAssociative(a, b, c)]
                  @conclusion-congruent |
                    congruent(add(add(a, b), c), add(a, add(b, c)), n)
                    [by specialize congruentOfEqual(add(add(a, b), c), add(a, add(b, c)), n) sum-associates]
                }
              @discharge-n |
                forall n: Int; congruent(add(add(a, b), c), add(a, add(b, c)), n)
                [by forall_intro generalize-n]
            }
          @discharge-c |
            forall c, n: Int; congruent(add(add(a, b), c), add(a, add(b, c)), n)
            [by forall_intro generalize-c]
        }
      @discharge-b |
        forall b, c, n: Int; congruent(add(add(a, b), c), add(a, add(b, c)), n)
        [by forall_intro generalize-b]
    }
  @conclusion |
    forall a, b, c, n: Int; congruent(add(add(a, b), c), add(a, add(b, c)), n)
    [by forall_intro generalize-a]
qed
```

### (3) Additive and multiplicative identities modulo $n$

> $a + 0 \equiv a \pmod n$ and $a \cdot 1 \equiv a \pmod n$.

$a + 0$ and $a \cdot 1$ are literally $a$ in $\mathbb Z$ (`addZeroRight`,
`mulOneRight`), so each is congruent to $a$.

```bpa
theorem addZeroCongruent: forall a, n: Int; congruent(add(a, ZERO), a, n)
proof
  @generalize-a |
    fix a: Int {
      @generalize-n |
        fix n: Int {
          @add-zero |
            add(a, ZERO) = a
            [by specialize addZeroRight(a)]
          @conclusion-congruent |
            congruent(add(a, ZERO), a, n)
            [by specialize congruentOfEqual(add(a, ZERO), a, n) add-zero]
        }
      @discharge-n |
        forall n: Int; congruent(add(a, ZERO), a, n)
        [by forall_intro generalize-n]
    }
  @conclusion |
    forall a, n: Int; congruent(add(a, ZERO), a, n)
    [by forall_intro generalize-a]
qed
```

### (4) Multiplication distributes over addition modulo $n$

> $a(b + c) \equiv ab + ac \pmod n$.

$a(b+c)$ and $ab + ac$ are equal integers by the distributive law of $\mathbb Z$
(`mulAddDistribLeft`).

```bpa
theorem mulDistributesCongruent:
  forall a, b, c, n: Int; congruent(mul(a, add(b, c)), add(mul(a, b), mul(a, c)), n)
proof
  @generalize-a |
    fix a: Int {
      @generalize-b |
        fix b: Int {
          @generalize-c |
            fix c: Int {
              @generalize-n |
                fix n: Int {
                  @distributes |
                    mul(a, add(b, c)) = add(mul(a, b), mul(a, c))
                    [by specialize mulAddDistribLeft(a, b, c)]
                  @conclusion-congruent |
                    congruent(mul(a, add(b, c)), add(mul(a, b), mul(a, c)), n)
                    [by specialize congruentOfEqual(mul(a, add(b, c)), add(mul(a, b), mul(a, c)), n) distributes]
                }
              @discharge-n |
                forall n: Int; congruent(mul(a, add(b, c)), add(mul(a, b), mul(a, c)), n)
                [by forall_intro generalize-n]
            }
          @discharge-c |
            forall c, n: Int; congruent(mul(a, add(b, c)), add(mul(a, b), mul(a, c)), n)
            [by forall_intro generalize-c]
        }
      @discharge-b |
        forall b, c, n: Int; congruent(mul(a, add(b, c)), add(mul(a, b), mul(a, c)), n)
        [by forall_intro generalize-b]
    }
  @conclusion |
    forall a, b, c, n: Int; congruent(mul(a, add(b, c)), add(mul(a, b), mul(a, c)), n)
    [by forall_intro generalize-a]
qed
```

### (5) Additive inverses modulo $n$

> For every integer $a$ there is an additive inverse $-a$: $a + (-a) \equiv 0
> \pmod n$.

$a + (-a) = 0$ in $\mathbb Z$ (`addNegRight`), so $a + (-a) \equiv 0 \pmod n$.

```bpa
theorem addInverseCongruent: forall a, n: Int; congruent(add(a, neg(a)), ZERO, n)
proof
  @generalize-a |
    fix a: Int {
      @generalize-n |
        fix n: Int {
          @add-inverse |
            add(a, neg(a)) = ZERO
            [by specialize addNegRight(a)]
          @conclusion-congruent |
            congruent(add(a, neg(a)), ZERO, n)
            [by specialize congruentOfEqual(add(a, neg(a)), ZERO, n) add-inverse]
        }
      @discharge-n |
        forall n: Int; congruent(add(a, neg(a)), ZERO, n)
        [by forall_intro generalize-n]
    }
  @conclusion |
    forall a, n: Int; congruent(add(a, neg(a)), ZERO, n)
    [by forall_intro generalize-a]
qed
```
